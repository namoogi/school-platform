# 세션 시작 점검 (모든 세션 공통)

1. **지침 읽기**: `AGENTS.md` → `docs/COLLABORATION.md` → (자동 실행이면) `docs/automation/AUTOPILOT.md`·`RUN-PROMPT.md`·`QUEUE.md`.
2. **세션 역할 확인**: 관제 세션(사용자와 대화하며 계획·정리·검토·보고)인지, 개발 세션(자동 실행·Codex 작업: 한 기능 구현)인지 첫 메시지에 적는다. 관제 세션은 큰 구현을 직접 하기보다 대기열·결정 기록을 정리하고 개발 세션에 넘긴다.
3. **저장소 상태**:
   - `gh pr list --state open` — 열린 PR, `[자동·진행 중]` PR과 마지막 커밋 시각(40분 규칙), 쌓인 PR의 끝 브랜치
   - 최근 CI 결과(`gh run list -L 5`)와 "주간 점검" 이슈
   - 기준 브랜치 결정(main에 앱이 있으면 main)
4. **환경**: 로컬 Postgres 16(54322), `npm ci`, `npm run typecheck`가 기준 브랜치에서 통과하는지.
5. **할 일 결정**: 사용자 요청 > 이어가기(멈춘 진행 중 PR) > 대기열 자동 허용 항목 > 설계 갱신 > 도구 갱신 > 대기. 고른 것과 이유를 한 줄로 남긴다.
