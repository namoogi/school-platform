# 결정 요청함

서브 세션·자동 실행이 사용자 결정을 기다리는 일을 모은다. 관제 세션이 관리하고, 사용자는 관제 대화에서 답한다.
규칙: `docs/automation/SCHOOL-SESSIONS.md` '승인·결정이 필요할 때'. 답이 나면 '결정'으로 옮기고 요청한 세션에 알린다.

상태: **열림**(답 기다림) · **추천안 진행 중**(되돌릴 수 있어 먼저 진행, 답 오면 맞춤) · **보류**(되돌리기 어려워 멈춤) · **결정**
