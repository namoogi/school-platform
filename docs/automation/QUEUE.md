# 자동 개선 대기열

자동 개선 실행(②)이 고를 수 있는 작업 목록. **자동 허용**만 사람 확인 없이 구현 PR까지 진행한다. **승인 필요**는 설계 문서까지만 만든다. 위에서부터 처리한다.

| 상태 | 작업 | 범위·완료 기준 |
| --- | --- | --- |
| 자동 허용 | 접근성 자동 검사(axe)를 E2E에 추가 | 개발 의존성 추가, 심각도 serious 이상 0건을 E2E 단계로. 위반이 있으면 고치거나 목록으로 보고 |
| 자동 허용 | DataTable 컴포넌트 (정렬·빈 상태·밀도) | `src/components/`에 추가하고 전체 관리 학교 표와 설정 표에 적용. DB 변경 없음 |
| 자동 허용 | 다크 테마 토큰 | 보고서 §5.1 다크 초안으로 의미 토큰만 재정의(`prefers-color-scheme`), 대비 계산 기록 |
| 자동 허용 | 확인 대화상자 컴포넌트 | 학교 상태 변경·청구 확정·구성원 빼기의 `confirm()`을 대체 (포커스 가둠·Esc) |
| 승인 필요 | AI 분석 연결 | 유료 API. 프롬프트·비용 추정 문서까지만 |
| 승인 필요 | 초대 메일 발송 | 외부 발송. 서비스 비교 결정 기록까지만 |
| 승인 필요 | 실제 결제 연동 | 결제 대행사 비교 결정 기록까지만 |
| 승인 필요 | 학교 가입 신청 흐름 | 새 표·공개 화면. 디자인 브리프까지만 |
