# Claude Code로 학교 홈페이지 시안 만들기

학교 선생님이 **자기 구독**의 Claude Code(데스크톱 앱·터미널·웹)에서 쓰는 안내다. 플랫폼은 구독 로그인 정보를 받지 않는다. 공통 규칙·API: [README.md](README.md)

## 준비 (선생님)
1. `/site` → 설정 → **AI 작업 공간**에서 에이전트 'Claude Code', 맡길 종류·항목·권한, 기한(7일 권장)을 골라 발급하고 복사한다.
2. 토큰을 대화창에 붙여 넣지 않는다. 환경 변수로 넣는다.
   - 터미널: `export SCHOOL_AGENT_TOKEN=<복사한 값>` 뒤 `claude` 실행
   - 클라우드(claude.ai/code): 환경 설정의 네트워크 비밀(호스트 `onschools.vercel.app`, 머리 `x-agent-token`)로 넣으면 요청에 자동으로 붙는다. 이때 스크립트에는 `SCHOOL_AGENT_TOKEN`에 아무 `agt_` 모양 값(예: `agt_` 뒤 0 64개)을 준다.
3. 이 저장소를 열거나(권장, 스크립트를 쓸 수 있음) 이 문서와 README.md를 대화에 준다.

## 첫 지시 예 (복사해서 고쳐 쓰기)
```
학교 홈페이지 시안 작업이다. docs/agents/README.md 와 docs/agents/claude-code.md 를 먼저 읽어라.
토큰은 환경 변수 SCHOOL_AGENT_TOKEN 에 있다. 값을 출력하지 마라.
할 일: <예: 쪽 'admissions'의 입학 절차 글을 3단계로 다듬고 태국어 글을 더한다>
1) GET /api/agent/me 로 범위를 확인하고, 2) 최신 판을 읽어 고친 새 판을 base_version 과 함께 저장하고,
3) 저장한 판 번호와 바꾼 점을 나에게 알려라. 공개는 내가 한다. 모르는 사실은 지어내지 말고 물어라.
```

## 하지 말 것
- 공개를 시도하거나, 403이 났을 때 다른 길을 찾지 않는다(범위는 사람이 정한다).
- 저장소 코드를 고쳐 내용 문제를 풀지 않는다. 코드 변경은 학교 개발 연동의 PR 절차로 따로 한다.
