# 태국어 용어집 (ADR 0037 번역 묶음 `i18n/th.json`)

> **요약** 태국어 화면 문구를 같은 낱말로 옮기기 위한 기준. 학교 실무 용어는 태국 학교에서 흔히 쓰는 말을 따른다. 원어민 검토 전 초안이다(115차 이후, 2026-11-28).

## 문체
- 화면 문구는 존댓말 없이 짧고 중립적으로(버튼은 동사형: บันทึก, ยกเลิก). 안내 문장 끝에 ค่ะ/ครับ를 붙이지 않는다.
- 제품명·코드·주소·형식 이름(onschools, Claude Code, Codex, PDF, JSON, URL, `x-agent-token`, base_version)은 그대로.
- 채우기 자리 `{name}`은 그대로 둔다. 복수형 `{n, plural, …}`은 태국어에 복수형이 없으므로 `other` 한 갈래만 써도 된다(구조는 유지).
