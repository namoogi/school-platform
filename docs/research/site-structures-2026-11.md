# 학교 홈페이지 구조 패턴 조사 (2026-11-28, 134차 근거)

> **요약** 학교 사이트에 흔한 구조는 ① 상단 메뉴 + 하위 쪽 안 왼쪽 메뉴(한국 학교), ② 메가 메뉴 + 바로가기 + 고정 '입학 문의' 단추(미국·국제학교), ③ 바로가기 타일 포털입니다. 한 쪽 스크롤·벤토·스크롤 이야기형은 유행이지만 쓰는 곳이 좁습니다(추정). 템플릿 마켓은 대부분 '업종·목적'과 '스타일'로 거르고, 구조(레이아웃)로 거르는 곳은 WordPress 디렉터리 정도라서, 우리 고르기 화면에 구조 축을 따로 둡니다.

**조사 한계:** 이 조사는 웹 검색 결과 요약(스니펫)에 기댔습니다. 조사 세션에서 페이지 본문 열기(WebFetch)가 막혀(webflow.com·wordpress.org DNS 오류) 본문을 직접 확인하지 못했고, 실제 학교 사이트 화면도 보지 못했습니다. 통계는 출처가 밝힌 것만 적었습니다. 본문 확인이 필요하면 다시 조사합니다.

## 1. 구조 패턴 8가지
| # | 이름 | 탐색 동작 | 학교에 맞는 경우 | 근거(검색 결과) |
| --- | --- | --- | --- | --- |
| S1 | 게시판 포털형(상단 메뉴 + 왼쪽 하위 메뉴) | 대메뉴 드롭다운, 하위 메뉴는 새 쪽으로, 하위 쪽 안에 왼쪽 세로 메뉴 | 공지·게시판이 많은 한국 공립학교 | 정보교육학회논문지 2003(KoreaScience JAKO200332056743889), 아이엠티처 자료 |
| S2 | 메가 메뉴형 | 대메뉴에 화면 폭 패널, 고정 상단 줄, 유틸리티 메뉴 | 쪽이 많은 사립·국제학교 | Finalsite 'top navigation trends', 'school website navigation strategies'(대메뉴 8개 이하), Design Shack 2025 |
| S3 | 바로가기 타일 포털형 | 첫 화면에 자주 찾는 기능 타일, 대상별 묶음 | 재학생 가족이 주 방문자인 학교·교육청 | Finalsite 2025-11 사례, 경기도교육청 개편 보도 2025('맞춤형 바로가기') |
| S4 | 모집 랜딩형(고정 행동 단추) | 긴 첫 화면 + 늘 보이는 '입학 문의·견학' 단추 | 모집이 중요한 사립·국제·대안학교 | Colorlib 학교 사례(IGS Sydney 고정 견학 단추), Finalsite 국제학교 사례 |
| S5 | 한 쪽 스크롤형(옆 차례) | 메뉴를 누르면 구역으로 스크롤, 현재 구역 표시(스크롤스파이) | 작은 배움터·유치원·행사 쪽 | Codyhouse 세로 고정 탐색, UX Collective, EasyScrollDots |
| S6 | 매거진·편집형 | 크고 작은 기사 카드의 비대칭 배치 | 소식·작품 기록이 많은 학교 | Speckyboy, Awwwards 매거진 |
| S7 | 벤토 격자형 | 크기가 다른 칸에 핵심 요약(구조보다 구역 배치) | 학교 소개 요약 | freeCodeCamp, Netguru 2026(모바일·화면 낭독기에서 약함) |
| S8 | 스크롤 이야기형(전체 화면 사진) | 메뉴 최소, 스크롤에 따라 장면 전환 | 사명·철학을 앞세우는 학교, 후원 쪽 | Wix scrollytelling, Tilda 2025 |

- 숨김(슬라이드아웃) 메뉴는 독립 구조가 아니라 S2·S5·S8에 붙는 방식으로 봤습니다.
- 분할 화면형은 근거를 찾지 못해 뺐습니다.

## 2. 마켓의 거름 칸
| 곳 | 거르는 칸 | 성격 |
| --- | --- | --- |
| WordPress.org | Layout(Grid·Columns·Sidebar…), Features, Subject | 구조 + 기능 + 주제 |
| Webflow | Category(Education 등), Style, Type, 기능 태그 | 업종 + 스타일 |
| Framer | Business·Creative·Style·Landing·Portfolio | 목적 + 스타일 |
| Squarespace | Type(기능), Topic(주제) | 기능 + 주제(2차 자료) |
| Wix | Education > Schools & Universities 등 | 업종 |
| ThemeForest | Category, Price, Rating, Date | 업종 + 상거래 |

## 3. 우리 분류(ADR 0050)로 옮긴 것
- **메뉴 구조**(공개 화면 동작으로 실제로 다른 것만): 위 메뉴형(드롭다운, 하위 메뉴 = 쪽) · 옆 메뉴형(S1) · 한 쪽 스크롤형(S5). 메가 메뉴형(S2)은 새 템플릿과 함께 더한다.
- **첫 화면 구성**: 알림판 · 매거진·편집(S6) · 모집 랜딩(S4) · 작품 격자 · 큰 사진 이야기(S8) · 바로가기 타일(S3).
- **내용·목적**: 알림·공지 · 이야기·철학 · 입학 모집 · 프로젝트·작품 · 사명·후원 · 국제·다국어 · 유치원 · 작은 배움터.
- 벤토(S7)는 구조가 아니라 구역 모양 후보로 남긴다.
