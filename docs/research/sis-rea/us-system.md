# REA 갈래 보고서: 미국 K-12 학적 제도 (기관·제도로서의 학교 기록)

- 작성: 2026-11-25 · 갈래: 미국 학교 기록이 **제도로서** 무엇을 담아야 하는가 (공급사 제품은 `commercial-sis.md`에서 다룸)
- 목적: 한국 + 미국을 기준 체계로 삼는 다학교 플랫폼의 핵심 데이터 모델(모든 표 `school_id` + RLS, 추가만 하는 판, 학기·학년도 마감 판, 정정은 새 판, 국가 서식은 출력 프로필)에 줄 근거.
- 표기
  - **사실 (검색 요약, [번호])**: 웹 검색 결과 요약에서 확인. 원문은 열지 못했다.
  - **사실 ([번호])**: 원문을 열어 확인. 이번 갈래에는 해당 없음(아래 '한계' 참고).
  - **추정**: 조사자 판단이나 일반 실무 지식. 근거 문서로 확인하지 않았다.
  - **확인 필요**: 근거가 부족하거나 출처끼리 다르다.
- **법률 자문이 아니다.** FERPA·COPPA·PPRA·주법 설명은 설계 근거용 요약이다. 실제 운영 판단은 해당 주·학교의 법률 검토가 필요하다.
- 개인정보 없음. 예시는 모두 일반 제도 설명이다.

## 0. 방법과 한계 (먼저 읽기)

1. 이 세션 네트워크는 정부·기관 사이트를 막았다. 원문 열기(WebFetch)를 시도한 `www.ed.gov`, `aacrao.org`, `in.gov`가 모두 이름 해석에 실패했다. 지침에 따라 더 시도하지 않았다.
2. 그래서 이 보고서의 '사실'은 전부 **웹 검색 결과 요약(검색 엔진이 원문에서 뽑은 발췌·요약)**이 근거다. 규정 조문 번호·숫자는 검색 요약에 나온 그대로 적었다. 조문 원문 대조가 필요한 곳은 '확인 필요'로 따로 표시했다.
3. 원문으로 다시 확인하려면 세션 네트워크 설정에서 `ed.gov`, `studentprivacy.ed.gov`, `ecfr.gov`, `nces.ed.gov`, `aacrao.org`, `commonapp.org`를 허용해야 한다.
4. 한국 쪽 사실은 같은 REA의 `national-alt.md`(한국 갈래)를 따랐다. 이 갈래에서 다시 확인하지 않았다.
5. 미국은 연방 국가라서 **학사 규칙 대부분이 주·학군 권한**이다. 아래 예시(시카고·메릴랜드·켄터키·텍사스 등)는 '이런 모양이 있다'는 표본이다. 미국 전체 기준이 아니다.

## 1. 학사 구조

### 1.1 학년·학년도·학기

| 항목 | 내용 | 근거 |
| --- | --- | --- |
| 학년 | PK(유치 전)·K·1~12학년. 초등(대개 K–5), 중학교(6–8 또는 7–8), 고등학교(9–12) 구분은 학군마다 다르다 | 추정 (일반 실무). Ed-Fi는 학년을 `GradeLevelDescriptor` 코드로 둔다: 사실 (검색 요약, [62]) |
| 학년도 길이 | 연방 기준은 없다. 주가 정한다. 38개 주 + DC가 최소 수업일수를 정하고, 180일이 오래된 관행이다(Pew 2023) | 사실 (검색 요약, [19]) |
| 최근 변화 | EdWeek(2026-10): 32개 주가 180일 이상. 콜로라도 160일(최소), 캔자스 186일(최대). 오클라호마 166→173일(2027-28부터). 웨스트버지니아는 180일 대신 연 900시간(2027-28부터) | 사실 (검색 요약, [19]) |
| 단위 혼재 | 주마다 '연 일수', '연 시간·분', '일 시간·분' 가운데 하나 이상으로 정한다. 점심·쉬는 시간 포함 여부도 다르다(ECS) | 사실 (검색 요약, [19]) |
| 학기 종류 | 학기제(semester, 2개), 3학기제(trimester), 분기제(quarter, 4개), 블록제가 공존한다 | 추정 (일반 실무) |
| 학기와 성적 기간은 다르다 | Ed-Fi에서 `Session`은 `Term` 코드(예: Semester, Quarter)를 갖는다. `GradingPeriod`(성적 기간, 예: First Six Weeks, 1st semester)는 따로 있다. 성적은 6주마다 매기고 학기는 한 학기 내내 갈 수 있다 | 사실 (검색 요약, [63]) |
| 성적 기간 → 학기 → 최종 | Ed-Fi `GradeType` 값: Conduct, Exam, Final, Grading Period, Mid-Term Grade, Progress Report, Semester | 사실 (검색 요약, [63]) |

> 설계 함의 (추정): 학기 나무(ADR 0025 L1 `terms`)는 **학점이 붙는 학기**와 **성적을 매기는 기간**을 다른 마디로 가져야 한다. 미국 고교의 흔한 모양: 학년도 → 학기 2 → 분기 2씩(성적 기간). 최종 성적·학점은 학기나 학년도 마디에 붙는다. 중간 성적(progress report)은 기록되지만 성적증명서에는 오르지 않는다.

### 1.4 SCED (NCES 과목 분류 코드)

| 항목 | 내용 | 근거 |
| --- | --- | --- |
| 무엇 | 주·학군마다 다른 과목을 비교·교환하려고 NCES(국가교육포럼)가 만든 **자발적** 분류 체계 | 사실 (검색 요약, [13]) |
| 12자리 식별자 | 과목 코드 5자리(교과 영역 2 + 과목 번호 3) + 수준 1자리 + 학점(또는 초·중 과목은 학년 범위 4자리) + 과목 순서. 예: 회계 I = `12104` + `G` + `0.50` + `14` → `12104G0.5014` | 사실 (검색 요약, [13]) |
| 수준 코드 | B 기초·보충, G 일반, C 대학 학점용(AP·IB·이중등록 포함), X 수준 없음(개관·자습). E(심화)·H(우등)는 주마다 쓰임이 다르다(버지니아는 E를 초·중 전용, H를 고교 우등에 씀) | 사실 (검색 요약, [14]) · 주별 차이는 **확인 필요** |
| 속성 | 12자리 뒤에 붙이는 선택 속성(attribute)이 따로 있다 | 사실 (검색 요약, [13]) |
| 학교 과목과의 관계 | 학교는 자기 과목 번호·이름을 유지하고 SCED 코드를 **사상(mapping)**한다. 표의 열 구성도 '학교 과목 번호 · 학교 과목명 · SCED 과목 코드 · 수준 · 학점 · 순서 · SCED 식별자'다 | 사실 (검색 요약, [13]) |

> 설계 함의 (추정): SCED는 학교 과목(`subjects`)에 붙는 **외부 분류 코드**다. 핵심 키가 아니다. 코드 목록(L5) + 과목 판의 사상 행으로 둔다. 한국의 교육과정 과목 코드(공통·일반선택 등)도 같은 자리에 들어간다.

### 1.5 학점(Carnegie unit)과 졸업 요건

| 항목 | 내용 | 근거 |
| --- | --- | --- |
| Carnegie 단위 | 1906년 Carnegie 재단이 정했다. 1학점 = 교사와 함께하는 **120시간**(연 7,200분). 예: 하루 1시간 × 주 5일 × 24주 | 사실 (검색 요약, [15]) |
| 주별 정의 차이 | 2010년 워싱턴주 조사: 시간 기준 정의 가운데 120시간이 가장 흔함(9개 주, 33%). 미주리는 7,830분(약 130.5시간) | 사실 (검색 요약, [15]) |
| 재단의 입장 변화 | Carnegie 재단은 시간 단위 학점을 벗어나려 한다(EdWeek 2022) | 사실 (검색 요약, [15]) |
| 반 학점 | 한 학기 과목은 보통 0.5학점이다(SCED 예시의 0.50) | 사실 (검색 요약, [13]) · '보통'은 추정 |
| 주 최소 졸업 요건 | 47개 주 + DC가 주 단위 최소 졸업 요건을 둔다(ECS 2015). 2023 비교표는 이수 경로·졸업장 종류·추가 인증(endorsement)·과목·시험·과목 밖 요건을 다룬다. 34개 주 이상이 졸업 시험·평가를 요구한다 | 사실 (검색 요약, [18]) |
| 교과별 학점 | 영어·수학·과학·사회 등 교과별 최소 학점은 주마다 다르다. 이번 검색 요약에는 교과별 숫자가 없었다 | 확인 필요 ([18] 원문 표) |
| 학군 추가 요건 | 학군은 주 최소보다 더 요구할 수 있다. 봉사 시간을 요구하는 주·학군도 있다 | 추정 |

### 1.6 학점 보충(credit recovery)과 성적 대체

| 항목 | 내용 | 근거 |
| --- | --- | --- |
| 정의 | 낙제한 과목의 학점을 다른 방식(대개 온라인·짧은 과정)으로 되찾는 것. 전국 통일 정의는 없다 | 사실 (검색 요약, [35]) |
| 원 성적 처리 (테네시 녹스 학군) | 보충 과목 성적의 25%를 원 성적에서 가져온다. 성적증명서에 보충 이수를 표시한다(예: 'CR English 11'). 원래 낙제 성적은 증명서에 남을 수 있으나 GPA에는 넣지 않는다 | 사실 (검색 요약, [35]) |
| 노스캐롤라이나 | FAQ: 보충은 졸업 학점만 되찾고 GPA에 영향 없음. 2025-26 설정 안내: 원 성적을 이수 비율만큼 새 점수에 섞고 원 성적을 감춘다 | 사실 (검색 요약, [35]). 두 문서의 관계(옛 규칙 → 새 규칙인지)는 **확인 필요** |
| 성적 대체(grade replacement)는 다르다 | 유타 프로보: 같은 과목을 다시 들어 더 높은 성적을 받으면 원 성적·과목을 증명서에서 뺀다. 보충과 다른 절차다 | 사실 (검색 요약, [35]) |

> 설계 함의 (추정): '원 시도'와 '보충·재수강 시도'는 **별개 수강 사건**이고, 그 관계(대체·평균·병기)는 학교 규칙 판이다. 원 시도를 지우지 않는다. 증명서에서 감출지, GPA에서 뺄지는 출력 프로필·GPA 규칙이 정한다. 한국의 '미도달 → 보충 이수 → E'와 같은 꼴이다.

### 1.7 역량 기반 학점·졸업 (NH·VT)

| 항목 | 내용 | 근거 |
| --- | --- | --- |
| 뉴햄프셔 | Ed 306.22: 학교 이사회는 표 306-1/306-2의 학점 누적을 통해 **역량을 입증한 성취**로 졸업을 정해야 한다. Ed 306.27: 졸업 20학점의 배분(표 306-2). 2023·2024년 개정안이 있었다 | 사실 (검색 요약, [16]). 개정안 채택 여부는 **확인 필요** |
| 버몬트 | Act 77(2013)과 교육 질 기준(EQS, Rule 2000)으로 모든 고교가 숙달 기반(proficiency-based) 학습·졸업 요건으로 옮겼다. 이제 Act 73으로 **학교별 숙달 기반 요건을 주 단위 졸업 요건으로 바꾸는 중**이다(2025 보고서, 2026 권고) | 사실 (검색 요약, [17]) |
| 시사점 | 역량 기반이어도 결국 '학점'으로 환산해 증명서에 올린다(NH는 학점 누적 형식 유지) | 사실 (검색 요약, [16]) · 일반화는 추정 |

> 설계 함의 (추정): 버몬트처럼 **졸업 요건 체계 자체가 학년도에 따라 바뀐다.** 졸업 요건은 입학 기수(cohort)별로 고정되는 규칙 판이어야 한다. 역량 성취(ADR 0025 `competency_items`)와 학점(수강 결과)은 둘 다 1급이다. 역량 → 학점 환산은 규칙이다.

## 2. 성적

### 2.1 글자 성적·척도·GPA

| 항목 | 내용 | 근거 |
| --- | --- | --- |
| 글자 성적 | A–F(D, F 사이 E는 대개 없음), +/− 쓰임과 백분율 분할점은 학교·학군이 정한다. 예: College Board 표본 학교 소개서 'A 94–100 = 4, B 85–93 = 3'. Penn은 '예: A = 90%, B = 80–89%처럼 척도를 밝히라'고 요청 | 사실 (검색 요약, [67]) · 'E 없음'은 추정 |
| 비가중 GPA | 4.0 척도(A=4 … F=0)가 흔하다 | 사실 (검색 요약, [67], [27]) |
| 가중 GPA | 연방·주 공통 기준 없음. College Board도 AP 가산점을 정하지 않는다. 흔한 기본값: 우등 +0.5, AP·IB·이중등록 +1.0(5.0 척도) | 사실 (검색 요약, [27]) |
| 학군 예 | 플로리다 힐스버러: A = 일반 4.0 / 우등 4.5 / AP·IB·DE·AICE 5.0, 입학 기수별로 바뀜. 텍사스 프리스코: 상위 과목 5.5, 일반 5.0. 6.0 척도도 있음. 내부는 가중, 보고는 4.0 상한인 곳도 있음 | 사실 (검색 요약, [27]) |
| 주가 정하는 경우 | 텍사스: AP·IB·OnRamps·이중등록에 같은 가중. 플로리다: 2026–27학년도부터 주 공통 5.0 가중 척도 | 사실 (검색 요약, [27], [68]) |
| 졸업 우등 | 아이오와 한 학교: 졸업 우등은 비가중 척도로 정함 | 사실 (검색 요약, [27]) |
| Common App 신고 | GPA 척도를 4~20, 100 중에서 고른다. 누적 GPA를 계산하지 않거나 맞는 척도가 없으면 'none'. 가중·비가중을 둘 다 계산하면 **가중 값**을 신고 | 사실 (검색 요약, [20]) |

> 설계 함의 (추정): GPA는 **원천 자료가 아니라 계산 결과**다. (과목 결과 + 학점 + 수준 + 척도 판 + 가중 규칙 판 + 포함·제외 규칙)으로 언제든 다시 셀 수 있어야 한다. 마감 판은 계산에 쓴 규칙 판 id를 고정한다. 한 학생에게 GPA가 여러 개(비가중·가중·교과 GPA·졸업 우등용) 있을 수 있다.

| 학교 소개서(school profile) | 개설 과목, 성적 체계, 특별 프로그램, 학교 정책. 한 연구는 14개 요소를 4묶음(교육과정·성적 체계·진학 기회·학교 공동체)으로 정리. 성적 체계 묶음에 석차·GPA 분포 포함. 상담교사가 Common App 추천 시스템에 올린다. 학교 소개서와 학교 보고서는 다른 문서다 | 사실 (검색 요약, [22], [67]) |
| GPA 분포 공개 | 졸업 기수별 GPA 분포표를 내는 학교가 있다. 최고 GPA를 공개하지 않는 학교도 있다(한 학생이 드러나서) | 사실 (검색 요약, [67]) |
| 상담교사 추천서 | 학생 전반에 대한 서술. 한국 '행동특성 및 종합의견'에 가장 가깝다(5절) | 추정 |

> 설계 함의 (추정): 학교 소개서는 **학교 단위 출력 프로필**이다. 척도 판·가중 규칙 판·개설 과목 목록·졸업 요건 판·(선택) 기수별 분포 통계가 원천이다. 분포 통계는 기수 마감 판의 투영이다. 소규모 학교는 분포로 학생이 드러날 수 있어 최소 인원 가림 규칙이 필요하다.

### 5.3 전학과 기록 이관

| 항목 | 내용 | 근거 |
| --- | --- | --- |
| FERPA 예외 | 34 CFR 99.31(a)(2): 학생이 입학하려 하거나 입학 예정인 학교에 **동의 없이** 교육 기록을 보낼 수 있다. 99.34 조건을 따른다 | 사실 (검색 요약, [10]) |
| 통지 | 보내는 학교는 보호자·적격 학생의 마지막 주소로 통지하려 합리적으로 노력해야 하고, 요청하면 보낸 기록 사본을 준다. 연례 FERPA 통지에 '요청하는 학교에 기록을 보낸다'고 적었거나 본인이 이관을 시작했으면 개별 통지 의무가 없다 | 사실 (검색 요약, [10]) |
| 노숙 학생 | McKinney-Vento: 기록이 없어도, 마감을 놓쳤어도 **즉시 입학**. 예방접종·거주·출생증명·학교 기록 미비로 늦추지 못한다. 받는 학교는 이전 학교와 기록을 신속히 주고받아야 한다 | 사실 (검색 요약, [44]) |
| 위탁 학생 | ESSA: 원래 학교에 남지 않기로 '최선 이익 결정'이 나면 기록 없이도 즉시 입학, 받는 학교는 즉시 이전 학교에 기록을 요청. McKinney-Vento와 별개 조항. ESSA가 '위탁 배치 대기'를 노숙 정의에서 뺐다(예외적으로 둘 다 해당 가능) | 사실 (검색 요약, [45]) · 법 조문(ESEA §1111(g)(1)(E), McKinney-Vento §722) 원문은 **확인 필요** |
| 폐교 사립학교 | 플로리다: 문을 닫는 사립학교는 학생 기록의 영구 정보를 공립 학군에 넘겨야 한다 | 사실 (검색 요약, [57]) |

> 설계 함의 (추정): ①입학은 **기록 도착 전에** 일어날 수 있다(임시 학적·서류 미비 상태). ②이관은 '받는 곳·보낸 범위·일자'를 남기는 공개 사건이다. ③우리 플랫폼 안의 학교끼리 이관해도 **다른 학교 자료를 직접 읽게 하지 않는다**. 이관 묶음(스냅샷)을 받는 학교에 새로 만든다(지침 1의 학교 경계 유지).

### 6.2 열람권과 수정 요청권

| 항목 | 내용 | 근거 |
| --- | --- | --- |
| 열람 | 34 CFR 99.10: 요청 후 합리적 기간 안에, **45일을 넘기지 않고** 열람하게 해야 한다. 더 짧게 정한 주도 있다. 열람 요청이 걸려 있는 동안 그 기록을 없애면 안 된다 | 사실 (검색 요약, [7]) |
| 다른 학생 | 기록에 다른 학생 정보가 있으면 요청자 몫만 보여 준다(99.12) | 사실 (검색 요약, [7]) |
| 수정 요청 | 99.20: 기록이 **부정확하거나 오해를 낳거나 학생 사생활권을 침해**한다고 보면 수정을 요청할 수 있다. 학교가 거부하면 청문 기회를 줘야 하고, 합리적 기간 안에 연다. 수정하기로 하면 수정하고 서면 통지 | 사실 (검색 요약, [4]) |
| 성적은 대상 아님 | 수정 요청권으로 **성적·평가·의견·징계 같은 실질 판단을 다툴 수 없다.** 성적이 **잘못 기록된** 경우만 해당. 학교가 자발적으로 응할 수는 있다 | 사실 (검색 요약, [5], [6]) |
| 거부 후 의견서 | 청문 뒤에도 수정하지 않으면 보호자·학생이 이의 의견서를 기록에 붙일 수 있고, 학교는 기록이 있는 동안 함께 보관·공개한다(99.21) | 추정 (규정 원문 미열람, **확인 필요**) |

> 설계 함의 (추정): 수정 요청은 **정정과 다른 흐름**이다.
> - 정정(학교 내부): 원 작성자·승인자가 새 판을 만든다(2.5절).
> - FERPA 수정 요청(외부 당사자): 요청 → 결정(수정/거부) → (거부 시) 청문 → 결과 → (거부 유지 시) 이의 의견서 첨부.
> 요청을 받아들이면 결국 정정 판을 만들고 그 판이 요청 id를 가리킨다. 이의 의견서는 원 기록을 바꾸지 않는 **첨부 사건**이고, 그 기록의 발행본에 함께 나가야 한다. 45일 기한은 요청 사건의 마감일이다.

> 설계 함의 (추정): 보존은 **기록 유형별 규칙 판**(영구 / 생년월일 + n년 / 감사 후 n년)이다. '추가만 하는 원장'과 '보존 기간 뒤 파기'는 충돌한다. 파기는 행 삭제가 아니라 **파기 사건 + 내용 제거(식별 정보 지움) + 법정 영구 항목만 남김**으로 설계해야 한다. 열람 요청이 걸린 기록은 파기를 막는다(99.10). 이는 지침 4(삭제 금지)와 부딪치므로 **별도 ADR이 필요**하다(추정).

| 출석 기록 | 플로리다: 의무교육 목적의 출석 기록을 유지·작성(주법 1002.42(4), 1003.23(2)). 워싱턴: 매년 주 교육위원회 승인, 재적 보고로 출석 보고 의무(RCW 28A.195.060)를 채움(필수 여부는 페이지마다 다름). 델라웨어: 비공립학교의 연간 재적·출석(학년 범위별 ADM·ADA)을 6/1~7/31에 수집. DC: 가을 재적 자료 | 사실 (검색 요약, [57]) · 워싱턴 필수 여부는 **확인 필요** |
| 인가 — Cognia | 사립학교도 공립과 같은 인가 과정(자체 평가, 진단, 외부 평가). 최초 인가 '필수 요건' 9개를 예/아니오로 증거 제출로 확인. 학생 기록 요건을 직접 다룬 문구는 찾지 못함 | 사실 (검색 요약, [58]) · 기록 요건은 **확인 필요** |
| 인가 — NAIS | '좋은 실무 원칙'(PGP): 업무 책임자는 개인·기관 기록의 비밀과 사생활권을 지킨다, 재정 지원 신청·기록·결정의 비밀 보장, 이사회 기록 유지. 회원 자격은 PGP 정신 준수가 조건. 학생 기록 전용 정책은 아님 | 사실 (검색 요약, [59]) |

| 해외 미국식 학교 | 미국 교육과정·학점·GPA·성적증명서 형식을 쓰고 CEEB 코드는 ETS Code Control로 받는다. 개인정보는 현지 법(예: 태국 PDPA, 한국 개인정보보호법)을 따르고 FERPA는 대개 적용되지 않는다 | CEEB: 사실 (검색 요약, [25]). 나머지는 추정 |

> 설계 함의 (추정): 사립·대안학교에 주가 요구하는 최소치는 대개 **재적·출석**이다. 인가 기관은 **믿을 수 있는 성적증명서**(일관된 척도, 설명표, 발급 통제, 기록 보안)를 본다. 그러니 우리 학교가 미국 대학에 학생을 보내려면 '척도 판 + 과목 설명 + 학교 소개서 + 발행 통제 + 공개 기록'이 갖춰져야 한다. 태국의 미국식 학교는 '미국 출력 프로필 + 태국 개인정보 규칙'의 조합이 된다.

## 10. 토대에 주는 시사점

모두 **추정**(조사자 판단)이다. ADR 0025의 층 이름(L1~L6, E1~E6)을 따랐다.

### 10.1 핵심에 1급으로 둘 것 (KR + US 공통 토대)

1. **학기 나무에 '학점 학기'와 '성적 기간'을 다른 마디 종류로** (L1). 결과 행은 어느 마디에 대한 결과인지 가리킨다. 중간 성적·학기 성적·최종 성적이 같은 수강에 여러 개 붙는다.
2. **수업일 달력 + 학적 기간 행**(L1·L2). 만성 결석(재적 일수 분모), ADA/ADM, 한국 수업일수 2/3이 모두 여기에 달려 있다. 입학이 기록 도착보다 먼저 올 수 있다(McKinney-Vento·위탁).
3. **외부 식별자 행**(L2): 주 학생 ID, 학군 ID, 한국 NEIS 번호 등은 `external_identifiers`(체계 + 부여 기관 + 기간). 학교 쪽 CEEB 코드·주 학교 코드도 같은 꼴로 학교에 붙인다.
4. **수강 시도 = 사건, 시도 결과 상태**(L3·L4): 이수·낙제·미완료(기한 포함)·철회. 재수강·보충은 원 시도를 가리키는 새 시도. 시도 학점·취득 학점은 시도에 붙는다.
5. **결과의 대상 축**(L4): 과목 총괄 / 성취기준(역량 항목) / 행동·습관 항목. `result_kind`와 함께 둔다. 서술(작성자 역할: 교과 교사·담임·상담교사)도 같은 원장.
6. **교시 출결 사건이 원천, 하루 출결은 계산**(L4). 출결 코드는 '종류 × 인정 여부·사유' 두 축.
7. **프로그램 참여 기간 행 + 민감 등급**(L2 확장): 별도 표, 별도 RLS, 읽기 기록부(IDEA). 일반 성적·출결 경로에서 조인되지 않게.
8. **정정 판과 당사자 요청을 분리**(L6): 정정 판(사유 코드·원 작성자 참여·승인 단계·통지·감사) / 수정 요청 사건(기한·결정·청문·이의 의견서 첨부). 요청을 받아들이면 정정 판이 요청 id를 가리킨다.
9. **공개(disclosure) 사건**(L6): 발행본 발급, 전학 이관, 외부 제출마다 받는 곳·근거·범위·일자. FERPA 99.32와 한국 발급 대장을 한 경로로.
10. **디렉터리 공개 거부 표시**(L2): 사람 × 학교 × 기간. 졸업 뒤에도 유지. 학교 누리집 공개와 에이전트 공개 작업이 검사한다.
11. **마감 판 종류 셋**(L6): ①수업(성적 기간·학기) 마감, ②학년도 기록 마감, ③**지정일 보고 스냅샷**. 모두 적용 규칙·척도·코드 판 id를 고정한다.
12. **보존·파기 정책**(L6): 기록 유형별 보존 규칙과 '파기 사건'. 추가만 하는 원장과 파기의 충돌은 별도 ADR로 푼다.

### 10.2 코드 목록·규칙 판으로 둘 것 (L5, 학교·국가별 값)

### 10.4 남는 질문 (결정·확인 필요)

1. 보존 기간이 끝난 기록의 **파기와 추가만 하는 원장**의 관계(ADR 필요).
2. 13세 미만 학생 계정·보호자 계정을 열 때 COPPA 학교 승인과 FERPA 열람권을 어떻게 화면·권한으로 구현할지(지침 9, ADR 필요).
3. FERPA 비대상 사립학교에도 열람 45일·수정 요청 흐름을 기본으로 켤지(추천: 켬, 되돌릴 수 있는 기본값).
4. 프로그램 참여(특수교육·급식 등) 자료를 첫 단계에 넣을지, 민감 확장으로 미룰지.
5. 원문 대조가 필요한 항목: 34 CFR 99.21 이의 의견서, WAC 392-415-070 (2)항 목록, COMAR 45수업일 조항, NCES 2017 출결 코드표, ECS 교과별 졸업 학점 표, Ed-Fi 채택 주 목록.
