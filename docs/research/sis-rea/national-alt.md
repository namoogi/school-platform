- **항목별 입력 주체가 정해져 있다.** 정정 증빙도 "기재요령에 명시된 항목별 입력 주체가 작성한 것"인지로 판단한다. 사실 (K9 계열 Q&A 발췌)
- **학년도 입력이 끝나면 학교생활기록부Ⅱ 출력물과 각종 보조부를 3회 이상 대조·확인한다.** 사실 (2026 기재요령 발췌, K42 검색 요약)
- **보존: 학교생활기록부Ⅰ·Ⅱ는 「공공기록물 관리에 관한 법률 시행령」에 따라 준영구 보존한다.** 사실 (2024 고등 기재요령 발췌, K42). 학교폭력 조치 기록은 졸업 후 최대 4년 보존으로 늘었다는 2023 보도가 있다 (확인 필요)
- 초등학교 교과는 등급 없이 서술 위주, 중학교는 A–E 성취도와 원점수·과목평균(표준편차): 추정 (원문 확인 필요)

| 척도 | 3단계(ดี/พอใช้/ควรส่งเสริม) | 추정 |
| 국가 점검 | สพฐ.이 유아 과정 수료자 발달 평가를 실시하고 기록 안내서·성장·위생 습관 기록 양식을 냄 | 사실 (T18, T19) |

> 설계 함의: 유아는 점수·성적이 아닌 **영역·기준별 관찰 판정 + 서술 + 성장 측정(키·몸무게)**이다. 같은 "판정(judgment)" 구조에 척도만 다르게 둔다.

2. **증거물(artefact)**: 파일·링크·발표 기록. 여러 수업·프로젝트·역량에 연결(다대다).
3. **판정(judgment)**: 누가(역할), 무엇을(역량/과목), 어떤 척도로(수준·P/F·서술 전용), 어떤 증거로, 언제. credit은 판정의 결과.
4. **서술(narrative)**: 작성자 역할(교사·지도교사·멘토·학생 자기평가), 대상(과목·학기·종합), 글자 한도.
5. **확인·서명(sign-off)**: 멘토·위원회·발표 심사단·학교 인증. 여러 사람이 순서대로.
6. **학습 계획·제안(proposal)**: 학생이 설계한 과목·프로젝트의 제안 → 승인 → 개설로 이어지는 상태 기계.
7. **발표 행사(exhibition/POL)**: 일시, 심사단(사람 id), 피드백, 결과 판정.

### D2. 핵심 모델에서 1급(first-class)으로 둘 것

ADR 0004 안 B의 표(사람·학적·학기·수업·수강·평가·마감 판·발행)에 아래를 더하거나 이름을 맞춘다. 표 이름은 가칭이다.

1. **학적 사건 `enrollment_events`**: 입학·전입·전출·유예·정원외·복학·진급·유급·졸업·수료. 사건마다 일자, 사유 코드, 근거 문서. 학년도별 학적 상태는 사건에서 유도한다. (한국 제7조 누가 기록, 태국 REGIS 진급·졸업 모두 사건형.)
2. **식별자 `person_identifiers`**: 종류(주민등록번호·태국 13자리 ID·여권·학교 학번), 민감도, 암호화 저장, 선택 입력. 주민등록번호 같은 고유식별정보는 기본 저장하지 않고 필요할 때만(추정: 개인정보보호법상 처리 제한, 법률 검토 필요). 지침 7(이름·메일로 연결 금지)과 같은 맥락에서 **이 값으로 사람을 연결하지 않는다.**
3. **출결 기록 `attendance_marks`**: 일·교시(세션) 단위 원자료. 상태는 학교 코드 집합(판)에서 고르고, 국가 분류(한국 종류×사유, 태국 시간 산정)는 **출력층 매핑**으로 계산한다. 수업(offering) 연결은 선택. 출석인정·증빙 첨부. 한국 '결과'와 태국 과목 시간 80%가 모두 교시·과목 단위가 필요하므로 일 단위만으로는 부족하다.
4. **수업 개설과 기원 `course_offerings.origin`**: 학교 개설 / 학생 설계 / 프로젝트 / 인턴십. 학생 설계는 **`course_proposals`**(제안자 person, 계획서 판, 후원 교사, 승인 단계, 결정) → 승인되면 개설. 학생이 운영자(facilitator)가 될 수 있게 `offering_staff`의 역할에 학생·외부 멘토를 허용한다(지침 9 학생 역할 RLS 점검이 선행).
5. **역량·기준 틀 `frameworks → framework_items`**(판): 학교 정의 역량(예: 자율·책임), 국가 틀(한국 성취기준, 태국 ตัวชี้วัด·คุณลักษณะ 8·유아 기준)을 같은 구조로. 수업은 목표 항목을, 판정은 대상 항목을 id로 가리킨다.
6. **척도 `scales → scale_levels`**(판): 백분율→A–E 경계, 0–4 8단계, ดีเยี่ยม–ไม่ผ่าน 4단계, 유아 3단계, P/F, 역량 수준. 특수 상태(ร, มส, 미이수, 보충 이수 상한 E)는 **값이 아닌 상태 플래그**로 둔다.
7. **판정 `judgments`**: (대상 person, 수업 또는 틀 항목, 척도, 값, 원점수·성취율 선택, 판정자 역할, 증거 연결, 일자). 기존 `assessment_results`를 이 구조로 일반화하거나, assessment_results는 점수 원장·judgments는 결론으로 나눈다(설계 선택: ADR 필요).
8. **증거물 `artefacts`**: 파일·링크·발표 기록. `artefact_links`로 수업·프로젝트·틀 항목·판정에 다대다. 정정 증빙(한국 "교육활동 결과물")도 같은 표를 쓴다.
9. **서술 `narratives`**: 종류(과목 세특·창체 영역 특기·종합의견·분기 서술·자기평가·멘토 의견), 작성자 역할, 대상 범위, 판. **글자 한도는 출력 규칙 판**이 검사한다(같은 서술이 한국 서식 500자, 학교 자체 서식 무제한일 수 있다).
10. **확인·서명 `attestations`**: (대상 판, 서명자 person, 역할, 단계, 결정, 일자). 멘토 확인, 발표 심사, 학업성적관리위원회 심의, 정정대장 결재, 교장 결재를 한 경로로. (지침의 "권한·쓰기 경로는 역할마다 하나" 원칙과 맞춤.)
11. **마감 판과 정정 판**: 이미 ADR 0004 B의 `offering_closures`가 있다. 범위를 **수업 성적만이 아니라 학년도 학생 기록 전체**(출결 합계·서술·창체)로 넓힌 `record_closures(person, 학년도, 판)`가 필요하다. 정정 판 필수 필드: 이전 판, 사유, 증빙(artefact), 심의(attestation), 결재(attestation), 항목 종류별 승인 단계 생략 규칙(한국 학생정보 심의 생략).

### D3. 학교 정의 확장으로 둘 것

- 학교별 출결 코드와 학교장 세부 기준(지각 인정 시간, 겹침 처리 규칙).
- 창체·동아리·봉사·수상·자격·독서처럼 **국가마다·해마다 바뀌는 기록 종류** → ADR 0004의 `record_items`(종류 표 + 형식 표) 방식. 종류마다 필드 스키마·입력 주체 역할·글자 한도·대입 전송 여부를 판으로.
- 학교 역량 틀, 발표 행사 형식, 인턴십 기관(외부 기관·멘토는 사람 id로).
- 학업성적관리규정 수치(성취도 경계, 수행/지필 비율, 태국 ระหว่างเรียน:ปลายภาค 비율 — 비율 존재는 추정).
- 기독교 대안학교 특유 기록(예배·공동체 생활·섬김 활동 등)은 record_items의 학교 종류로. (구체 항목은 학교 면담 필요: 확인 필요.)

### D4. 하나의 핵심에서 학생부·ปพ.를 함께 내는 방법: 출력 규칙 층

```
핵심 원장 (사람·학적 사건·출결 원자료·수업·판정·서술·증거·서명)
   │  마감 판(record_closures / offering_closures) ← 불변
   ▼
출력 규칙 판 output_profiles (예: KR-학생부-고-2026, KR-대안-자체학생부, KR-교육과정편제표,
   TH-ปพ.1:ป, TH-ปพ.5, TH-ปพ.6, TH-ECE-통지, TH-REGIS-명단, MASTERY-형식)
   ├─ 필드 매핑: 출력 칸 → 마감 판 질의 (id 기준)
   ├─ 코드 변환: 학교 출결 코드 → (결석|지각|조퇴|결과)×(질병|미인정|기타), 출석인정 / 과목 시간 %
   ├─ 척도 변환: 판정 → A–E·석차등급·분포비율 / 0–4·ร·มส / 4단계
   ├─ 검사: 글자 한도, 필수 칸, 연도별 금지 기재(예: 2026 출석인정 사유 공란)
   └─ 가리기: 대입 미전송 항목, 블라인드 대상, 민감 식별자
   ▼
발행본 published_documents (스냅샷: 마감 판 id + 출력 규칙 판 id + 렌더 결과) ← 지침 5
```

원칙:

1. **매핑은 출력 쪽에만 둔다.** 핵심 원장에 "학생부용 열"을 만들지 않는다. 그래야 태국·한국·자체 서식이 서로를 오염시키지 않는다.
2. **출력 규칙 판은 학년도·학교급·국가별 판**이다. 기재요령이 바뀌면 새 판을 추가하고, 과거 발행본은 과거 판을 가리킨 채 남는다.
3. **변환이 정보를 잃으면 질문을 연다**(지침 6). 예: 학교 출결 코드 '현장학습'이 한국 매핑에서 출석인정인지 기타결석인지 정해지지 않았으면 발행을 막고 질문을 연다.
4. **통계는 마감 판에서만.** 과목평균·표준편차·수강자수·분포비율·석차등급은 수업 id 모집단의 마감 판 스냅샷 값(지침 8). 태국 ปพ.5의 반 성적표도 같은 경로.
5. **공식 양식과 학교 사본을 구분한다.** NEIS 학생부·태국 ปพ.1은 국가 시스템·지정 인쇄 양식이 원본이다. 우리 출력은 기본적으로 '입력용 보조부/인쇄용 자료'로 표시하고, 미인가 학교 자체 학생부처럼 우리가 원본인 경우만 '학교 발행본'으로 표시한다(법적 지위는 확인 필요).

### D6. 우선순위 제안

1. **먼저** (토대): 학적 사건, 출결 원자료 + 학교 코드 집합, 척도 판, 판정·서술·증거·서명, 학년도 기록 마감 판. 지침 4·8·10의 판 규칙을 이 표들에도 적용.
2. **다음**: 출력 규칙 층과 첫 두 판 — `KR-대안-자체학생부`(드리미 예시학교)와 `TH-ปพ.6`(Rungarun 예시학교 통지표). 둘 다 학교 발행본이라 법적 위험이 낮다(추정).
3. **그다음**: `KR-교육과정편제표`, `TH-ปพ.1:ป 인쇄용 자료`, `TH-REGIS 명단 내보내기`, 학생 설계 과목 제안 흐름(학생 역할 RLS 점검 선행, 지침 9).
4. **ADR 필요**: (a) 판정 일반화(assessment_results와 judgments 관계), (b) 학년도 기록 마감 판 범위, (c) 출력 규칙 층과 published_documents 스냅샷 관계, (d) 민감 식별자 저장 정책.

### D7. 남은 확인 항목

- 2026 고등학교 기재요령 원문: 항목 목차(수상·자격·독서 존치 여부), 과목 세특·창체·행특 글자 수, 5등급 4·5등급 경계, 소인수 기준(5명/13명), 학교폭력 항목 보존기간.
- 대안교육기관법·시행령에 학습 기록 작성·보존·폐쇄 시 이관 조항이 있는지. 관할 교육청 등록 가이드라인 본문(K30).
- 미인가 대안학교 실제 기록 도구 현황: 문헌 근거가 없어 **현장 면담** 필요(대안교육연대 등).
- 태국: ปพ.8/ปพ.9 이름, ปพ.1 정정·서명 규칙, 사립학교의 ปพ.3 제출처, DMC 기준일(사립은 REGIS가 맞는지), 유아 12개 기준·3단계 척도, 새 CBE 교육과정의 평가·성적 체계, REGIS 가져오기 형식.
