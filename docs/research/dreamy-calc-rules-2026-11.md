## 1. 과목 점수
- **[잼] 총점**: Σ(점수 ÷ 만점 × 비율), 소수 2자리 반올림
  - 점수가 하나도 없으면 null이다. 0점과 '안 넣음'을 가른다.
  - 만점이 0 이하인 영역은 합에서 빠지지만 '점수 있음'으로는 센다. 그 비율만큼 총점이 낮아진다.
  - 결측은 건너뛸 뿐 가중치를 재배분하지 않는다. 미제출이 있으면 총점이 낮아진다.
- **[잼] 원점수**: 총점을 정수로 반올림한다. 성취도는 이 정수를 본다. 즉 반올림이 두 번이고, 순서는 영역 합 → 소수 2자리 → 정수 → 성취도다.
- **[잼] 가중치 합**: |합 − 100| ≤ 0.001을 재기만 하고 막지는 않는다. 정규화하지 않는다.

## 2. 성취도 (절대평가 5단계)
- **[잼]** 90 이상 A, 80 이상 B, 70 이상 C, 60 이상 D, 그 밖 E. 입력은 정수 원점수다.
- **경계 [추론]**: 총점 89.5 → 원점수 90 → A. 총점 79.995 → 80.00 → 80 → B.
- 화면 칸 꼴: `A(54)`·`P` (성취도 + 수강자 수)

## 3. 통과/미통과 (포털 정정 2회 반영, `reflect.ts` 210~223)
- **[잼] 학생 판정(수동 값)**: 따로 있는 칸이 아니라 이미 적힌 성취도다. 출처가 둘이고 순서가 있다.
  1. 이번 평가 입력 행(수업 × 학생)의 성취도
  2. 입력 행이 **아예 없을 때만** 이미 저장된 학생부 행의 성취도
  - 입력 행이 있는데 성취도가 비어 있으면 2로 내려가지 않는다. 입력 행이 생기는 순간 계승이 끊긴다(전환기 비파괴 장치).
- **[잼] 되먹임**: 한 번 'P'로 저장된 행은 입력 행이 없는 학기에 2를 타고 다시 'P'로 읽힌다. 아무도 다시 정하지 않아도 P/F가 유지된다. 즉 입력과 결과가 같은 칸이다.
- **[잼] P/F 여부**: 과목 P/F이거나, 학생 판정이 'P'·'F'면 P/F다. A~E 과목 안에 P 학생이 섞이는 것이 정상이다.
- **[잼] P/F일 때 비우는 것**: 원점수(중등은 과목평균도). **남는 것**: 성취도·세특.
- **[잼] 과목만 P/F이고 학생 판정이 없을 때**: 성취도는 A~E로 원점수 잣대를 쓰고, 원점수만 빈칸이다. P로 강제하는 코드는 없다.
- **[미확인]** P/F 판정에 출석·산출물이 들어가는 코드

## 4. 이수·졸업
- **학점 [잼]**
  - 한 과목·블럭 4학점. 선택 A·B·C 3블럭은 12학점.
  - 제2외국어 D 블럭 2학점. 자율은 3학년만.
- **졸업 기준 [적힌값]**: 선택 68 · 창의 30 · 주요(국·영·수) 8 · 트랙 12학점, 평균 70, 출석 80%, 6학기
- **학년 판정 [잼]**: 평균 ≥ 70, 출석 ≥ 80. 값마다 참·거짓·null(자료 없음) 세 가지다.
  - **사고**: null을 통과로 접으면 미달이 통과가 된다.

## 5. 통계
- **[잼]** 평균·모표준편차(n으로 나눔), 소수 1자리. 빈 모집단은 null(0으로 세지 않음).
- **모집단 열쇠**: 코드는 `과목명|학년|학기`이고 머리말은 '과목명·학기·수업연도'라 어긋난다(포털 내부 문제).
  - 플랫폼은 수업 id를 쓰므로 해당 없다.
- **집계 참여**: 교환학생·테스터·제외는 모집단에서만 빠지고 본인 성적은 남는다(별개 축).
- **박아 둔 값**: 박힌 평균·표준편차를 먼저 쓰고, 없으면 계산한다. 박은 이유도 칸에 둔다.
- **[미확인]** 석차등급·동점. 드리미는 쓰지 않는 것으로 보인다.

## 6. 학교급·기수·트랙
- **학년**: 입학연도에서 파생한다. 과거 기록은 그때 값을 박제한다.
- **진급·졸업 판정은 고등 기준**: 중등은 일부러 뺀 곳과 빠뜨린 곳이 섞여 있다.
- **[잼] 중등만**: '원점수/과목평균'을 함께 표기한다. P/F면 과목평균도 비운다. 고등 행에는 과목평균 칸을 쓰지 않는다.
- **사고**: 기수 정규식 `\d+기`가 '중1기'를 놓쳤다.

## 7. 사고에서 나온 규칙 (건드리지 않을 것)
1. 표기명을 바꾸기 전에 반 전체의 평균·표준편차를 박는다. 사람이 지시할 때만 하고, 자동으로 굳히지 않는다.
2. P/F는 원점수를 비운다.
3. 1~4기 학생부는 스냅샷이 그려진다. 표와 스냅샷을 같이 고친다.
4. 성취도 빈칸이 정규식 잣대를 조용히 지나갔다. 밴드 검사는 빈 값을 명시적으로 다룬다.
5. 같은 수업의 같은 세특 문장은 결함이 아니다.
6. 계산은 순수 함수로 떼어 경계값을 잰다.

## 8. 계산식 판에 반영한 것 (ADR 0040 초안)
| 드리미 요구 | 계산식 판 |
| --- | --- |
| 두 번 반올림과 순서, 밴드가 보는 값 | `round`(digits·mode)를 단계마다 `lets`로 적고, `band`에 넣을 값을 식으로 지정 |
| null은 1급 값 | 3값 논리: 비교·and·or·if가 null을 지킨다. 접으려면 `coalesce` |
| 가중치 합 비정규화 | `weighted_score` `normalize: false` = Σ 점수÷만점×비율 |
| 만점 0 이하 영역 | 합에서 빼고 '점수 있음'으로 셈 |
| P/F 출처(과목 속성·학생 판정), 학생 판정 = 입력 행 성취도 → 입력 행이 없을 때만 이전 기록 | `course.pass_fail` + `entry.exists`·`entry.level` + `prior.level` |
| 되먹임(P가 스스로 유지) | 플랫폼은 입력(`prior.level`)과 결과(마감 판)를 다른 칸으로 두고, 계승을 식에 드러나게 적는다(견본의 `manual`) |
| P/F면 원점수만 비우고 성취도(P·F)는 남김 | 견본 `rounded_twice_bands`의 `is_pf`·`manual_pf` |
| 중등은 과목평균도 비움 | 표기(출력 프로필) 몫, 다음 단계 |
| 집계 참여 ≠ 성적 보유 | 수업 마감 판 `closure_results.in_stats`(이미 별개 축) |
| 박은 값 우선 + 이유 | 마감 판 스냅샷 + 정정 판 reason |
| 학년 단위 판정(평균 70·출석 80) | 다음 단계: '학년도 범위' 계산식(입력 = 학년도 기록) |
| 학교급·트랙별로 규칙이 빠짐 | 다음 단계: 계산식을 수업 갈래·학교급에 묶는 연결 |
