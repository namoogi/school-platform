# 0040. 계산식 판: 학교마다 이수 기준·성적 산출을 선언형 식으로

- 상태: 채택(초안 단계 — 마감 연결·화면은 다음 차시)
- 날짜: 2026-11-27
- 제안: Claude(관제)
- 결정: 사용자(2026-11-27)
  - "대안학교는 각 학교별로 교육과정이 조금씩 다 다르고 성적을 산출하는 방식도 다 다르다."
  - "계산은 드리미포털에 물어봐" / "답 오기 전에 일반형으로 계산식 판 초안 시작해"
- 관련: ADR 0025(학사 토대 F2 성적 정책·마감 판), 0035(공용 기본 + 설정값 맞춤), 0039(서버 오류 이름표), `docs/research/dreamy-calc-rules-2026-11.md`(드리미 규칙)

## 결정
1. **계산식 판** `calc_rules`
   - 칸: (학교, 이름, 판) → 제목·식(JSON)·이유
   - 학교 관리자만 명령 함수 `app.save_calc_rule`로 쓴다(`base_version` → 409). 판은 고치지 않는다.
   - 학교 구성원만 자기 학교 판을 읽는다.
2. **식은 데이터다. 코드를 실행하지 않는다.**
   - 서버는 `src/lib/calc/expr.ts`의 연산만 실행한다.
     - 산술·최소·최대·합·평균·비교
     - and·or·not·if·coalesce
     - round(자리·방식 5가지)
     - weighted_score(정규화 선택), band(성취도 구간)
     - count_levels(역량 도달 개수), missing
   - 저장 전에 `checkSpec`이 검사한다: 연산·변수 허용 목록, 개수, 깊이 24·마디 400, 중간값 순서, 밴드 하한 순서.
3. **입력**(학생 한 명 × 수업 하나)
   - 평가 항목 점수·가중치·만점·제출 여부
   - 출석 비율, 역량 수준 목록, 학점
   - 과목 P/F 속성, 학생 개별 판정(수동 값)
4. **자료 없음은 1급 값**(드리미 사고에서 나온 규칙)
   - null은 0점·미달과 다르다. 비교·and·or·if가 null을 지킨다.
   - 자료 없음을 통과나 미달로 접으려면 식에 `coalesce`로 직접 적는다.
5. **견본 5가지**: 가중 평균, 역량 도달 개수, 프로젝트 통과/미통과, 동료·교사 혼합, 드리미 방식(`rounded_twice_bands`)
   - 학교가 골라 고쳐 쓴다.
   - 드리미 방식은 포털 규칙을 경계값까지 재현한다. 시험: `tests/calc-expr.test.ts`
     - 두 번 반올림, 비정규화
     - P/F 출처 둘
     - P/F면 원점수만 비움
6. **미리 계산**: 저장하지 않고 합성 견본 입력으로 결과를 돌려준다(`POST /api/calc-rules {action:'preview'}`).
7. **오류**는 ADR 0039대로 이름표로 낸다(`err.calcSpecInvalid`, `db.calcRule*`).

## 다음 단계 (이 ADR 범위, 아직 안 함)
- **마감 연결**: 수업 갈래·학교급마다 어느 계산식을 쓸지 묶고, 수업 마감 판에 계산식 판 번호와 결과를 남긴다. 드리미처럼 중등에는 졸업 판정이 없는 경우도 담는다.
- **학년도 범위 계산식**: 학년 단위 판정(평균 70·출석 80, 세 값). 입력은 학년도 기록이다.
- **화면**: 성적 → 계산식(견본 고르기·식 편집·미리 계산·판 이력). 처음부터 다국어(ADR 0037).
- **학교 AI 쓰기**: 작업 토큰 종류 `package`가 계산식 판을 쓰게 한다. 사람이 확정한다.
- **검사 문구 이름표화**: 미리 계산의 문제 목록을 이름표로 바꾼다.

## 고려한 안
| 안 | 판단 |
| --- | --- |
| 학교 AI가 SQL·JS 함수를 올림 | 기각: 공용 DB에서 코드 실행은 학교 경계·보안을 깬다(ADR 0035) |
| 성적 정책 판(F2)에 칸 몇 개 더하기 | 기각: 대안학교 규칙(역량 도달, P/F 출처 둘, 세 값 판정)을 칸으로 다 담을 수 없다 |
| **선언형 식 + 허용 연산(채택)** | 학교마다 자유롭게 쓰되 서버가 검사·실행. 경계값을 시험으로 고정 |
