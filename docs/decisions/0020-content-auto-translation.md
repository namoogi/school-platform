# 0020. Codex 구독으로 콘텐츠를 정기 번역하고 시안 저장

- 상태: 채택(2026-11-24 사용자 지시: 별도 번역 API 없이 현재 구독으로 처리)
- 제안/결정: 사용자, 구현 Codex
- 관계: ADR 0013(학교 토큰·새 판), 0016(공개 권한)

## 결정

학교 서버에 모델 API를 연결하지 않는다. 이 대화에 연결한 Codex 예약 작업이 매시간 학교의 새 콘텐츠와 수정 사항을 읽고, 현재 구독 세션에서 번역한 후 학교 콘텐츠 API로 새 시안을 저장한다. 학교 API는 읽기·저장 통로이며 외부 번역 API가 아니다.

학교 서버에서 등록 즉시 실행하는 방식이 아니라 Mac에서 주기적으로 확인하는 방식이다. Mac과 앱이 실행 중이고, 네트워크·로그인·구독 사용량·학교 토큰이 유효해야 한다. 빠진 실행은 다음 확인 때 최신 판을 읽어 처리한다. 별도 API 결제나 자동 크레딧 구매를 설정하지 않는다.

## 구현

- `scripts/agent-translate.py scan`: 토큰 학교를 검증하고 허용된 항목 종류만 읽는다. 제목·본문·요약·캡션 등 누락되거나 갱신이 필요한 칸을 작업 파일로 만든다.
- Codex가 작업 파일의 문맥을 읽고 한국어·태국어·영어를 직접 번역한다. 스크립트에는 모델 호출이 없다.
- `apply`: 최신 판을 다시 읽고 허용된 번역 칸만 바꾼다. `base_version`으로 동시 수정 충돌을 거부하고 저장 결과를 다시 확인한다.
- 로컬 상태 파일에 마지막 판·원문·자동 번역 출처를 보관한다. 같은 내용을 반복 저장하지 않으며, 항목마다 저장 직후 상태를 기록한다.
- 명령 실행은 로컬 파일 잠금으로 겹치지 않는다. 번역 중 다른 실행/사람이 새 판을 만들면 적용 단계에서 다시 확인한다.

## 원문과 수동 번역 보존

누락된 번역만 기본 생성한다. 이 작업이 만든 번역은 원문 변경 시 갱신하되, 그 사이 사람이 번역을 고쳤으면 보존한다. 기존에 있던 번역은 수동 검토본으로 취급하며 자동으로 덮지 않는다. 원문만 바뀌고 수동 번역이 그대로라면 검토 대상으로 남긴다.

원문 언어는 채워진 비자동 번역 칸에서 고른다. 여러 언어가 이미 존재하면 한국어·태국어·영어 순서를 사용한다. 혼합 원문이나 구조 이동으로 대응이 불확실하면 Codex가 문맥을 확인하고 자동 갱신 대신 검토 대상으로 남긴다.

URL·자산·블록 구조·숨긴 내용은 번역하지 않는다. 이미지 안 글자와 PDF 내부 현지화는 별도 작업이다. 원문·그림·PDF·기존 판을 삭제하거나 덮어쓰지 않는다.

## 권한과 공개

현재 연결된 룽아룬숙사 토큰은 `story`와 읽기·올리기·편집·생성·보관 권한만 가진다. 따라서 처음 적용은 성품 동화다. 다른 종류나 다른 학교를 읽기 위해 권한을 우회하지 않는다.

자동 작업은 번역 시안 저장까지 한다. `publish` 권한이 없으므로 공개 요청을 반복하거나 관리자의 로그인으로 우회하지 않는다. 서버의 공개 판/시안 구분을 유지한다. 향후 공개 권한이 생겨도 최신 시안이 공개 원문과 다른 경우에는 함께 공개하지 않으며, 사용자가 지정한 공개 대상만 별도로 처리한다.

토큰은 실행할 때 환경 변수 `SCHOOL_AGENT_TOKEN`에만 넣고 헤더로 사용한다. 로컬 키체인에서 읽는 실행 래퍼에는 토큰 값이 없다. 작업·상태 파일은 저장소 밖에 두고 커밋하지 않는다.

## 검증과 운영

- `python3 -m unittest discover -s tests -p 'agent_translation_test.py'`
- 검증 항목: 누락 칸만 처리, URL/숨긴 내용 제외, 원문 불변, 수동 번역 보호, 태국어 원문 유지, 임의 필드 변경 거부, 다른 학교 거부, 새 판 충돌 때 POST 금지.
- 운영 확인은 읽기 전용 `scan`으로 시작한다. 필요한 번역이 없으면 새 판을 만들지 않는다.
- 실패 항목은 다음 실행에서 다시 읽는다. 인증 실패·권한 부족은 사용자에게 알리며 토큰을 재발급하거나 권한을 넓히지 않는다.
- 반복 실행 결과가 이전과 같으면 조용히 끝내고, 새 번역 저장·새 검토 항목·새 장애가 있을 때만 알린다.
- 자동화를 끄면 반복 작업만 멈춘다. 기존 시안·공개 판과 파일은 그대로 남는다.

## 검토한 다른 안

| 안 | 판단 |
| --- | --- |
| 서버 번역 API + DB 대기열 | 사용자가 별도 API를 원하지 않아 도입하지 않음 |
| 대화할 때마다 수동 번역 | 가능하지만 새 콘텐츠를 정기적으로 처리하지 못함 |
| Codex 구독 예약 작업 | 채택. 사용 중인 로그인과 학교 토큰으로 정기 처리, 로컬 실행 조건과 구독 한도 적용 |
