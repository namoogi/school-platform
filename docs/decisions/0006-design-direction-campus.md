# 0006. 디자인 방향: 학사 업무형 기본 틀 + 3단 작업함 세부 화면

- 상태: 채택
- 날짜: 2026-11-23
- 제안: Claude (24차 원형 8종 비교)
- 검토: 사용자
- 결정: 사용자 (2026-11-23) — "학사업무형을 기본으로, 세부 분리가 필요하면 3단 등의 작업함 형식"

## 배경
18차 디자인 기반(ADR 0003)이 투박하다는 의견에 따라 24차에서 탐색·레이아웃·서체·밀도·상호작용이 다른 원형 8종을 같은 합성 자료로 비교했다([조사](../research/dashboard-rea-2026-11.md), [24차](../rounds/round-24.md)).

## 고려한 안
| 안 | 내용 | 장점 | 단점·위험 |
| --- | --- | --- | --- |
| 1 학사 업무형 | 아이콘 레일 + 상단 막대 + 업무 카드 + 할 일 열, 본문 16px | 교사·학교 관리자가 매일 여는 화면에 맞음, 학습 부담 낮음 | 표가 많은 화면은 길어짐 |
| 8 3단 작업함형 | 함 → 목록 → 상세, 근거 옆에서 결정 | 자료 → 질문 → 확정 흐름(핵심 업무)에 맞음 | 그 밖의 화면에는 맞지 않음 |
| 2·3·4·5·6·7 | 명령·목록 / 런치패드 / 분석 / 문서 / 공공 / 그리드 | 각자 강점 | 사용자가 기본 틀로 고르지 않음. 필요하면 화면 유형으로 다시 검토 |

## 결정
- **기본 틀 = 학사 업무형.** 왼쪽 아이콘 레일(88px, 아이콘 + 짧은 이름, 묶음은 가는 선)과 상단 막대(64px, 학교 전환 · 확인 대기 알림 · 계정)를 쓴다. 홈은 업무 카드 격자와 오른쪽 할 일 · 최근 기록 열로 만든다.
- **세부 처리 = 3단 작업함.** 목록과 상세를 오가며 하나씩 처리하는 화면(첫 적용: 관리자 확인)에 쓴다. 함 → 목록 → 상세 순서이고, 선택 상태는 주소(`?box=&id=`)에 담는다. J/K로 이동한다.
- **토큰:**
  - 색: 따뜻한 회색(stone)과 청록(teal, 주 동작·링크·선택), 레일은 짙은 슬레이트.
  - 서체: Pretendard, 본문 16/25, 제목 32/28/22/18.
  - 밀도: 행 48 / 컨트롤 40px.
  - 반경: 6 / 8 / 12px.
  - 의미 토큰 구조(ADR 0003)는 유지하고 원시 값만 바꿨다.
- 다시 볼 조건: 성적·명단처럼 행이 많은 화면을 만들 때 7번 데이터 그리드형을 해당 화면 유형으로 추가 검토한다. 전체 관리자 통계는 4번 분석형을 검토한다.
