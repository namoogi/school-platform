# 0013. 학교별 AI 작업 공간과 관제 서브 세션의 병행

- 상태: 채택(방향·1단계) · 제안(학교별 코드 개발)
- 날짜: 2026-11-23
- 제안: Claude(관제 세션)
- 검토: (PR 링크)
- 결정: 사용자 (2026-11-23)

## 배경
사용자 지시(2026-11-23): "각 학교별로 본인들의 홈페이지나 시스템을 개선하기 위한 Codex·Claude 구독 계정을 붙이는 기능을 만들자. 학교 플랫폼 전체(관제)에서도 서브 세션을 생성해서 운영하는 방식도 필요하고, 병행이 가능하도록."
ADR 0011(학교 자율 운영)의 3단계 '학교별 생성형 개발'을 구체화한다. 첫 사례는 룽아룬숙사 동화를 Codex로 만드는 일이다(ADR 0012, 외부 작업 토큰).

## 고려한 안
| 안 | 내용 | 장점 | 단점·위험 | 비용 |
| --- | --- | --- | --- | --- |
| A. 학교 에이전트 + 범위 토큰 (채택) | 학교가 **자기 구독**으로 Claude Code·Codex를 **자기 앱**에서 돌리고, 플랫폼은 학교 범위 작업 토큰·학교 저장소 연결·에이전트 안내를 준다 | 플랫폼이 구독 로그인 정보를 갖지 않음, 비용이 각 학교 구독으로, 범위를 DB가 강제 | 학교가 앱을 직접 다뤄야 함(안내 문서로 줄임) | 플랫폼 추가 비용 없음 |
| B. 구독 계정을 플랫폼에 연결 | 학교의 Claude·ChatGPT 로그인을 플랫폼이 보관해 대신 호출 | 학교는 플랫폼 안에서만 씀 | 개인 구독을 제3자 서비스에서 쓰는 것은 약관상 허용되지 않을 가능성이 높음(약관 확인 필요), 비밀번호 보관 위험 | — |
| C. API 키 연결(학교별) | 학교가 Anthropic·OpenAI **API 키**를 등록해 플랫폼 안 대화형 편집(ADR 0011 2단계)에 씀 | 플랫폼 안에서 바로 대화 | 사용량 과금(구독과 별개), 키 보관 | 학교별 API 사용료 |

## 결정
안 A를 기본으로 한다. 안 C는 ADR 0011 2단계(대화형 편집) 비용 검토 때 다시 본다. 안 B는 하지 않는다.

### 학교 쪽: AI 작업 공간
- 학교 관리자가 학교 화면에서 **에이전트 토큰**을 발급한다(범위: 항목 종류 story·page·news × 선택적 key × 권한[시안 저장, 그림·PDF 올리기, 읽기]). 공개·설정·구성원·다른 학교는 어떤 토큰도 못 한다(DB 명령 함수가 강제, ADR 0012).
- 토큰마다 에이전트 종류(Claude Code / Codex / 기타)·쓰임·발급자를 등록하고, **활동 기록**(언제 어떤 시안을 만들었나)을 학교 관리자가 본다. 기한·폐기·마지막 사용.
- `docs/agents/`의 Claude Code용·Codex용 시작 안내를 학교가 자기 앱에 주면 바로 일한다. 결과는 시안이고 공개는 학교 사람이 한다.
- 학교 전용 **코드** 개발(학교 저장소, 플랫폼 확장 지점·모듈 계약)은 다음 단계에서 따로 설계한다(이 기록 갱신). 그 전까지 학교 코드 변경은 플랫폼 저장소에 PR로 내고 관제가 검토한다.

### 관제 쪽: 서브 세션
- 관제 세션이 학교·기능별 서브 세션을 만들어 맡긴다. 규약: `docs/automation/SCHOOL-SESSIONS.md`(이름·태그·첫 지시 틀·경계·끝낼 때).
- 서브 세션도 사람과 같은 경로(로그인 화면 또는 범위 토큰)로만 운영 내용을 바꾼다. 점검 계정은 읽기 전용이다(ADR 0010).

### 병행 규칙
- **판 충돌 방지:** 새 판 저장은 `base_version`(보고 고친 판)을 받고, 그 사이 다른 판이 생겼으면 409로 거부하고 최신 판을 알려 준다(ADR 0012에서 구현). 사람 편집·학교 에이전트·관제 서브 세션 모두 같은 규칙.
- **코드 충돌 방지:** 한 PR에 한 기능, 겹치는 파일은 작은 PR로 먼저 병합하고 PR 설명에 적는다. 세션 사이 알림은 send_message.
- **공개는 사람이:** 에이전트와 서브 세션은 시안까지. 공개는 학교 관리자(사용자 지시가 있으면 관제가 화면으로 확인).

## 영향
- 코드: ADR 0012의 토큰·명령 함수를 일반화(범위·등록·활동 기록·base_version), `docs/agents/`, 22차 개발 연동의 세션 요청 문구에 안내 링크.
- 문서: `docs/automation/SCHOOL-SESSIONS.md`, `docs/NEXT.md` 세션 표.
- 되돌리기: 토큰 폐기로 즉시 차단. 기능을 끄면 기존 편집 경로만 남는다.

## 확인 방법
- 토큰 범위 밖 거부(종류·key·다른 학교·공개) 양방향, 기한·폐기, base_version 409, 활동 기록 표시(E2E).
- 첫 실사용: 룽아룬숙사 동화 — Codex가 토큰으로 캐릭터 PNG·PDF 시안을 올리고 선생님이 공개.
