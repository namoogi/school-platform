# 0039. 서버 오류는 이름표로: 응답 때 사용자 언어로 바꾼다

- 상태: 채택
- 날짜: 2026-11-27
- 제안: Claude(다국어 전환 세션)
- 결정: 사용자(2026-11-27, ADR 0037 결정의 연장 — "모든 기능들은 영/한 공통으로 언어전환이 가능하도록")
- 관련: ADR 0037(언어는 데이터로)

## 배경
- 화면 문구는 ADR 0037로 이름표 + 번역 사전이 됐다. 그런데 서버(API·DB 함수)가 돌려주는 오류는 한국어 문장 그대로다.
  - 앱 코드: `throw new ValidationError('기간은 12개까지 …')` 약 340곳
  - DB 함수: `raise exception '학교 관리자만 할 수 있습니다.'` 고정 문구 약 370개(값이 든 문구 제외)
- 영어 화면을 쓰는 사람도 실패 안내는 한국어로 본다.

## 고려한 안
| 안 | 내용 | 장점 | 단점·위험 |
| --- | --- | --- | --- |
| A | 서버가 이름표로 던지고, 응답 때 요청한 사람의 언어로 바꾼다 | 화면 코드 그대로(`data.error`를 보여 줌), 에이전트도 같은 응답 | 응답 때 언어를 한 번 더 정해야 함(오류일 때만) |
| B | 서버는 이름표만 주고 화면이 번역 | 서버가 가벼움 | 화면 수십 곳·외부 에이전트 모두 고쳐야 함 |
| C | DB 함수도 이름표로 다시 쓰기 | 근원에서 해결 | 마이그레이션 수백 함수 교체, 위험 큼 |

## 결정 — 안 A
1. 오류 종류(`ValidationError`·`NotFoundError`·`ForbiddenError`·`NoSchoolError`·`StorageError`)는 `src/lib/errors.ts`의 `AppError`를 잇는다. `new ValidationError('err.이름', { 값 })`처럼 이름표로 던진다.
   - `message`에는 기준 문구(한국어)가 들어가 기록·시험·이전 코드가 그대로 읽는다.
   - 이름표가 아닌 문장을 넘기면 지금처럼 그대로 돌려준다(아직 옮기지 않은 곳이 깨지지 않게).
2. `errorResponse`(src/lib/api.ts)가 응답을 만들 때 언어를 정한다: 사용자 설정 → 쿠키 → 학교 기본 언어 → 브라우저 → 한국어(화면과 같은 순서). 응답은 `{ error: 그 언어 문구, code: 이름표 }`. 이름표가 없으면 `{ error }`만.
3. DB 함수 문구는 함수를 고치지 않는다. 기준 문구가 DB 문구와 **글자까지 같은** `db.*`(또는 `err.*`) 이름표가 있으면 그 이름표로 번역한다. 값이 든 문구(`format`)는 한국어 그대로 간다.
   - `tests/server-errors.test.ts`가 `db.*` 문구가 마이그레이션에 그대로 있는지 본다(DB 문구를 바꾸면 번역이 조용히 멈추는 것을 막음).
   - 새로 쓰는 DB 함수도 고정 문구를 쓰고 `db.*` 이름표를 함께 더한다. 값이 꼭 필요하면 값 없는 문장 + 따로 칸(예: `detail`)을 쓴다.
4. 오류 값(vars)에는 비밀·입력 원문을 넣지 않는다(AGENTS.md 검토 3).

## 단계
- 101차: 틀 + 앱 코드 오류 전부(홈페이지 `site*.ts`·동화 `story*`는 홈페이지 세션 몫이라 제외) + 자주 나오는 DB 문구 29개.
  - 값 속 낱말도 번역: 값이 이름표이거나 `noun.*` 기준 문구(한국어 명사)와 같으면 그 언어로 바꿔 넣는다(`localVars`).
  - 입력 원문(시트 주소)을 오류에 싣던 두 곳은 값을 뺐다(검토 규칙 3).
- 다음: 나머지 DB 고정 문구 약 340개 `db.*` 이름표.

## 영향
- 화면 코드는 바뀌지 않는다. 응답에 `code`가 더해진다.
- 오류가 날 때만 사용자 설정을 한 번 더 읽는다(정상 요청 비용 없음).
- 되돌리기: `errorResponse`가 `c.text`만 돌려주게 하면 예전과 같다.

## 확인 방법
- `tests/server-errors.test.ts`(단위): 이름표/문장 구분, 영어 응답, DB 문구 연결과 어긋남 검사.
- 영어 설정 사용자로 권한 밖 요청 → 영어 안내.
