# 0031. 학교 홈페이지 템플릿: 둘러보고 골라 시작, 빈 칸 목록으로 자동 배치·이전을 잇는다

- 상태: 채택
- 날짜: 2026-11-26
- 제안: Claude(관제)
- 결정: 사용자 지시(2026-11-25 "다양한 학교 홈페이지들의 형식을 정리한 다음 각 학교가 홈페이지 템플릿을 둘러보고 선택해서 작업을 시작할 수 있도록 하자. 물론 템플릿에 자동적으로 관리자가 첨부한 학교 자료가 AI로 분석되어 배치되거나 또는 기존의 홈페이지의 크롤링 및 이전이 지원되도록 하고", 2026-11-26 "계속 진행해 줘")

## 배경
- 학교 홈페이지 모듈(ADR 0008·0011)이 이미 갖춘 것
  - 블록·잡지형 구역 체계와 테마 2개(campus·dawn)
  - 판·공개 흐름, zip 가져오기(빠진 칸만 채우기)
- 지금은 학교가 빈 쪽에서 시작하거나 옛 사이트 묶음을 가져와야 한다.
- 사용자 목적은 세 가지다.
  - 학교가 템플릿을 둘러보고 골라 시작하는 것
  - 첨부 자료를 AI가 분석해 배치하는 것
  - 기존 사이트를 크롤링해 옮기는 것

## 고려한 안
| 안 | 내용 | 장점 | 단점 |
| --- | --- | --- | --- |
| **A 코드 안 템플릿 목록 + 쪽 시안 복제 (채택)** | 템플릿은 저장소 코드(판 번호 있음). 고르면 그 학교에 **시안 쪽**을 만든다. 공개는 사람이 한다. 이미 있는 주소의 쪽은 건드리지 않는다 | 기존 블록·판·공개 흐름을 그대로 쓴다. 학교 사본은 학교 것이 된다(ADR 0027과 같은 '복제 후 학교 소유') | 템플릿을 고치면 이미 적용한 학교에는 반영되지 않는다(의도된 동작) |
| B 템플릿을 DB 기본판(ADR 0027)에 넣기 | 관제 기본판의 홈페이지 부분으로 관리 | 관제 화면에서 고칠 수 있다 | 지금은 쪽 내용 관리 화면이 관제에 없다. 템플릿 수가 적어 코드가 단순 |
| C 테마(디자인)만 고르기 | 쪽 구성은 학교가 직접 | 단순 | 사용자 목적('형식을 골라 시작')에 못 미침 |

## 결정
- **A를 채택한다.** 템플릿 7종(`docs/research/homepage-templates-2026-11.md` 3절)
  - 알림 중심, 이야기, 입학 모집, 프로젝트, 사명·후원, 국제·다국어, 한 쪽 소개
- 템플릿 = 아래 다섯 가지의 묶음
  - 추천 테마
  - 쪽 목록(주소·순서·내용: 기존 블록 형식, `validateContent` 통과)
  - **빈 칸 목록(slots)**: 쪽·블록·칸 경로, 무엇을 넣을지, 자료 종류(글·사진·목록), 찾을 단서
  - 공개 의무 안내(빠진 정보 체크)
  - 판 번호
- 적용
  - 학교 관리자만 할 수 있다.
  - 만드는 것은 쪽의 시안(1판)뿐이고, 저절로 공개되지 않는다.
  - 같은 주소의 쪽이 이미 있으면 건너뛰고 알려 준다(학교 것을 덮지 않음).
  - 적용 기록은 쪽 판 메모(`템플릿 <이름> v<판>`)와 활동 기록에 남긴다.
- 미리보기
  - 방문자 화면과 같은 그리기 코드(`SiteBlocks`)로 그린다.
  - 내용은 템플릿 안내 문구만 쓰고, DB를 읽지 않는다.
- 후속 차시도 이 빈 칸 목록을 쓴다.
  - **66차 자동 배치**: 관리자가 올린 학교 자료(PDF·문서·사진)에서 빈 칸을 채운 **새 시안 판**을 만든다.
    - 분석은 학교 AI(작업 토큰 `page` + 템플릿 빈 칸 안내, 학교 구독 = 플랫폼 비용 없음)가 기본이다.
    - 플랫폼이 유료 API로 분석하는 길은 비용 확인 뒤에 연다(사용자 비용 원칙).
  - **67차 기존 사이트 이전**: 학교가 준 주소를 같은 사이트 안에서 몇 쪽 읽는다(크롤링). 글·사진을 빈 칸에 맞춰 시안 판으로 옮기고, 빠진 칸만 채운다(50차 규칙).

## 영향
- 새 코드: `src/lib/site-templates.ts`(목록·적용), 둘러보기·미리보기 화면, 적용 API. DB 표는 새로 만들지 않는다(쪽·판 표를 그대로 쓴다).
- 데이터 경계: 학교 ID는 로그인 소속에서 정한다. 쓰기는 기존 `createEntry`(RLS) 경로 하나다.
- 되돌리기: 만든 시안 쪽은 보관(소프트 삭제)으로 치운다.

## 확인 방법
- 모든 템플릿 쪽이 `validateContent`를 통과하고, 빈 칸 경로가 실제 칸을 가리키는지(단위 시험)
- 적용: 시안만 만들고 공개하지 않는다. 같은 주소의 쪽은 건너뛴다. 교사·다른 학교는 거부한다(통합 시험).
- 화면: 둘러보기 → 미리보기 → 적용 → 쪽 목록에 시안(e2e·axe)
