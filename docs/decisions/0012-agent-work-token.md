# 0012. 외부 작업 토큰: 성품 동화 전용 · 시안만 · 명령 함수로만

- 상태: 채택
- 날짜: 2026-11-23
- 제안: 사용자 — "룽아룬숙사 홈페이지에서 동화 페이지에 한해서만 Codex로 작업 세션을 주고, Codex에서 동화 PDF 생성 및 캐릭터 PNG 제작한 것을 동화 페이지에 업데이트한다."
- 결정: 사용자 지시(2026-11-23), 구현 방식은 Claude(관제 세션이 정한 방향: 범위 제한 작업 토큰)
- 관계: ADR 0011 3단계 '학교별 생성형 개발'의 첫 사례. ADR 0010(점검 토큰)과 같은 꼴(머리 토큰·sha256·기한·폐기·마지막 사용), ADR 0004의 명령 함수 방식.

## 배경
- 이미 구독 중인 ChatGPT의 Codex(선생님 Mac의 Codex CLI 또는 Codex 클라우드)로 동화 PDF와 캐릭터 PNG를 일괄로 만든다. Gemini 이미지는 별도 요금이라 이번 일에는 쓰지 않는다.
- 만든 파일을 사람이 한 장씩 편집 화면에 올리면 16쪽 × 언어 × 캐릭터 수만큼 손이 간다. 외부 에이전트가 직접 올리되, **동화 시안만** 바꿀 수 있어야 한다.
- 에이전트는 Google 로그인을 할 수 없고, 해서도 안 된다(사람 계정 권한 전체가 넘어감).

## 고려한 안
| 안 | 내용 | 장점 | 단점·위험 |
| --- | --- | --- | --- |
| A. 토큰별 에이전트 계정 + RLS 조건 | 토큰마다 가짜 사용자를 만들고 기존 표 정책에 '에이전트면 story만' 조건을 더한다 | 기존 API를 그대로 씀 | 모든 표 정책에 예외가 퍼진다. 새 표를 만들 때마다 에이전트 조건을 빠뜨릴 위험. 사용자 경로(asUser)와 에이전트 경로가 섞임 |
| **B. 명령 함수만 여는 방식 (채택)** | 토큰 요청은 표 권한이 전혀 없는 역할 `agent_request`로 돌고, `agent` 스키마의 함수 6개만 부를 수 있다. 함수는 제한 역할 `agent_writer`가 소유하고, 그 역할에도 RLS가 걸린다 | 노출 면이 함수 6개로 좁다. 공개·설정·쪽·소식·다른 학교는 **함수가 없어서** 할 수 없다. 범위를 DB가 두 번(함수 검사 + RLS) 강제 | 함수·정책을 따로 유지해야 한다 |
| C. 현행 유지 | 선생님이 Codex 결과물을 받아 편집 화면에 직접 올림 | 새 코드 없음 | 반복 수작업. ADR 0011(학교 스스로 운영) 방향과 맞지 않음 |

## 결정 (안 B)
### 토큰
- 표 `public.agent_tokens`: school_id, 이름, 범위(`scope_kind = 'story'`만, 선택적으로 동화 key 하나), **sha256만**(원문 저장 안 함), 기한 7·30·90일, 폐기 시각, 마지막 사용 시각, 만든 사람. 행은 지우지 않는다.
- 표 `public.agent_token_uses`: 토큰으로 한 일(파일 올리기, 새 판 저장) — 추가만.
- 발급·폐기: 그 학교 관리자만(`app.create_agent_token`, `app.revoke_agent_token`), 성품 동화 기능이 켜진 학교만. 운영 기록(access_log)에 남는다. 원문은 발급 응답에서 한 번만 돌려준다. 해시 열은 사람에게도 보이지 않는다(열 권한).
- 요청 머리 `x-agent-token: agt_<64 hex>`. `/api/agent/*`만 이 머리를 읽고, 로그인 쿠키와 함께 오면 거부한다. 사람 경로(`/api/site/*` 등)는 이 머리를 모른다(401).
- 학교가 이용 중지되거나 성품 동화 기능이 꺼지면 토큰도 곧바로 멈춘다.

### 할 수 있는 일 (agent 스키마 함수)
| 함수 | API | 하는 일 |
| --- | --- | --- |
| `agent.whoami` | `GET /api/agent/me` | 학교·범위·기한 확인 |
| `agent.stories` | `GET /api/agent/stories` | 범위 안 동화 목록 |
| `agent.story` | `GET /api/agent/stories/<key>` | 최신 판 내용(새 판의 바탕) |
| `agent.assets` | `GET /api/agent/assets` | 그 학교 그림·PDF 목록 |
| `agent.upload_asset` | `POST /api/agent/assets?name=` | PNG·JPG·WEBP·PDF 올리기(같은 내용은 다시 쓰지 않음) |
| `agent.save_story` | `POST /api/agent/stories/<key>/versions` | 범위 안 동화의 **새 판(시안)** 저장. 공개하지 않는다 |

- 새 판의 책임자(created_by)는 토큰을 발급한 관리자, 판 메모 앞에 `[작업 토큰: 이름]`이 붙는다.
- 새 판 내용은 사람 편집과 같은 검사(validateContent)를 거치고, DB 함수가 다시 '내용이 가리키는 그림·파일이 모두 이 학교 것'인지 확인한다.
- 공개·설정·쪽·소식·새 동화 만들기·다른 학교: 함수가 없다. `agent_request`는 어떤 표도 읽거나 쓸 수 없고, `app` 스키마도 쓸 수 없다.

### 데이터 경계와의 관계 (AGENTS.md)
- 1(RLS): 새 표 모두 school_id + RLS. `agent_writer`의 site_* 정책은 '함수가 정한 학교 · story · 지정 key'만 허용한다.
- 2(asUser): 토큰 요청은 사용자 요청이 아니므로 `asAgent()`(agent_request 역할)를 쓴다. `asSystem()`은 쓰지 않는다.
- 3(학교 ID): 학교는 토큰 행에서 정한다. 요청이 보낸 학교 값은 없다.
- 4·5(보존): 판·그림·공개 기록은 그대로 추가만. 발행 화면은 판 스냅샷만 읽는다(내려받기 블록의 파일 이름·크기도 저장 때 판에 적힌다).

### PDF
- `site_assets`에 `application/pdf` 허용. 4MB 이하(Vercel 요청 한도 약 4.5MB), 머리 `%PDF-`를 DB 제약으로도 강제.
- 16쪽 그림 PDF는 인쇄용이면 4MB를 넘기 쉽다. **웹용(150dpi 정도, JPEG 그림)으로 줄인 파일**을 기준으로 한다. 더 큰 파일이 필요하면 저장소(Supabase Storage 등) 도입을 **새 ADR로 따로 묻는다**(다시 볼 조건).
- 새 블록 `download`: PDF 내려받기 단추(언어별 이름·설명, 파일 이름·크기 표시). 공개 화면은 공개된 판이 가리킬 때만 파일을 주고(기존 public_asset 규칙), PDF는 `Content-Disposition: attachment` + `Content-Security-Policy: sandbox` + `nosniff`로 내려받기만 한다.

## 위험과 대응
| 위험 | 대응 |
| --- | --- |
| 토큰 유출 | 할 수 있는 일이 '그 학교 동화 시안 추가'뿐이다. 공개는 사람이 하므로 방문자에게 바로 나가지 않는다. 판은 보존돼 이전 판으로 되돌릴 수 있다. 짧은 기한, 즉시 폐기, 마지막 사용·사용 기록 표시. 동화 key 하나로 좁혀 발급할 수 있다 |
| PDF 안의 실행 가능한 내용(자바스크립트, 프로그램 실행, 첨부 파일, XFA 양식) | 올릴 때 거부: `/JavaScript`·`/JS`·`/Launch`·`/EmbeddedFile(s)`·`/SubmitForm`·`/ImportData`·`/XFA`·`/RichMedia`·`/GoToE`·`/Encrypt`. 이름의 `#xx` 표기를 풀고, Flate로 압축된 객체 묶음(/ObjStm)도 풀어 본다 |
| 검사를 피하는 PDF(다른 압축 필터로 숨긴 객체 묶음, 깨진 구조) | 알 수 없는 필터의 객체 묶음은 거부. 그래도 완전한 검사는 아니다(남는 위험) → 사이트 안에서 열지 않고 내려받기로만 주어 같은 출처 실행을 막는다. 읽는 쪽 PDF 프로그램의 보안 설정에 기대는 부분이 남는다 |
| 그림 스트림의 우연한 바이트가 `/JS`처럼 보여 정상 PDF를 거부 | 스트림 내용은 보지 않고(객체 묶음만 예외) 사전 부분만 검사 |
| 큰 파일로 요청 한도 초과 | 한 요청 4MB, 스크립트가 미리 크기를 알려 준다 |
| 다른 학교 그림을 가리키는 판 | DB 함수가 내용의 모든 uuid가 그 학교 자산인지 확인 |
| 함수 소유 역할의 권한 확대 | `agent_writer`는 로그인·BYPASSRLS 없음, site_* 중 필요한 표의 select·insert만. 마이그레이션이 요청 역할이 이 역할의 구성원이 아님을 확인한다 |

## 영향
- 마이그레이션 `20261123001200_agent_tokens.sql`: 역할 2개, 표 2개, agent 스키마, site_assets PDF 허용.
- 코드: `src/lib/agent.ts`·`agent-api.ts`·`pdf-check.ts`, `/api/agent/*`, `/api/site/agent-tokens*`, `/site` 설정의 '외부 작업 토큰' 패널, 블록 `download`(site-shared·site·SiteRenderer·SiteClient).
- 안내: `docs/agents/story-agent.md`, 스크립트 `scripts/agent-story-upload.mjs`.
- 되돌리기: 토큰을 모두 폐기하면 즉시 멈춘다. 코드를 되돌려도 표·판은 남는다(판은 보존 규칙).
