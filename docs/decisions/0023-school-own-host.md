# 0023. 학교 자체 주소로 공개 홈페이지 열기 (rungarunsuksa.vercel.app)

- 상태: 채택
- 날짜: 2026-11-24
- 제안·결정: 사용자 — "기존 사이트 분석을 해서 가져오는 작업은 차차 하더라도 새로운 사이트의 주소 표기는 rungarunsuksa.vercel.app으로 연결해 줘."
- 관계: ADR 0008(학교 홈페이지), 31차 옛 주소 호환. ADR 0019 단계 C(학교 도메인)를 앞당긴다.

## 고려한 안
| 안 | 내용 | 판단 |
| --- | --- | --- |
| **A. 주소를 이 프로젝트로 옮기고 호스트로 다시 쓰기 (채택)** | Vercel 도메인을 플랫폼 프로젝트에 붙이고 `proxy.ts`가 그 주소의 요청을 `/s/<학교>/…`로 다시 쓴다. 주소창은 그대로(`rungarunsuksa.vercel.app/about`) | 주소 표기가 학교 주소, 옛 경로도 그대로 열림. 학교 도메인(`www.학교.kr`)에도 같은 방식 |
| B. 옛 프로젝트에서 넘겨주기(308) | 옛 사이트가 새 주소로 보냄 | 주소창이 `onschools.vercel.app/s/…`로 바뀜 → 지시와 다름 |
| C. 옛 프로젝트가 새 사이트를 대신 받아 보여 줌(프록시) | 옛 프로젝트 유지 | 두 프로젝트·두 배포를 계속 관리 |

## 결정
- `src/lib/site-hosts.ts`: 주소 ↔ 학교 표(코드 + 환경 변수 `SCHOOL_HOSTS`), 경로 규칙(옛 `/about`·`/friends/**`·`/news/**` 그대로, 관리 화면은 플랫폼 주소로 307).
- `src/proxy.ts`: 학교 주소면 다시 쓰고 머리 `x-school-host`를 붙인다. 다른 주소에서는 그 머리를 지운다(링크 모양 속이기 방지).
- 공개 화면 링크: 학교 주소로 볼 때는 `/about`, 플랫폼 주소로 볼 때는 `/s/<학교>/p/about`. 그림 주소(`/s/<학교>/a/…`)는 그대로.
- 학교 홈페이지 관리의 '공개 홈페이지 열기'가 학교 주소를 보인다.
- 데이터·권한 변경 없음(공개 판 판단은 그대로).

## 사람이 할 일 (관제 권한 밖)
- Vercel: 옛 프로젝트에서 `rungarunsuksa.vercel.app`을 떼고, 플랫폼 프로젝트(school-platform) → Settings → Domains에 붙인다. 옛 사이트는 그 순간 이 주소에서 내려간다(코드·배포 기록은 남음).

## 확인 방법
- `tests/site-hosts.test.ts`(경로 규칙), 로컬 `next start`에 Host 머리로 확인(첫 화면·/about·/news·/friends 200, /login·/auth 307, 링크가 /about, 플랫폼 주소에서 위조 머리 무시). 운영은 주소를 옮긴 뒤.
