# 0041. 국가 기준은 기본판 견본, 학교 성적·양식은 성적표 분석으로 학교 사본에서 응용

- 상태: 채택
- 날짜: 2026-11-27
- 제안: Claude(관제)
- 결정: 사용자(2026-11-27)
  - "한국학교의 학생부 기재요령이야. 참고하도록 해. 미국식은 조사해서 반영하도록 하고."
  - "다만 대안학교는 그 양식이나 성적 산출하는 방식이 다를 수도 있어. 그건 각 학교별로 성적표를 받아서 분석하는 작업을 거쳐서 기본 DB에서 응용해서 양식을 만들어야 해."
- 관련: ADR 0025(학사 토대, 한국+미국 기준), 0027(기본판·학교 사본), 0035(공용 기본 + 설정값 맞춤), 0040(계산식 판)
- 근거 문서: `docs/research/kr-us-grading-2026-11.md`, 절차 `docs/agents/grade-intake.md`

## 결정
1. **국가 기준은 기본판 견본이다.** 학교가 고르지 않으면 아무 학교에도 적용되지 않는다.
   - 계산식 견본 7개
     - 한국: `kr_high_common`, `kr_high_elective`, `kr_high_science_lab`, `kr_high_arts_pe`, `kr_middle`, `kr_middle_arts_pe`
     - 미국: `us_letter_plus_minus`
     - 0040의 6개와 합쳐 13개다.
   - 척도 견본 2개: `kr_abc`(체육·예술·과탐실험 A·B·C), `us_plus_minus`(± 글자 성적, 4.0 평점)
   - 경계값은 시험 `tests/calc-expr.test.ts`·`tests/calc-kr-us.test.ts`로 고정한다.
   - 견본마다 원문 근거(기재요령 쪽, 미국 출처)를 `note`와 조사 문서에 적는다.
2. **이수 보충을 입력으로 받는다**: `support.achievement`(최소 성취수준 보장지도 이수), `support.attendance`(과목 출석 미달 추가학습 이수).
   - 보충 전 40% 미만은 `I`(미이수)다.
   - 자료가 없으면 null(3값, ADR 0040).
3. **모집단 계산을 따로 둔다**(`src/lib/calc/population.ts`): 석차·석차등급(누적비율·반올림 인원·경계 동점 중간석차·5명 이하 미산출), 과목평균, 모표준편차, 분포비율, 평점 평균(GPA).
   - 학생 한 명 × 수업 하나만 보는 계산식 판과 섞지 않는다. 다른 학생을 함께 봐야 하기 때문이다.
   - 평점표·가중·누적비율은 인자로 받고 박지 않는다.
   - 모집단 열쇠는 수업 id(ADR 0004)다. 누구를 넣을지(집계 참여)는 부르는 쪽(마감)이 정한다.
4. **학교 맞춤은 성적표 분석 절차로 한다**(`docs/agents/grade-intake.md`).
   1. 받기: 빈 양식·가림 견본·규정
   2. 매핑표
   3. 가까운 견본 고르기
   4. 학교 사본에 새 판 쓰기('왜' 칸에 조항)
   5. 미리 계산으로 학교 결과와 맞춰 보기. 다르면 질문을 연다.
   6. 학교 관리자 확정
   - 분석은 학교 구독 AI나 관제가 한다(ADR 0032). 서버 유료 분석은 없다.
   - 실제 학생 정보는 저장소·시험에 남기지 않는다.
5. 초등은 문장 서술이 원칙이라 계산 견본을 두지 않는다. 서술 기록과 출력 프로필이 맡는다.

## 다음 단계 (아직 안 함)
- 수업 마감 판이 학교가 고른 계산식 판으로 원점수·성취도·이수를 계산한다. 이어서 모집단 계산으로 과목평균·분포·석차등급을 붙여 스냅샷에 남긴다(ADR 0040 마감 연결과 함께).
- 서술 칸 글자 수 한도를 성적 정책 판에 두고, 셀 단위를 고르게 한다('글자' 또는 'byte, 한글 3').
- 출력 프로필: 한국 학생부 칸(원점수/과목평균, `A(54)`, 석차등급 '·')과 미국 성적증명서 GPA 칸을 모집단 계산 결과와 연결한다.
- 학교 작업 토큰 `package`로 계산식·척도 판 초안 쓰기(사람이 확정).

## 고려한 안
| 안 | 판단 |
| --- | --- |
| 국가 기준을 모든 학교의 고정 규칙으로 | 기각: 대안학교는 양식·산출이 학교마다 다르다(선생님) |
| 학교마다 처음부터 식을 새로 쓰기 | 기각: 반복이 많고 반올림·동점 같은 경계에서 틀리기 쉽다. 시험으로 고정한 견본에서 출발하는 편이 안전하다 |
| **견본 + 성적표 분석 → 학교 사본(채택)** | 기본판은 그대로 두고 학교가 응용한다(ADR 0027·0035와 같은 방식) |
