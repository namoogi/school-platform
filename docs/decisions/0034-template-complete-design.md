# 0034. 홈페이지 템플릿 = 완성 디자인(색·글꼴·첫 화면 + 쪽 구성)

- 상태: 채택
- 날짜: 2026-11-27
- 제안: Claude(홈페이지 세션)
- 결정: 사용자(2026-11-27). 선생님이 템플릿 화면과 상용 학교 테마 판매 화면을 나란히 보여 주며 "내가 아는 템플릿의 개념과 많이 다른데?"라고 하셨습니다. 이어 선택지 질문에 '템플릿 = 완성 디자인', '예시 그림은 선생님 쪽 AI로 사진풍 생성'을 고르셨습니다.
- ADR 0031을 고친다(대체가 아님). 0031의 쪽 시안 복제, 빈 칸 목록, 공개는 사람이 한다는 원칙은 그대로 둔다.

## 배경
- ADR 0031의 템플릿은 쪽 구성(어떤 쪽에 어떤 내용)과 추천 테마의 묶음이었다.
- 그런데 테마가 2종(학사 기본·새벽빛)뿐이었다. 그래서 7종이 비슷한 문서처럼 보였다.
- 선생님이 아는 템플릿은 상용 테마처럼 '사진·색·배치가 다른 완성 디자인'을 보고 고르는 것이다.
- 원인은 설계에 있었다: 디자인 층(테마)이 너무 적고, 예시 그림이 없었다.

## 고려한 안
| 안 | 내용 | 장점 | 단점 |
| --- | --- | --- | --- |
| **A 템플릿 = 완성 디자인(채택)** | 템플릿마다 고유 테마(색·글꼴·첫 화면 큰 사진·카드 모양) + 쪽 구성 + 예시 내용·그림 | 고르는 것이 하나. 상용 템플릿과 같은 경험 | 테마 CSS가 늘어남 |
| B 디자인·구성 따로 고르기 | 테마 6~8종과 구성 7종을 따로 고름 | 조합이 자유로움 | 처음 쓰는 학교에는 고를 것이 둘이라 어려움 |
| C 썸네일만 손봄 | 구조는 그대로 | 빠름 | 디자인을 고른다는 경험이 약함 |

## 결정
- **A를 채택한다.**
- 화면 모양(테마)을 8종으로 늘린다.
  - 기존: 학사 기본(campus), 새벽빛(dawn)
  - 새로: 맑은 하늘(clear), 힘찬 시작(bold), 작업실(studio), 등불(lamp), 지평(horizon), 씨앗(seed)
  - 새 테마 6종은 공용 틀 하나에 `--t-*` 토큰 값과 몇 가지 모양만 바꾼다.
  - 블록·쪽 구조는 모든 테마가 같다. 그래서 학교는 설정에서 언제든 다른 모양으로 바꿀 수 있다.
- 템플릿과 디자인 짝
  - 알림 중심 → 맑은 하늘, 이야기 → 새벽빛, 입학 모집 → 힘찬 시작, 프로젝트 → 작업실
  - 사명·후원 → 등불, 국제·다국어 → 지평, 한 쪽 소개 → 씨앗
  - 템플릿 판 번호를 2로 올린다(이야기형은 1 그대로).
- 둘러보기
  - 카드마다 큰 썸네일을 둔다. 첫 화면, 그 아래 구역, 휴대폰 화면을 겹친 그림이다(`npm run templates:thumbs`).
  - 카드에 '미리보기'와 '자세히·시작하기' 단추를 둔다.
  - 미리보기는 관리 화면 밖 전체 화면(`/templates/<key>`)으로 연다. 방문자에게 보일 틀(머리·메뉴·바닥) 그대로이고, 쪽마다 넘겨 볼 수 있다.
  - 로그인한 사람만 보고, DB는 읽지 않는다.
  - **공개 주소 `/demo/<key>`**(2026-11-28 사용자 결정: "나중에 프로모션 할 때는 공개 페이지가 필요", "공개 주소만 따로 빼서 실제 템플릿만 나오도록"): 누구나 보고, 위 안내 줄·예시 안내 없이 템플릿 화면만 나온다. 내용이 합성 예시뿐이라 학교 자료가 나가지 않는다. 로그인하지 않은 사람이 `/templates/<key>`를 열면 같은 쪽의 `/demo/<key>`로 보낸다. 두 주소는 `src/app/templates/TemplateView.tsx` 하나를 쓴다.
- 예시 그림
  - 22장. 선생님 쪽 AI(기본 Gemini Flash)로 사진풍으로 만든다. 프롬프트는 `docs/design/template-image-prompts.md`(3장 이상이라 생성 전에 확인).
  - 오기 전에는 자리 그림(SVG)을 쓴다.
  - 그림에는 사람 얼굴·글자·로고를 넣지 않는다.
- 적용
  - '시작하기'에 '화면 모양도 이 디자인으로 바꾸기'를 둔다.
    - 홈페이지가 닫혀 있으면 기본으로 켜고, 열려 있으면 기본으로 끈다. 열려 있으면 방문자 화면이 바로 바뀐다는 것을 알린다.
    - 설정이 없으면 바꾸지 않고 알린다.
  - 이관(87차) 단추도 같은 선택을 쓴다.
  - 학교 쪽에는 예시 그림·글이 아니라 `[ ]` 안내 자리가 들어간다(0031 그대로).

## 영향
- 코드
  - `SITE_THEMES`·`SiteTheme`(site-shared): 설정 저장은 목록에 있는 값만 받는다.
  - `globals.css`: 89차 테마 묶음
  - `SiteFrame`: 학사 기본 밖의 테마는 넓은 바닥을 쓴다. 미리보기용 `preview` 링크도 더했다.
  - 템플릿: 테마·판 번호, 알림 중심형 첫 화면 큰 사진 구역
  - 예시 그림 자리·예시 소식
  - 화면: 전체 화면 미리보기 경로, 둘러보기 카드
  - `applyTemplate(design)`, 썸네일·자리 그림 스크립트
- DB
  - 마이그레이션 `20261128000200_site_theme_designs.sql`: `site_settings.theme` 확인 제약을 8가지 값으로 넓힌다. 새 표는 없고, 기존 행은 그대로다.
  - 모양 바꾸기는 기존 RLS 경로(`site_settings` update, 학교 관리자)를 쓴다.
- 데이터 경계: 새 쓰기 경로가 없다. 학교 ID는 로그인 소속에서 정한다.
- 공용 영향
  - 새벽빛(룽아룬숙사)은 CSS·동작을 바꾸지 않았다.
  - `SiteFrame` 변경은 더하기뿐이다: 새 테마의 바닥 정보, `preview` 속성.
- 되돌리기: 설정에서 화면 모양을 되돌린다. 코드는 커밋을 되돌린다.

## 확인 방법
- 단위 시험
  - 모든 템플릿 테마가 `SITE_THEMES`에 있다.
  - 예시 그림 자리가 실제 칸을 가리키고 파일이 있다.
- 통합 시험
  - `design: true`면 학교 설정의 모양이 바뀐다. 설정이 없으면 `no-settings`가 된다.
  - 다른 학교 설정은 바뀌지 않는다.
  - 설정 저장은 목록 밖 값을 학사 기본으로 바꾼다.
- e2e
  - 둘러보기 썸네일 → 전체 화면 미리보기(쪽 넘기기)
  - axe 위반 0건
- 화면 점검: `ui:review`로 새 테마 6종의 전체 화면 미리보기를 찍는다.
