# 0004. 도메인 모델 정규화: 학교 · 사람 · 학사 구조 · 수업 · 평가 · 발행

- 상태: **제안** (Claude 안 A) — Codex 안 B를 받아 비교한 뒤 사용자가 결정
- 날짜: 2026-11-22
- 제안: Claude (관제 세션)
- 근거: [드리미포털 구조 분석](../research/portal-analysis.md) L1~L13, 14~17차 구현, ADR 0001~0003
- 결정: 사용자 (대기)

## 배경

새 플랫폼은 지금 학사 규칙 확정과 문서 발행(14~16차)까지만 있다. 학생부 · 학생 포털 · 학교 홈페이지를 올리려면 사람·학기·수업·평가의 핵심 표가 필요하다. 드리미포털은 학교 개념 없음, 사람을 문자열로 참조(180열), 통계 모집단을 과목명으로 묶음, 규칙 사본 같은 구조 문제로 사고가 반복됐다. 처음부터 정규화된 핵심 모델을 세운다.

## 안 A: 핵심 표 (Claude)

```
schools ─┬─ school_settings (판)            school_levels (중·고 …)
         ├─ academic_years ── terms (학기·텀; 14차 확정 규칙에서 생성)
         ├─ cohorts (기수: 입학 학년도·학교급) ── homerooms (반, 학년도별)
         ├─ people ── person_names (이름 이력) ── person_accounts (계정 연결, 0..n)
         │     └─ enrollments_school (학적: 입학·전학·졸업·상태, 기간)
         ├─ subjects (실제 과목) ── subject_labels (발행 표기, 판·적용 범위)
         ├─ course_types (갈래: 수명주기 계기·공개 규칙·P/F 허용)
         ├─ course_offerings (학기·과목·갈래·블록·학교급·학점·P/F)
         │     ├─ offering_staff (person, 역할: 담당·보조·외부 강사)
         │     ├─ offering_enrollments (person, 상태, P/F 선택)
         │     ├─ assessments (평가 항목) ── assessment_results (원점수·성취도·P/F)
         │     ├─ narratives (세특 등 서술, 글자 한도는 school_settings)
         │     └─ population_exclusions (모집단 제외 person·사유)
         ├─ record_items (출결·수상·자격·동아리·행동특성 등, 종류 표 + 값)
         └─ published_documents (14차) ← 스냅샷에 과목 표기 판·통계·양식 포함
```

- **권한**: 역할(학교 관리자·교사)은 `memberships`(16차). 모듈 단위 관리자 `module_grants(person/account, module, 범위)`. 수업 단위 권한은 `offering_staff`에서 유도(담당 교사만 그 수업 성적 저장).
- **학생 포털**: 학생·보호자 계정은 `person_accounts`로 자기 `person`에만 연결, RLS 규칙 "본인 기록만".
- **홈페이지**: `site_pages`·`site_blocks`(판·공개 상태), 공개 수업 아카이브는 `course_offerings` + `course_types.publishable`에서 만드는 **뷰**(사본 금지).
- **통계**: `offering_stats(offering_id, mean, sd, n, computed_at)`는 계산 결과 캐시일 뿐이고, 발행본에는 그때 값을 스냅샷으로 넣는다. 표기 변경은 모집단에 영향이 없다(키가 id).

## 영향

- 새 마이그레이션 여러 개(타임스탬프 이름). 기존 14~17차 표는 유지하고, `terms`는 확정 규칙(`school_rules`)에서 만든다.
- 학생 실데이터는 이 결정 뒤에도 합성 자료로 시험하고, 실제 학교 자료를 넣는 것은 개인정보 처리 결정 뒤.
