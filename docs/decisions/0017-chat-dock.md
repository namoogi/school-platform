# 0017. 어디서나 여는 대화창 (옛 개선 요청 판 이식)

- 상태: 채택
- 날짜: 2026-11-23
- 제안: 사용자 지시
  - "이전 시스템에서 쓰던 개선 요청 판의 구성·기능을 살펴보고, 전체 관리 및 학교별 관리 기능에 붙여서 각 관리자들이 대화를 통해 시스템을 개선하도록 하자."
  - "언제든 화면에서 대화창을 열어서 관제 센터, 학교 AI, 홈페이지 인터페이스 개선, 시스템 기능 개선 등에 활용할 수 있도록 하자. 일단은 API로 대화 대응하는 기능은 나중에 하고, 각 세션이 응답할 수 있도록 하자."
- 결정: 사용자(2026-11-23), 구현 방식은 관제 세션(Claude)
- 관계: ADR 0015(관제 센터) 위에 쌓는다. 참고: 옛 MyCut 개선 요청 판 기능 문서·시안 스펙(2026-11-16, 사용자 제공).

## 배경
관제 센터(ADR 0015)는 전체 관리자 전용 페이지였다. 학교 관리자는 시스템 개선을 말할 통로가 없었고, 전체 관리자도 다른 화면에서 일하다 대화하려면 페이지를 옮겨야 했다.

## 옛 판에서 가져온 것 / 가져오지 않은 것
| 옛 개선 요청 판 | 이번 | 이유 |
| --- | --- | --- |
| 모든 화면 상단 버튼 + 떠 있는 창(끌기·크기 조절·위치 기억·반투명 바탕) | 가져옴 | 사용자 지시("언제든 화면에서") |
| 대화 + 요청 카드, 탭(답 필요·진행·끝남·전체) | 가져옴(대화 = 요청 한 건) | |
| 결정 카드: 선택지 카드 버튼(누르면 바로 결정, 기본 선택·라디오 없음), 직접 작성한 안으로 계속, 반려 | 가져옴 | 세션의 결정 요청에 그대로 맞음 |
| 결과 확인: 변경 확인 완료 / 다시 수정 요청 | 가져옴(review 상태) | |
| 구성원 요청은 관리자 승인 | 학교 관리자의 '시스템 기능' 요청은 전체 관리자 승인(pending) | 학교 범위 밖(플랫폼 코드) 변경이라 |
| Enter 보내기 · Shift+Enter 줄바꿈 · 한글 조합 중 Enter 무시 | 가져옴 | |
| Claude API 대화 분류(답변·되묻기·요청 등록), 전용 예산 | **나중** | 사용자 지시. 유료라 비용 추정·승인 뒤(관제 D-5) |
| Mac 연결기 자동 개발·검사·배포, 시뮬레이션 관문 | 세션이 대신함 | 답·개발은 그 대화를 맡은 Claude 세션. 전달은 관제(ADR 0015) |
| 첨부(5개·10MB) | 나중 | 첫 판은 글만. FileDrop 재사용 예정 |
| 변경 표식(stamp)로 조회 줄이기 | 단순 주기 조회(열림 10초·대화 5초·닫힘 60초 숫자만) | 관리자 수가 적음. 늘면 다시 봄 |

## 결정
- 대화 = `control_requests`(kind `chat`) 한 건. 주제 `control`(관제 센터)·`school_ai`(학교 AI)·`site_ui`(홈페이지 인터페이스)·`system`(시스템 기능).
- 학교 대화는 `school_id`를 갖고 RLS가 `app.is_school_admin(school_id)`로 읽기·쓰기를 연다. 메시지의 학교는 트리거가 대화에서 복사한다(다른 학교를 적을 수 없음). 관제 주제는 학교가 없고 전체 관리자만.
- 받을 세션: 대화를 맡은 세션(`assignee_session`) → 그 학교를 맡은 세션(`control_sessions.school_id`) → 없으면 관제가 정함(`control.assign`). 시스템 기능은 학교 세션이 아니라 관제가 정한다.
- 학교 관리자의 시스템 기능 요청은 `pending`으로 들어가고 전체 관리자만 풀 수 있다(트리거 + RLS). 승인 전 글은 전달하지 않는다.
- 세션은 `POST /api/control/requests/<id>/messages {"kind":"message","status":"review"…}`로 답한다. 화면은 주기 조회로 보인다.

## 영향
- DB: 마이그레이션 `20261123001700_chat_dock.sql`(열 추가·정책 교체·control.* 다시 만들기). 되돌리기: 화면에서 `chat` 속성을 빼면 대화창만 사라지고 기록은 남는다.
- 화면: `src/components/ChatDock.tsx`(셸 상단 '대화'), API `/api/chat*`, 세션 API `GET /api/control/requests/<id>`·`POST …/assign`.
