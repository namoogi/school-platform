# 0025. 학사 토대: 한국 + 미국 기준 · 사건 원장 · 마감 판 · 출력 프로필 · 학교 정의 확장

- 상태: **제안** (사용자 검토 후 채택. 채택 전에는 구현하지 않는다)
- 날짜: 2026-11-25 (54차 초안 → 55차 기준 재구성)
- 제안: 관제 세션(Claude)
- 사용자 방향(2026-11-25): "태국이 기준이 되기보다 한국 시스템과 미국(영어) 시스템이 기본이 되고, 태국이나 그 외 나라는 그 시스템을 기준으로 나라별 출력 양식에 맞춰 응용하는 형태."
- 근거:

## 1. 문제
학사정보 시스템은 기능을 하나씩 붙이면 무너진다.
- 드리미포털 학생부: 이름 문자열 연결, 마감 스위치 다섯, 처음 없던 축을 뒤에 끼운 마이그레이션.
- 오픈소스 SIS: 외래키 0개, `ALTER TABLE` 사용자 필드, 코드 업로드 확장의 원격 코드 실행 사고.

우리는 거기에 더해 각 학교가 자기 AI로 기능을 만들고 키우게 하려 한다. 공급사 누구도 하지 않는 일이다. 그래서 기능보다 먼저, 모든 기능이 같은 방식으로 올라설 토대를 정한다.

## 2. 결정 요약
1. **기준은 한국 + 미국.** 핵심 개념·용어·구조는 두 제도를 모두 담을 수 있게 만든다. 한쪽에만 있는 개념도 핵심이나 규칙에 자리가 있다(3절 대응). 태국·영국·캐나다·호주·뉴질랜드 등은 이 기준 위의 **코드·척도·규칙 판 + 출력 프로필**로 응용한다. 다만 출력만으로는 안 되는 공통 구조 다섯 가지는 처음부터 핵심에 둔다(5절 ★).
2. **학사 사실은 모두 '누가 · 무엇을 · 무엇에 대해'로 기록한다**(REA 원장). 화면·서식·통계는 원장의 투영이다.
3. **시간 축 셋을 섞지 않는다**: 업무 유효 기간, 기록 판, **마감 판**. 마감 판은 세 종류다(수업·성적 기간 / 학년도 기록 / 지정일 보고 스냅샷).
4. **국가 서식은 출력 프로필이다.** 첫 출력은 한국 학생부(인가·대안 자체)와 미국 성적증명서·성적표·학교 소개서.
5. **학교의 AI는 코드가 아니라 '정의'를 만든다.** 값·규칙·기록 유형·양식·흐름의 판을 '기능 꾸러미'로 묶는다. 플랫폼이 검증·미리보기·실행하고 사람이 켠다. DDL·코드 업로드는 없다.

## 3. 한국 + 미국 기준 대응
전체 대응표는 `docs/research/sis-rea/us-system.md` 9절에 있다. 여기서는 토대에 미치는 결론만 적는다.

| 개념 | 한국 | 미국 | 토대에서 |
| --- | --- | --- | --- |
| 학년 | 학교급별 학년(초1~고3) | PK·K·1~12 연속 | **학년 코드(표기) + 정규 서수** 두 칸. 영국 Year·호주 Year도 표기만 다름 |
| 학년도·학기 | 3월 시작, 2학기 | 8~9월 시작, 학기·3학기·분기, **학점 학기 ≠ 성적 기간** | 학기 나무의 마디 종류: 학년도 / 학점 학기 / 성적 기간 / 텀. 학교마다 섞어 씀(4텀 + 2학기 동시 허용) |
| 수업일 | 법정 수업일수, 출석 2/3 이수 | 주별 최소 일수·시간, ADA/ADM, 만성 결석 10% | **수업일 달력 + 학적 기간 행**을 1급으로(분모가 필요) |
| 성취·성적 | 성취도 A–E(90/80/70/60/40), 원점수·평균·표준편차, 석차등급 | 글자 성적 A–F(+/−), GPA(가중·비가중), 석차 선택 | 척도 판(백분율 → 등급, 여러 축). **결과의 대상 축**(과목 총괄 / 성취기준·역량 / 습관·품행). GPA·석차·평균은 계산 규칙 판 + 마감 판 고정 |
| 학점·이수 | 고교학점제 192학점, 출석 2/3 | Carnegie 120시간, 주별 졸업 요건 | 과목 판의 학점 + 이수 판정 규칙 + **입학 기수별 졸업 요건 판**(온타리오·뉴질랜드도 같은 꼴) |
| 과목 분류 | 교육과정 과목·선택 분류 | 일반·우등·AP·IB·이중등록·CTE, SCED 코드 | 둘 다 코드 목록(수준 축 ≠ 분류 축). SCED·교육과정 코드는 외부 분류 사상이고 핵심 키가 아님 |
| 수강 | 수강 신청·배정 | 시도 단위(낙제·재수강·보충·철회·미완료) | **수강 시도 = 사건**, 시도 상태·시도 학점·취득 학점. 재수강은 원 시도를 가리키는 새 시도(온타리오 전면 공개도 이것으로) |
| 교사 서술 | 세특(과목별, 공식 기록), 행특(담임) | 성적표 의견, 상담교사 추천서 | **서술은 1급**(작성자 역할: 교과 교사·담임·상담교사, 대상: 과목·학생·학년도). 출력이 다를 뿐 |
| 활동 | 창체 영역(자율·동아리·진로·봉사) | 과외 활동(대개 학생 자기 신고), 봉사 시간 | 학교 정의 기록 유형(E3) + 시간·작성 주체(학교/학생) |
| 출결 | 종류 4 × 사유 3, 연간 집계 | 교시 원천 → 하루 환산(주 규칙), 종류 × 인정 여부 | **교시 출결 사건이 원천**. 코드 두 축(종류 × 사유·인정), 환산·분모는 규칙 판. 수업 단위 AM/PM·교시·분을 담는 시간 축(영국 하루 2회·뉴질랜드 반나절) |
| 학적 | 입학·전입·전출·휴학·자퇴·졸업 | 입학 유형·퇴학 사유(주 코드), 주 학생 ID | 기간 행 + 사유 코드(국가별 코드 목록) + **외부 식별자** |
| 학생부 하나 vs 여럿 | 학교생활기록부 한 문서 | 성적표 + 성적증명서 + 누적 기록 + 상담교사 서류 | 원장은 하나, 출력 프로필이 여럿 |
| 정정 | 마감 후 원칙 금지 → 학업성적관리위원회 심의 → 정정대장 | 교장 승인, 경과 기간별 승인 단계, 사유·서명·감사 | 같은 **정정 판**(사유 코드·원 작성자·승인 단계·통지). 단계·기한은 학교 규칙 판 |
| 당사자 권리 | (일반 개인정보 경로) | FERPA 열람 45일, 수정 요청 → 청문 → 이의 의견서, 공개 기록부, 디렉터리 공개 거부 | **수정 요청 사건**(정정 판과 분리), **기록 주석(진술)**, **공개 사건**, **디렉터리 공개 거부 표시**. 온타리오·호주·뉴질랜드도 같은 꼴 |
| 민감 정보 | 특수교육 대상·다문화 등 | IEP·504·EL·급식·노숙·위탁(법별 보호) | **프로그램 참여 기간 행 + 민감 등급**, 별도 표·별도 RLS·열람 기록부 |
| 보고 | NEIS(국가 원본) | 10월 1일 재적 스냅샷, CRDC | **지정일 보고 스냅샷**(마감 판의 셋째 종류). 영국 센서스·호주 8월 센서스도 같은 꼴 |
| 대안 형식 | 대안학교 자체 학생부 + 편제표 | Mastery Transcript, 홈스쿨·소규모 사립 묶음 | 역량 + 증거 + 확인 → 출력 프로필 |

한쪽에만 있는 개념:
- **한국에만**(핵심 또는 규칙에 자리 마련): 석차등급, 원점수·평균·표준편차 기재, 세특, 창체 영역, 출석 2/3 이수, 휴학, 학업성적관리위원회.
- **미국에만**: GPA, 과목 수준 가중, 성적 기간 분리, FERPA 권리, 프로그램 참여 보호, 만성 결석, 보고 스냅샷, 학교 소개서·CEEB.

## 4. 원장 모델 (REA로 본 학사)

| REA | 우리 개념 | 예 |
| --- | --- | --- |
| 행위자 | 사람(`people`)과 역할(학생·교직원·보호자·멘토·상담교사·외부 강사), 학교, 외부 기관(시험 기관·수여 기관) | 담임이 출결을 기록, 위원회·교장이 정정을 승인, 시험 기관이 결과를 보냄 |
| 사건 | 날짜가 있는 사실 하나. 추가만 하고, 정정은 원 사건을 가리키는 새 사건 | 입학·전학, 수강 시도, 출결, 결과, 서술, 증거 제출, 확인(서명), 수정 요청, 공개, 마감, 발행, 수여 |
| 자원 | 사건이 쓰거나 만드는 것 | 수업 자리, 학점·이수, 역량 성취, 자격(졸업장·인증), 발행 문서, 산출물 |

- **쌍대성**: 수강 시도는 자리를 쓰고, 이수 판정은 학점을 만들고, 자격 수여는 학점·요건을 소비한다. 합계(학점·GPA·졸업 진행)는 언제나 사건에서 다시 셀 수 있어야 한다. 트리거로 덮어쓴 합계를 원본으로 삼지 않는다.

## 5. 핵심 층 (플랫폼 소유, 모든 표 `school_id` + RLS + 복합 FK)
✔ 있음 / ＋ 추가 / △ 보강. ★ = 영어권 조사에서 '출력만으로 안 되고 핵심에 필요'로 나온 것. 표 이름은 가칭이다.

| 층 | 내용 | 표 |
| --- | --- | --- |
| L0 학교·계정 | 테넌트, 계정, 소속 권한, 학교의 관할·부문·인가 | ✔ `schools` · `memberships` · `person_accounts` / △ 학교 관할·인가 칸 |
| L1 학사 구조 | 학교급, 학년 코드 + 정규 서수, 학년도, **학기 나무**(마디 종류: 학점 학기·성적 기간·텀, 입력 창), **수업일 달력**, 반·기수 | ✔ `school_levels` · `academic_years` · `cohorts` · `homerooms` / △ `terms`(나무·종류) / ＋ `grade_levels` · `calendar_days` |
| L2 사람·관계 | 사람, 이름 이력, ★**외부 식별자**(체계·상태 임시/정식/대체·범위·검증), 학적(기간 행 + 사유 코드, 학적 속성도 기간 사건), 가족·보호자, 교직원 배정, **디렉터리 공개 거부**, **프로그램 참여**(민감, 별도 RLS) | ✔ `people` · `person_names` · `enrollments_school` / ＋ `external_identifiers` · `families` · `guardian_links` · `staff_assignments` · `directory_optouts` · `program_participations`(민감 확장) |
| L3 배움의 틀 | 과목(판, 학점·수준·외부 분류 사상), 표기 판, 갈래 규칙, 개설(기원: 학교·학생 제안·프로젝트·인턴십), 담당·수강, **수강 시도**, 수업 제안 판, 역량 틀(CASE 모양), ★**자격 층**(자격·입학 기수별 요건 판·학점 원천·수여 사건) | ✔ `subjects` · `course_types` · `course_offerings` · `offering_staff` · `offering_enrollments` / ＋ `subject_labels` · `course_attempts` · `course_proposals` · `competency_frameworks` · `competency_items` · `competency_links` · `rubrics` · `qualifications` · `qualification_requirements` · `qualification_awards` |
| L4 사건 원장 | ★**출결 사건**(시간 축: 수업 단위 AM/PM·교시·분, 코드 두 축, 통계 범주), 평가 항목, 결과(`result_kind` + **대상 축**), 서술(작성자 역할), 증거물, 확인·서명, ★**외부 결과**(시험 기관·회차·잠정/확정/재채점, 읽기 전용 판) | ＋ `attendance_events` · `assessments` · `assessment_results` · `narratives` · `evidence_items` · `attestations` · `external_results` |
| L5 규칙 | 학교별 코드 목록(표준 사상·유효 기간·이전 코드), 척도 판, 계산 규칙 판(GPA 가중·석차·평균·출결 환산·분모·글자 수·자료 단위), 정정 흐름 규칙(승인 단계·기한), 보존 규칙. 모든 규칙 판에 '왜'(결정 근거) 칸 | ＋ `code_lists` · `scales` / △ `school_settings`(판) |
| L6 마감·권리·발행 | **마감 판 3종**(수업·성적 기간 / 학년도 기록 / ★지정일 보고 스냅샷), 정정 판, ★**수정 요청 사건**·**기록 주석(진술)**, **공개 사건**(발급·이관·외부 제출), 발행본 스냅샷, 출력 프로필 판 | ＋ `closures`(종류) · `correction_requests` · `record_annotations` · `disclosures` · `output_profiles` / ✔ `published_documents` · `document_templates` |

원칙:
- 사람·수업·과목·학교는 id로만 참조한다(지침 7). JSON 안에 참조를 숨기지 않는다.
- 사건 행은 추가만 한다. 정정 사건은 `corrects_id`로 원 사건을 가리킨다. 현재 값은 뷰·계산 캐시다.
- 마감 판은 적용한 규칙·척도·코드·표기 판 id를 고정한다. 정정은 이전 판을 가리키는 새 판이다.
- 국가 제도(성취평가제, 석차등급, GPA 가중, 태국 0–4·มส·ร, 영국 9–1, NCEA N/A/M/E, 온타리오 수준 1–4)는 **척도·코드·규칙 판 + 출력 프로필**로 들어온다. 핵심 표에 열로 박지 않는다.
- 민감 정보(프로그램 참여, 국가 ID)는 별도 표·별도 RLS·열람 기록부. 일반 성적·출결 경로에서 조인되지 않는다(지침 9).

### 5-1. 드리미포털 학생부에서 배운 것 (`docs/research/portal-gradebook-review.md`)
- **표기는 판이다.** 학생부 과목명은 '대학 제출용 표기'이고, 바꾸는 것이 정상 실무다. 학생부 행 = 개설 id + 표기 판 id. 표기를 바꿔도 모집단·통계는 그대로다.
- **자료 단위를 정의에 둔다.** 성적·수상은 학기, 창체·봉사·자격증은 학년도처럼 정한다. 학기 키 하나에 연 단위 자료를 묶었다가 그 해 기록이 사라진 사고가 있었다.
- **규칙은 DB에, 계산은 판 + 경계값 시험.** 마감·정정·참조는 DB 제약·트리거·명령 함수로 막는다. 반올림·분할점·가중치는 판으로 두고 경계값 시험을 붙인다.
- **규칙 판에 '왜' 칸을 둔다.** 학교 AI가 규칙 변경을 제안할 때 그 칸을 먼저 읽는다. 사고에서 나온 규칙은 밖에서 보면 비일관으로 보이기 때문이다.
- **양식은 렌더 판, 자료는 하나.** 발급 당시 양식은 출력 프로필·템플릿 판으로 고정한다.
- **자국(수정 이력)은 모든 판 표에.** 학생과 무관한 정의 변경도 남긴다.
- **학교의 정상 실무를 AI에게 알린다.** 포털 AI가 표기 변경을 '위조'로 거절한 사고가 있었다. AI 연결 글(ADR 0022)에 학교의 정상 실무 목록을 싣는다.

## 6. 확장 사다리 — 학교(와 학교의 AI)가 기능을 만드는 방법

| 단 | 무엇을 바꾸나 | 예 | 누가 · 어떻게 |
| --- | --- | --- | --- |
| E1 값 | 코드 목록에 학교 값 | 출결 사유, 관계, 결과 수준, 갈래, 학적 사유 | 학교 관리자·학교 AI(범위 토큰). 즉시, 판으로 |
| E2 규칙 | 판이 있는 규칙·척도('왜' 칸 포함) | GPA 가중, 반올림, 글자 수, 출결 환산, 졸업 요건, 정정 승인 단계 | 학교 관리자 승인으로 새 판. 마감 판은 옛 판을 고정 |
| E3 기록 유형 | 학교 정의 기록: 필드 정의(JSON Schema 판) + 일반 기록 표, 자료 단위·개인정보 등급 포함 | 창체·독서·봉사 시간·신앙생활·상담·동아리·트랙 프로젝트 | 학교 AI가 정의 판을 만들고, 검증기를 통과하면 관리자가 켬. 사람·수업 참조는 정해진 열로만 |
| E4 화면·출력 | 양식, 목록 보기, 출력 템플릿 | 관찰 기록 양식, 자체 학생부, 학교 소개서 | 정의 판 → 플랫폼 렌더러. 합성 자료로 미리보기 |
| E5 흐름 | 선언형 상태 흐름 | 초안 → 검토 → 승인 → 마감, 학생 수업 제안, 정정 요청 | 정의 판 → 플랫폼 흐름 엔진. 상태 전환은 사건 |
| E6 모듈 승격 | 여러 학교가 같은 E3 유형을 쓰면 형이 정해진 표로 | — | 관제 세션이 ADR + 마이그레이션으로 |

**기능 꾸러미**는 하나의 기능을 이루는 E1~E5 정의 판의 묶음이다. 켜고 끄고 되돌릴 수 있다.

**학교 AI의 작업 순서**(범위 토큰을 정의 종류로 넓힘):
1. 명세: 학교 요구를 꾸러미 초안으로 쓴다.
2. 검증: 스키마 형식, 숨은 참조 금지, 필드별 개인정보 등급, 핵심 마감·정정 규칙 불변, 이름 충돌을 검사한다.
3. 미리보기: 합성 자료로 확인한다.
4. 켜기: 관리자가 켠다.
5. 모든 정의 변경은 판이고 `base_version` 409를 따른다.

하지 않는 것:
- 에이전트 DDL
- 코드·스크립트 업로드
- 핵심 표에 열을 더하는 사용자 필드
- 학교가 마감·정정 규칙 자체를 끄는 것

## 7. 출력 프로필 (국가·학교 서식)
- 하나의 원장에서 서식별 스냅샷을 낸다. 출력 프로필 판이 필드 매핑, 코드·척도 변환, 글자 수 검사, 가림, 출력 제약(예: 'IE는 성적 증명서에 못 씀')을 맡는다.
- **기준 출력(먼저)**:
  - 한국 학생부(인가), 한국 대안학교 자체 학생부 + 교육과정 편제표(드리미)
  - 미국 성적증명서(공식·비공식, 설명표 자동 첨부), 미국 성적표(전통형·성취기준형), 학교 소개서
- **응용 출력(나중, 기준 위에서)**:
  - 태국 ปพ.1·ปพ.5(룽아룬숙사), CLR 2.0·OB 3.0·Mastery 형식
  - 영국 CTF·센서스, 온타리오 OST, BC 성적증명서, 호주 A–E 보고, NCEA
  - 미국 주 보고(Ed-Fi 내보내기)
- 변환에서 정보가 빠지거나 규칙이 충돌하면 질문을 연다(지침 6).
- 국가 시스템(NEIS·DMC·주 SIS)의 원본은 국가 쪽이다. 우리 출력은 보조부·제출용이다.

## 10. 위험과 대응
- **정의 엔진이 '두 번째 데이터베이스'가 될 위험**:
  - 참조는 열로만 둔다.
  - 승격 기준을 둔다(3개 학교 이상 사용, 또는 마감 판 대상).
  - E3 값은 승격 전까지 마감 판에서 기본 제외한다.
- **AI가 만든 정의의 품질**: 검증기와 합성 자료 미리보기를 통과해야 하고, 켜는 것은 사람이다.
- **관제 권한 집중**(ADR 0024, PowerSchool 2024 유출 교훈):
  - 점검 토큰 기한을 짧게 둔다.
  - 학교 입장·변경을 기록한다.
  - 관제 활동을 요약해 보여 준다.
  - 이상 활동 알림을 둔다(후보).
- **규정 변경**(기재요령 매년 개정, 온타리오 졸업 요건 판, 뉴질랜드 출결 코드 개편): 규칙·출력을 판으로 둔다. 원문 재확인 목록을 연 1회 점검한다.
- **근거의 한계**: 이번 조사는 많은 1차 출처(정부·표준 기관)가 네트워크에서 막혀 검색 발췌로 확인했다. 구현 단계에서 해당 규정은 원문을 다시 확인한다.
