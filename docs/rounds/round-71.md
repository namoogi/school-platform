## 한 일
- **학기 구조 직접 정하기** `src/lib/academics.ts` `definePeriodRule`
  - 자료 첨부 없이도 관리자가 **근거와 함께** 확정 규칙 새 판(`decision='edited'`)을 만든다.
  - 기존 판은 남고 `base_version` 409를 따른다. 기존 검사기(`validatePeriodValue`)와 RLS(관리자·본인 확정자)를 그대로 쓴다.
- **화면**
  - `/academics` 학교 구조
    - 학교급 목록·추가
    - 학기 구조: 현재 판·근거, 한 줄에 '열쇠 이름'으로 새 판
    - 학년도: 추가, 학기 구조 판으로 학기 만들기, 학기별 날짜
  - `/people` 사람·학적
    - 왼쪽: 찾기·목록(오늘 재학 학교급 표시)·사람 추가
    - 오른쪽: 학적(등록·끝내기: 졸업·전출·자퇴, 확인 창), 이름 판(이유와 함께 새 판)
  - 레일에 '구조'·'사람'을 더했다(학사 문서실 라이선스).
- **API**: `POST /api/academics`(level·year·rule·terms·term-dates), `POST /api/people`(add·rename·enroll·end-enrollment), `GET /api/people/<id>`
  - 쓰기는 모두 기존 DB 명령 함수가 관리자를 확인한다.
- **공용 작은 양식** `src/components/ActionForm.tsx`: 칸 → JSON → 새로 고침. 오류 문구를 그대로 보이고, 되돌리기 어려운 일은 확인 창을 띄운다. 72~76차에서 다시 쓴다.
