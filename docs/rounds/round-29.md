# 29차: 룽아룬숙사 학교 자동 준비 (이전 4a단계)

## 결정 (사용자, 2026-11-23)
'Rungarun Example School'(예시 학교)을 바꾸지 않고, 실제 학교를 새로 만든다. 예시 학교를 쓰지 않는 이유는 세 가지다.
- 배포마다 시드가 이름과 예시 관리자를 되돌린다.
- 지울 수 없는 예시 기록이 실제 학교 기록에 섞인다.
- 테스트가 예시 학교를 기준으로 돈다.

## 한 일
- `ops/schools.json`: 운영에 한 번만 만들 실제 학교 목록이다. 이름·언어·좌석·기능·사이트 설정만 담고, 이메일·개인정보는 넣지 않는다.
- `scripts/provision.mjs`
  - 운영 빌드(`VERCEL_ENV=production`)에서 시드 다음에 실행한다.
  - 학교가 없을 때만 전체 관리자 권한으로 `app.create_school`을 부른다. 그래서 라이선스 판과 운영 기록이 평소처럼 남는다.
  - 사이트 설정은 홈페이지를 닫은 상태로 넣는다.
  - 이미 있는 학교는 바꾸지 않는다. 실패해도 배포는 막지 않는다.
  - 첫 학교 관리자는 `PLATFORM_ADMIN_EMAILS`의 첫 계정이다.
- 룽아룬숙사 설정
  - 학교: 주소 `rungarunsuksa`, 이름 'Rung Arun Suksa'(학교 화면에서 바꿀 수 있음), 태국어, 시범, 좌석 10
  - 기능: 학교 제도 분석(필수)·학교 홈페이지·성품 동화
  - 홈페이지: `/s/rungarunsuksa`, 태국어 기본·영어·한국어, 닫힘
