## 한 일
- **자료 받기:** 선생님 컴퓨터의 룽아룬숙사 세션이 정리한 MIGRATION.md·content.json·manifest·book.json·후원자 글·CSS를 세션 대화 기록으로 받아 sha256으로 확인했다(저장소에는 넣지 않음).
- **새벽빛 매거진(dawn) 테마** — `.site[data-theme="dawn"]` 범위 안에서만 옛 Edition 9 토큰(남색 #193f67, 종이 바탕, 모서리·그림자 없음, 1px 선, 명조 제목, 무지개 선)을 정의. 서체는 fontsource(Manrope·Noto Sans/Serif Thai·Noto Serif KR, 모두 OFL, 공개 2주 지난 판).
- **블록 확장** (`site-shared.ts`·`site.ts` 검사·`SiteRenderer`·편집기)
  - `section`: 글·사진 왼쪽/오른쪽·넓은 사진·카드·사진 줄·항목–내용·차례·인용·안내 단추 10모양. 링크는 사이트 안 경로나 https만.
  - `gallery.items/filters`: 사진별 묶음·대체 글, 거르기 단추(aria-pressed) + 크게 보기(`<dialog>`, Esc·←→).
  - `news_list`: 공개된 소식 N개(볼 것이 없으면 안 보임).
  - `content.site`(home 판): 로고·소개·주소·전화·페이스북·방문 단추 → 머리·바닥. `content.head`: 머리말·여는 머리(표지 파노라마).
  - 동화 `meta.text_in_image`: 그림 안에 글이 있으면 글은 화면 읽기용(sr-only) + 그림 대체 글.
- **기존 홈페이지 가져오기** (`/site` 설정 칸, 학교 관리자): zip을 브라우저에서 fflate로 풀고(20MB 넘는 영상은 풀지 않음) → 만들 것 미리 보기 → 그림 한 장씩 올림(요청 한도 안) → 시안 생성(있는 항목은 새 판으로 더함) → 설정(새벽빛·th/en/ko) → '가져온 시안 모두 공개'. 변환은 `src/lib/site-import.ts`(순수 함수).
  - 학교 쪽 7개(home·about·curriculum·life·gallery·admissions·contact), 소식(기본 소식 4편), 동화 1편, 후원자 숨은 쪽(`friends/pages.json`이 묶음에 있으면).
- **옛 주소 호환:** `/s/<학교>/<key>` → `/p/<key>`, `/s/<학교>/friends/**` → 숨은 쪽(`?lang=ko` 기본), 308. 옛 사이트의 넘겨주기는 `/:path* → /s/rungarunsuksa/:path*` 한 줄이면 된다.
- 설정 양식이 가져오기 뒤 예전 값으로 덮어쓰던 문제를 고쳤다(설정이 바뀌면 양식을 다시 염).

1. 운영 `/site` → 설정 칸 → '기존 홈페이지 가져오기'에 묶음 zip을 올린다(friends/pages.json이 들어간 판).
2. 시안 미리보기로 확인 → '가져온 시안 모두 공개' → '홈페이지 열기' 저장.
3. 동화: 성품 이름, 영상 위치(YouTube 일부 공개 또는 Drive). 학교 공식 태국어 이름 확인.
