# 52차: 룽아룬숙사 홈페이지 정돈 — 새벽빛 디자인 체계 + 내용 재구성

- 날짜: 2026-11-24 · 세션: 관제
- 사용자 지시: "구성이 다소 정돈되지 않고, 기본 UI, UX 방향이 없이 사진과 텍스트가 그냥 나열된 느낌이다. UI, UX에 대한 여러 도구들 중 적용 가능한 것들을 선별하여, 레이아웃 구성부터 컨텐츠들이 정돈되고 알찬 느낌으로 구현하자."
- 범위 결정(사용자): 틀+내용 모두, 확인 안 된 메모는 방문자에게 숨김.

## 진단
구역 모양마다 제목 크기(25~42px)·사진 비율·맞춤이 달랐고, 구역 사이 간격과 배경이 같아 쪽의 마디가 없었다. 같은 활동 사진이 세 쪽에 반복됐고, "확인 필요·확인 중" 같은 작성 메모가 방문자에게 보였다. 동화 목록이 마지막 안내 띠 뒤에 붙어 첫 화면이 안내로 끝나지 않았다.

## 한 일
- 디자인 체계: `docs/design/DAWN-SYSTEM.md`(고른 도구와 근거), `globals.css` '52차' 절 — 글자 5단계, 구역 간격 하나, 사진 4:3 채우기, 사진–글 5:7 가운데 맞춤·짝수 줄 좌우 바꿈, 배움·안내 띠 연회색 띠, 카드 3단·동화 4단, 메뉴 14px.
- 첫 화면: 자동 동화 목록을 마지막 안내 띠 앞으로(`src/app/s/[slug]/page.tsx`).
- 룽아룬숙사 내용(관제 세션이 운영에 적용): 첫 화면 '한눈에 보기' 추가, 학교 소개는 학교 공간 그림으로(활동 줄은 학교생활에만), 문의 쪽의 겹치는 질문 목록 제거, 확인 메모는 방문자 문장으로 고치고 원문은 쪽마다 숨긴 '관리자 메모'에.
