## 한 일
- **화면** `/records?p=<학생>` 기록
  - 학년도 기록 마감 판
    - 학년도별 판·과목 수·수업일을 보인다.
    - 마감(확인 창)하면 DB가 학적·성적 마감 판·출결·서술을 모아 얼린다.
    - 다시 마감하면 사유와 함께 새 판이 되고, 화면이 본 판을 `base_version`으로 보낸다(409).
  - 발행
    - 형식: 학교생활기록부(학교 자체)·미국 성적증명서·태국 ปพ.1 학교 사본·영어권 학업 기록, 블라인드 선택
    - 발행본 목록에 확인 질문 수·공개 기록 수를 보인다.
  - 외부 결과(기관 발급, 고치지 않고 정정 행)·자격(학점 요건 확인) 기록
  - 학교 단위
    - 학교 소개서 발행
    - 지정일 보고 마감: 재학생 수·한국 학교 통계·미국 가을 재적. 집계만 얼리고 재학·출석률·만성 결석·자격 수를 보인다.
- **발행본 보기** `/records/doc/<id>`
  - 저장한 스냅샷(content)만 그린다(지침 5). `RecordDocumentView`가 형식과 관계없이 배열은 표, 객체는 정의 목록으로 그린다.
  - 해시를 다시 계산해 '내용 확인됨' 또는 '확인값 불일치'를 보인다.
  - 발행 때 남긴 확인 질문을 보인다.
  - 인쇄·PDF 단추를 둔다. 인쇄할 때는 종이만 남는다.
  - 공개 기록(받는 곳·목적·근거)을 남기고 목록으로 보인다.
- 학생·보호자 `/my/documents/<id>`도 JSON 대신 같은 `RecordDocumentView`·인쇄 단추로 보인다(열람 계약이 준 내용만).
- **API** `POST /api/records` (close-year·publish·disclose·external·qualification·count-report)
- **읽기** `src/lib/recordbook.ts`: `documentsOf`·`disclosuresOf`·`externalResultsOf`·`qualificationsOf`
- 73차 성적 화면의 과목 서술 종류를 KR 학생부 렌더러가 읽는 `subject_detail`로 맞췄다(73차 PR에 포함).
