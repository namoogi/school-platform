# 58차: 관제 기본판 · 학교 복제 · 보고 계약 (ADR 0027)

- 날짜: 2026-11-25 · 세션: 관제
- 사용자 지시: 관제는 기본 얼개를 갖고, 학교 생성 때 복제 → 이후 학교 AI가 구조를 바꿀 수 있으므로 관제와 학교가 DB로 묶이면 안 된다. 느슨하고 유동적인 구조로 하되, 관제는 학교 기본 정보를 통일된 길로 모은다. 선택: 논리 분리 먼저, 기본판 갱신은 제안 → 학교 수락.
