# 69차: 기존 사이트 이전 운영 시험 반영 — 경로 안만 읽기 · 태국어 단서 · 전화 패턴

- 날짜: 2026-11-26 · 세션: 관제
- 계기: 67차 배포 뒤 운영에서 실제 공개 학교 홈페이지(룽아룬숙사 `/s/rungarunsuksa`, 태국어)로 **읽기 전용 제안**을 시험했다.
  - 학교 자료에는 쓰지 않았다. 작업 학교 선택은 시험 뒤 지웠다.
  - 결과: 8쪽을 3.4초에 읽었고 그림 13장을 찾았다. 제안은 1개(바닥 연락처)뿐이었고 전화번호가 틀렸다.

## 고친 것
1. **경로 안만 읽기** `site-crawl.ts`: 시작 주소가 하위 경로(`/s/학교`)면 그 경로 아래만 따라간다. 같은 호스트의 플랫폼 로그인 쪽까지 읽던 문제를 막았다.
2. **단서 낱말 넓히기** `site-autofill.ts` `widenClues`: 템플릿 단서(한·영)에 태국어 같은 뜻 낱말을 더한다(사명 พันธกิจ, 연혁 ประวัติ, 입학 รับสมัคร, 연락처 ติดต่อ, 학비 ค่าเล่าเรียน 등). 낱말 표는 다른 언어로 넓힐 수 있다.
3. **태국 주소** 패턴(ตำบล·อำเภอ·จังหวัด + 우편번호 5자리)
4. **전화번호 패턴**: 앞뒤가 숫자인 긴 숫자열에서 잘라 내지 않는다. 0으로 시작하는 국내 번호와 +국가 번호를 본다.

## 배포 뒤 다시 시험(같은 날)
- 좋아진 것: 태국 주소를 '높은 확신'으로 찾았다. 국제형에서는 입학 여정(ประกาศปีการศึกษา…)도 찾았다.
- 남은 문제 두 가지를 이어서 고쳤다.
  - 한 쪽이 학교 경로 밖(플랫폼 로그인)으로 **리디렉트**되어 읽혔다 → 최종 주소가 경로 밖이면 건너뛴다('사이트 밖으로 넘어감').
  - 태국 전화가 두 묶음(062-0626837·045-953270)이라 못 찾았다 → 두 묶음 형식도 받는다.
- 시험: `site-autofill` +1 검사(두 묶음 전화), `site-crawl` 리디렉트로 경로 밖 쪽 건너뜀.
- 사명·후원 쪽은 이 사이트에 해당 제목이 없어 제안이 없다. 자료에 없는 칸은 비워 두는 것이 맞다.
