# 40차: 어디서나 여는 대화창 — 옛 개선 요청 판 이식 (ADR 0016)

- 날짜: 2026-11-23 · 세션: 관제(학교 플랫폼 전체)
- 사용자 지시: 옛 시스템 개선 요청 판의 구성·기능을 전체 관리·학교 관리에 붙여 관리자들이 대화로 시스템을 개선. 언제든 화면에서 대화창을 열어 관제 센터·학교 AI·홈페이지 인터페이스·시스템 기능에 쓰고, API 자동 답변은 나중, 세션이 응답.

## 한 일
- **대화창**(`src/components/ChatDock.tsx`): 셸 상단 '대화 n'(사람이 답·확인할 건수). 떠 있는 창(끌기·크기 조절·위치 기억·크게 보기·반투명 바탕), 왼쪽 목록(답 필요·진행·끝남·전체) / 오른쪽 대화. 760px 미만은 목록↔대화 전환.
- **대화 안**: 결정 카드(선택지 카드 버튼 = 바로 결정, 직접 작성한 안으로 계속, 이 변경 반려), 결과 확인(변경 확인 완료·다시 수정 요청), 승인 대기(전체 관리자 승인·반려), Enter 보내기·Shift+Enter 줄바꿈·한글 조합 보호.
- **범위**: 전체 관리 화면 = 모든 대화. 학교 화면(학교 관리자) = 그 학교 대화. 학교 관리자의 시스템 기능 요청은 승인 대기.
- **DB**(`20261123001600_chat_dock.sql`): 대화 주제·학교·맡은 세션, 메시지 deliver·학교(트리거), RLS 교체, 승인 대기 보호 트리거, control.* 갱신(thread·assign, inbox에 최근 10줄).
- **세션 쪽**: 대화 답하기·결정 요청을 학교로 보내기·맡은 세션 정하기(`docs/automation/CONTROL-CENTER.md`).
