## 한 일

  - 미리 찍어 저장소에 넣는다. 다시 찍기: 로컬 서버 → `npm run templates:thumbs`(로컬 주소만, 합성 계정).

- **예시 내용 미리보기**: `src/lib/site-template-samples.ts`
  - 템플릿마다 지어낸 가상 학교(물빛초등학교·숲속이야기학교 등)로 `[ … ]` 안내 자리를 채워 완성 모습을 보인다.
  - 연락처는 가상 값만(메일 `@example.org`, 전화 `000-000-0000`, 주소 '가상시').
  - 미리보기에서만 쓴다. '시작하기'로 학교에 만드는 시안에는 안내 자리가 그대로 들어간다(ADR 0031 그대로).
