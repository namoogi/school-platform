# 81차: 연구소 개편 — 카드로 한눈에 · 상세는 표·도식 · 하단 지침으로 진행

- 날짜: 2026-11-26 · 세션: 관제
- 사용자 지시: "연구소는 각 항목을 줄글 리스트로 두지 말고, 각 항목은 카드로 구성해서 직관적으로 한눈에 전체 내역을 볼 수 있도록 하고, 세부 내용은 텍스트 디자인·인포그래픽·도식과 표를 이용해 파악하고 고민할 수 있도록 구성하자. 연구소의 각 제안에 대한 지침을 하단에 입력하고 그에 맞춰 내용이 진행될 수 있는 구조도 만들자."
- 판단
  - 지침은 관제 센터 '지시'(`createDirective`, `control_requests.lab_item_id`)를 그대로 쓴다. **새 표·새 쓰기 경로가 없다**(AGENTS.md: 경로는 역할마다 하나).
  - 세션은 이미 `/api/control/mine`으로 자기 일을 당겨 오므로 그대로 받는다.

## 한 일
- **카드 보드** `/admin/lab`
  - 탭: 전체(기본)·할 일·기획·도구·방법론·연구소
  - 카드에 보이는 것: 종류 색 띠와 이름, 상태, 우선순위(▲·▽ 기호 함께), 결과 확인이 필요한 지침 수, 제목, 본문 첫 문단 요약, 연결된 할 일 진행 막대
  - 카드 꼬리: 표·도식 수, 지침 끝남/전체, 기한, 태그, 고친 날
  - 할 일 카드는 체크로 끝낸다. 빠른 추가는 '전체'에서 종류를 고른다.
- **상세** `/admin/lab/<id>`
  - 본문을 서식으로 그린다(`src/lib/richdoc.ts` 해석기 + `RichDoc`): 제목·문단·목록·표, 강조 상자(결정·주의·메모), 인포그래픽 블록
    - 지표 타일 `kpi`
    - 화살표 흐름도 `steps`
    - 가로 막대 `bars`
    - 아래가 넓은 계단 `tiers`
  - 옆 칸: 목차, 진행(지침 수·할 일·상위 항목), 관리(상태·우선순위·내용 고치기·보관)
  - 고치기: 쓰기/미리 보기 탭과 서식 도움말
  - HTML은 해석하지 않고 React 요소로만 그린다. 링크는 http(s)만 허용한다.
- **지침과 진행**(상세 맨 아래)
  - 지침마다 번호·상태와 대화(선생님 지침, 세션 보고)를 시간순으로 보인다. 세션 보고도 같은 서식으로 그린다.
  - 새 지침 입력란이 있다. 받을 세션은 기본이 관제이고, '새 세션 만들어 실행'도 고를 수 있다.
  - 지침은 관제 센터로 가고, 관제 센터의 해당 요청으로 가는 링크(`#r-<번호>`)를 둔다.
- `docs/automation/CONTROL-CENTER.md` '세션: 연구소 지침 처리': 세션이 지침을 받아 → 일하고 → 항목 본문을 서식으로 고치고 → 요청에 보고(review)하는 절차

## 고침(같은 날)
- 선생님: "카드를 눌러도 아무 변화가 없네." — 제목 글자에만 링크가 있었다. 제목 링크를 카드 전체로 늘려(`::after` 덮개) 카드 어디를 눌러도 상세로 간다. 할 일 체크 상자는 덮개 위에 두어 따로 눌린다. 키보드 초점은 카드 테두리로 보인다. e2e는 카드 아래쪽 빈 곳을 눌러 상세로 가는지 본다.
