# 88차: 홈페이지 설정 '저장했습니다' 표시가 가끔 사라지던 문제(e2e 불안정) 원인 고침

- 날짜: 2026-11-27 · 세션: 학교 홈페이지 기능·템플릿
- 계기: 관제 알림(2026-11-27). PR #129 CI(실행 45929568165)의 e2e '27차 학교 홈페이지' 단계가 `[data-testid=site-settings] [role=status]:has-text("저장했습니다")`를 기다리다 30초 시간 초과로 실패했다. 이전에 `router.replace('/site?box=settings')`로 고쳤지만 다시 났다.

## 원인
- `/site` 쪽은 설정 폼을 `key={settings.updated_at}`로 그린다.
- 저장하면 `updated_at`이 바뀐다. 화면이 새로 읽히면(`router.refresh`) 폼이 **새로 그려지고**, 폼 안의 '저장했습니다' 상태가 사라진다.
- 그래서 표시가 남는지는 새로 읽기가 언제 끝나는지에 달려 있었다. 빠르면 표시가 바로 지워져 시험이 실패했다.

## 고침
- 저장 뒤 주소를 `/site?box=settings&saved=1`로 바꾼다.
- 쪽이 `saved` 값을 폼에 넘기므로, 새로 그려진 폼도 '저장했습니다'로 시작한다.
- 표시를 넘겨받은 폼은 주소에서 `saved=1`을 지운다(`history.replaceState`, 서버를 다시 부르지 않음). 새로 고침·즐겨찾기로 다시 열면 표시가 나오지 않는다(Codex 지적 반영).
- 폼을 새로 그리는 방식(`key`)은 그대로 둔다. 다른 곳에서 설정이 바뀌어도 최신 값으로 다시 읽어야 하기 때문이다.
