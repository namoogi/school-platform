# 115차: 멈춤 방지 — 차례를 끝내는 글의 표시 + Stop 훅 (ADR 0044)

- 날짜: 2026-11-28 · 세션: 관제
- 사용자: "추천 프롬프트의 대부분이 사람의 판단이 꼭 필요하다기보다는 다음 프로세스로 넘어가면 되는 것들인데 멈춰있는 경우가 많이 있다. … 다음 프로세스를 진행하는 문구는 자동입력해 줄 수 있나?" → 선택: '멈춤 방지 훅 + 규칙 (추천)'

> **요약** 세션이 "다음엔 X 하겠습니다"로 끝내면, 저장소에 넣은 훅이 한 번 막고 "다음 단계를 지금 진행하라"를 넣는다. 사람 판단이 필요하거나(`[결정 필요]`) 기다리는 중이거나(`[대기]`) 끝났으면(`[완료]`) 그 표시를 붙여 끝낸다.

> **왜** 규칙은 이미 '멈추지 말라'였지만, 세션은 차례를 끝내면 깨울 것이 없어 멈췄다. 앱의 추천 프롬프트를 대신 눌러 주는 기능은 없다. 그래서 끝내는 순간을 검사한다.

```terms
용어 | 쉬운 설명 | 예시
Stop 훅 | 세션이 차례를 끝내려는 순간 저장소의 검사 프로그램이 한 번 보는 장치 | "CI 통과하면 병합하겠습니다"로 끝내면 → 막고 "지금 진행하라"
표시 | 끝낼 이유를 글 끝에 남기는 약속 | [결정 필요] 예산 승인 필요 · [대기] CI 감시 걸어 둠 · [완료]
```

## 확인하지 못한 것
- 이미 열려 있는 세션에는 설정을 다시 읽을 때까지 적용되지 않을 수 있다. 새 세션부터 확실히 적용된다.
- 클라우드 세션에서 저장소 훅이 신뢰 확인 없이 도는지는 문서로 확정하지 못했다. 병합 뒤 다음 세션에서 확인한다.
