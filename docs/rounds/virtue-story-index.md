# 성품별 동화 목록 (2026-11-23)

사용자 요청: 동화마다 큰 갤러리 카드를 반복하는 대신 성품별 캐릭터와 에피소드 제목으로 목록을 구성한다.

## 구현

- 공개 목록을 성품·캐릭터별로 묶고 기존 이야기 순서를 유지한다. PC 2열, 640px 이하 1열이다.
- 각 구역은 캐릭터 그림, 성품, 캐릭터 이름, 제목 링크로 구성한다. 요약과 장면 표지는 반복하지 않는다.
- 성품을 지정하지 않은 공동 이야기는 ‘함께 읽는 이야기’로 따로 둔다.
- 캐릭터 그림은 목록에 공개된 동화의 PNG 다운로드 갤러리에서 가져온다. 시안·숨긴 블록·unlisted 동화·일반 장면 이미지는 쓰지 않는다. 그림이 없으면 성품과 이름으로 표시한다.
- 기존 공개 함수와 익명 읽기 권한만 사용한다. DB 변경은 없다.

## 확인

- 최신 main(42차 디자인 변경) 통합 후 단위 테스트 51개, 타입 검사, 저장소 검사, 운영 빌드 통과.
- 실제 33편 제목과 확보한 8종 원본 PNG를 사용한 임시 로컬 화면에서 11개 성품과 공동 이야기 구성을 Chrome으로 확인했다. 임시 화면과 복사 이미지는 커밋에서 제외했다.
- 로컬 PostgreSQL이 없어 DB 통합 테스트와 전체 E2E는 미실행. 모바일은 CSS 구현만 확인했다.
