# 28차: 흰 화면 선을 회색 계열로 (디자인 다듬기)

## 목적 (사용자 지시)
흰 화면에서 표·입력 칸의 선이 너무 검어 디자인 품질이 낮아 보인다. 회색 계열로 바꿔 세련되게 만든다. 다크 화면은 그대로 둔다.

## 한 일
- **선 토큰 3단계**
  - 구분선 `--border-subtle`, 카드·표 테두리 `--border-default`, 입력·보조 버튼 `--border-input`을 모두 회색 계열로 바꿨다.
  - 학사형 입력 테두리 #8A8277 → #C9C1B4, 분석형 #858D9A → #D0D5DD.
  - 카드·표 테두리도 한 단계 연하게 했다.
- **입력**
  - 은은한 그림자(1px)를 넣었다. 마우스를 올리면 한 단계 진한 회색이 된다.
  - 초점은 주 색 테두리 + 연한 고리로 바꿨다(검은 테두리 없음).
- **보조 버튼**: 같은 회색 테두리 + 은은한 그림자.
- **다크 화면**: 새 토큰(`--border-strong`, `--shadow-input`)만 정의하고 모양은 유지했다.
- **홈페이지 편집기 경합 수정**
  - 저장·공개 직후 화면이 새로 고쳐지면서 그 사이 고친 글이 지워질 수 있었다.
  - 방금 저장한 판이 돌아오면 입력을 건드리지 않게 했다.
  - 빈 칸 차이로 '바뀜'이 잘못 켜지지 않게 비교 전에 정규화한다.

## 검증
- `npm run build` 통과
- `npm run test:e2e` 20/20, 3회 연속 통과. axe 접근성 단계 포함.
- 화면 캡처로 입력·버튼 테두리 색(#D0D5DD)을 픽셀 단위로 확인했다.

## 알아 둘 점
입력 테두리 대비는 약 1.5:1로 WCAG 1.4.11 권고(3:1)보다 낮다. 위쪽 라벨, 그림자, 초점 고리로 보완했다. 접근성을 더 우선하는 학교는 `--border-input`을 `--border-strong`으로 한 단계 올리면 된다(DESIGN-SYSTEM.md).
