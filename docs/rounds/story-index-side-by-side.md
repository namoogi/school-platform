# 성품 목록: 그림 왼쪽 · 이야기 오른쪽 (2026-11-24)

사용자가 목록의 빈 공간을 줄이고 캐릭터 그림을 왼쪽, 이야기를 오른쪽에 배치하도록 요청했다.

- 각 성품을 그림 열과 이야기 열로 나눈다. 오른쪽에 성품·캐릭터 이름, 그 아래 에피소드 제목 링크를 모은다.
- PC의 성품 2열은 유지한다. 구역 간 세로 간격과 안쪽 여백을 줄인다.
- 800px 이하는 성품 1열, 480px 이하는 그림 폭 88px로 줄여 휴대전화에서도 좌우 배치를 유지한다.
- 그림 없는 다른 학교는 빈 그림 열 없이 글이 전체 폭을 사용한다.
- 기존 11종 이미지·에피소드·언어 필터·공개 상태는 보존한다.
