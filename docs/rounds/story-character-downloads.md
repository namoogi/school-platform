# 장면별 캐릭터 PNG 조회·내려받기

사용자 요청: 완성된 동화 아래에서 각 장면의 캐릭터 PNG를 조회·다운로드한다.

기존 gallery 블록에 `download: "png"`, 선택적인 `scene: 1~200`을 더한다. 별도 표·권한·공개 경로는 만들지 않는다. 장면마다 갤러리를 두어 같은 캐릭터의 다른 포즈도 독립 파일로 유지한다. 기존 원고·쪽 그림은 그대로 보존하고 새 판에 갤러리를 덧붙인다. 캐릭터가 없는 장면에는 빈 파일을 만들지 않는다.

- 썸네일은 원본 비율을 유지한다. 캐릭터 이름, 크게 보기, PNG 내려받기를 제공한다. 확대창은 Esc·방향키·닫기 단추를 지원한다.
- 공개·시안은 같은 렌더러를 쓰고, 그림책이 있으면 PNG 갤러리를 본문 뒤에 배치한다. 편집기에서는 원본 블록 순서를 유지한다.
- 화면 편집의 성품 동화 기능 팔레트에 ‘장면 캐릭터 PNG’를 넣었다. 구역 설정에서 장면 번호와 언어별 캐릭터 이름을 고칠 수 있다. 자세한 편집기의 사진 묶음에서도 설정할 수 있다.
- 저장할 때 사람/RLS 경로와 범위 토큰 경로 모두 같은 학교 PNG인지 확인한다. 파일 이름·크기는 서버가 자산에서 채워 판에 저장한다. JPEG를 PNG라는 이름으로 받거나 다른 학교 파일을 연결할 수 없다.
- 일반 사진 갤러리·PDF 내려받기의 기존 동작은 유지한다. 파일 URL은 기존 공개 판 자산 경로를 사용한다.

## 데이터 예시

```json
{
  "type": "gallery",
  "download": "png",
  "scene": 2,
  "caption": { "ko": "장면별 캐릭터", "en": "Characters by scene", "th": "ตัวละครในแต่ละฉาก" },
  "items": [
    { "asset": "<이 학교 PNG 자산 UUID>", "alt": { "ko": "곰", "en": "Bear", "th": "หมี" } }
  ]
}
```

`assets`는 items에서 정규화한다. 기존 최신 판을 읽고 이 블록을 덧붙여 `base_version`과 함께 새 판을 저장한다. 원본을 확보하지 않은 동화에는 임의의 파일이나 다른 장면의 캐릭터를 넣지 않는다.
