# 61차: 학사 토대 F5 — 정의 엔진 · 검사기 · 기능 꾸러미 · 학교 AI 범위(package) (ADR 0025)

- 날짜: 2026-11-25 · 세션: 관제
- 사용자 지시: "계속 진행해 주시게"(F1~F6 끝낸 뒤 홈페이지 템플릿).
- 넘어갈 조건(ADR 0025 9절): 꾸러미 하나를 학교 AI가 명세 → 검증 → 미리보기 → 관리자 켜기까지 — **e2e로 확인**.

## 한 일 — 마이그레이션 `20261126000500_f5_definition_engine.sql`, `src/lib/packages.ts`

### 정의 판
- `definitions` + `definition_versions`: 종류 5가지
  - `record_type` (E3)
  - `form` · `view` · `output` (E4)
  - `flow` (E5)
- 판은 `base_version` 409를 따른다.
- 판마다 검사 결과(`issues`, `valid`)와 작성자(사람/학교 AI 토큰)를 남긴다.

### DB 검사기 `private.check_definition`
오류로 막는 것:
- **숨은 참조**: `*_id`·`*_email`·`*_name`, `student_…` 같은 칸. 사람·수업은 정해진 열(`person_id`·`offering_id`)로만 잇는다.
- 칸별 개인정보 등급 누락, 핵심 기록 이름(attendance·grades …), 칸 이름 겹침, 모르는 종류, 보기 없는 고르기 칸
- 흐름: 끝 상태에서 나가는 전환(핵심 마감·정정 규칙 — 끝난 기록의 정정은 새 기록), 끝에 닿지 않는 흐름

꾸러미 검사(`check_package`):
- 구성 판을 고정한다.
- 기록 유형·칸·흐름 이름이 꾸러미 안에서 풀리는지 본다.
- 오류 판이 섞이면 꾸러미도 오류다.

### 기능 꾸러미
- 구조: `feature_packages` + `package_versions` + `package_states`(켜기·끄기 사건)
- **켜기는 학교 관리자만** 한다. 조건:
  - 검사를 통과한 판만 켤 수 있다.
  - 같은 기록 유형을 다른 꾸러미가 켜 두었으면 거부한다.

### 학교 정의 기록 `custom_records` + 흐름 사건 `custom_record_transitions`
- 켜진 꾸러미의 기록 유형만 쓴다.
- 쓰는 사람: 교직원. 수업 대상 기록은 담당 교사·관리자만.
- 자료 칸 검사: 모르는 칸·필수·종류·보기·글자 수
- 흐름
  - 첫 기록에 처음 상태 사건이 함께 남는다.
  - 전환은 정의된 역할(admin·teacher·author)만, `from_state` 409.
- 정정
  - 앞 기록을 가리키는 새 기록이고, 한 기록은 한 번만 정정된다.
  - 끝난 기록의 정정은 관리자가 사유와 함께 한다.
- 끄면 새 기록·전환은 거부하고, 쌓인 기록은 그대로 읽힌다.
- 학년도 기록 마감 판(F4)에는 들어가지 않는다(E6 승격 전, ADR 0025 10절).

### 작업 토큰 종류 `package`(학사 꾸러미)
- 라이선스: 학사 문서실(`records`). 토큰 행 쓰기 정책도 종류별 라이선스로 고쳤다.
- 권한
  - read: 정의·꾸러미 읽기
  - create: 새 코드
  - edit: 새 판
- 주소(keys)는 홈페이지 항목에만 적용된다.
- 에이전트 함수: `agent.packages`·`agent.save_definition`·`agent.save_package`(활동 기록 `definition.version`·`package.version`).
- **켜기·기록 쓰기 함수는 토큰에 없다.**
- API
  - `GET/POST /api/agent/packages`
  - `POST /api/agent/definitions`
  - `GET /api/agent/packages/<code>/preview`
- 안내 문서: `docs/agents/README.md` '학사 꾸러미 정의'. AI 연결 글에 꾸러미 절이 붙는다.

### 미리보기 `previewPackage`
- 학교 자료를 읽지 않는다. 명세만으로 합성 자료(예시 학생 1·2·3)를 만들어 양식·목록·출력을 그린다.

### 관리자 화면 `/packages`(레일 '꾸러미')
- 꾸러미별로 보이는 것: 켜짐/검사 배지, 구성 판, 꾸러미·정의 판 검사 결과(칸 단위), 미리보기
- 켜기·끄기 단추

### 공통 고침
- `errorResponse`에 판 충돌 `P0409` → **409**를 더했다(F1~F5 판 함수가 쓰는 코드인데 화면·API에서 500으로 나가던 것).
