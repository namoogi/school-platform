# 24차: 디자인 원형 8종 비교

## 목적 (사용자 요청)

23차의 ‘같은 구조에서 색만 바꾼 비교’를 버리고, 서체·글자 크기·배치·레이아웃·탐색 구조까지 서로 다른 **시스템 대시보드 원형**을 조사해 실제 화면으로 비교한다. 범위는 사용자가 고름: 조사와 시안 6~8종, 참고 유형은 학사·교육 행정, 개발·업무 도구, 엔터프라이즈·분석, 문서·워크스페이스 전부.

## 설계 메모

- **격리:** 각 시안은 자기 CSS 모듈 안에서 토큰을 정의(원시 → 의미)하고 쓴다.
  - 전역 양식 규칙(input·label 등)은 `.pv-root` 안에 적용하지 않도록 범위를 좁혔다. 기존 화면에는 영향이 없다.
- **자료:** 모든 시안이 같은 합성 자료(`src/components/archetypes/data.ts`)를 그린다. DB를 읽지 않는다.
- **데이터 경계 반영:** 마감 판·원본 자료·답변한 질문은 시안에서도 읽기 전용(잠금 + 글자)으로 보인다.
  - 정정은 ‘새 판’ 버튼으로만 표시한다.
  - 학교 전환·발행 같은 동작은 ‘시안에서는 하지 않음’ 안내만 띄운다.
- **서체:** 모두 OFL 라이선스(@fontsource 계열, @sun-typeface/suit)이고 npm으로 들여왔다.
  - 해당 시안 화면에서만 글꼴 파일을 받는다.
- **삭제:** 23차 색 조합 견본(.dv-*, DashboardSample)은 지웠다. 기록은 git과 `round-23/` 화면에 남아 있다.

## 확인하지 못한 것

- 시안의 학교 전환·검색·탐색 링크는 화면만 있고 동작하지 않는다(시안 범위).
- 모바일 폭(≤820px)은 각 시안이 접히도록 CSS를 넣었지만 화면으로 하나하나 확인하지는 않았다.
- 화면 판독기(스크린 리더)로는 시험하지 않았다. axe 자동 점검은 대기열의 기존 과제다.
