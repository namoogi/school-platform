# 103차: 계산식 판 초안 — 선언형 식·검사·판 저장·미리 계산 (ADR 0040)

- 날짜: 2026-11-27 · 세션: 관제
- 사용자: "계산은 드리미포털에 물어봐" → "답 오기 전에 일반형으로 계산식 판 초안 시작해"

> **요약** 학교마다 다른 이수 기준·성적 산출을 '계산식'으로 적고 판으로 쌓는다. 식은 코드가 아니라 허용된 연산만 쓰는 데이터라 공용 DB에서도 안전하다. 드리미포털 규칙(두 번 반올림, P/F 출처 둘, 자료 없음 3값)을 견본으로 그대로 재현했다.

> **왜** 대안학교는 성적 내는 법이 학교마다 다르다. 표의 칸을 늘리는 대신 식으로 담으면 학교 AI가 학교 규칙을 그대로 옮겨 적을 수 있다. 그리고 '자료 없음'이 '미달'이나 '통과'로 바뀌는 사고(드리미 실제 사례)를 설계에서 막는다.

```terms
용어 | 쉬운 설명 | 예시
계산식 판 | 성적을 어떻게 낼지 적은 식을 판(버전)으로 쌓은 것 | "2026 과목 점수 1판"
선언형 식 | '무엇을 계산할지'만 적고 실행은 서버가 정해진 방식으로 하는 식 | "가중 평균을 소수 1자리로 반올림"
3값 논리 | 참·거짓 말고 '모름(자료 없음)'을 따로 두는 것 | 출석 기록이 없으면 이수 '모름'으로 남김
견본 | 학교가 골라 고쳐 쓰는 기본 식 | 역량 6개 중 5개 도달이면 이수
```

## 한 일
- `src/lib/calc/expr.ts`
  - 식 검사(`checkSpec`), 계산(`evaluate`), 반올림(`roundBy`), 가중 평균(`weightedScore`)
  - 견본 6가지: 가중 평균, 역량 도달, 프로젝트 P/F, 동료·교사 혼합, 드리미 방식(한국식 A–E), 미국식 A–D·F
  - 선생님: "한국은 ABCDE, 외국은 ABCDF, E와 F가 같다" → 미국식은 학생 판정 F를 P/F로 읽지 않는다(점수를 지우지 않음)
- 마이그레이션 `20261128000700_calc_rules.sql`
  - `calc_rules`: 학교·이름·판. 추가만 하고, 학교 구성원만 읽는다.
  - 명령 함수 `app.save_calc_rule`: 학교 관리자만, 409
- `src/lib/calc-rules.ts`(목록·이력·저장·미리 계산), `GET/POST /api/calc-rules`
- 드리미포털 교류
  - 요청 → 회신(sha256 3907ce5a…) → 정정 1(P/F 출처 둘, P/F면 원점수만 비움, 중등 과목평균) → 정정 2(학생 판정 = 입력 행 성취도, 입력 행이 없을 때만 이전 기록 계승)
  - 정리 문서 `docs/research/dreamy-calc-rules-2026-11.md`
