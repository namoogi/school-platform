# 103차: 다국어 전환 — 홈페이지 관리 화면·템플릿 (ADR 0037)

> **요약** 선생님이 영어로 바꾼 화면에서 홈페이지 관리(`/site`)·템플릿이 한국어로 남고 위 막대가 깨진 것을 고쳤다. 화면 한글 줄 541 → 76.

> **왜** 처음에는 `/site`를 홈페이지 세션 몫으로 빼 두었지만, 사용자가 영어 화면에서 직접 보고 지적해 이번에 옮겼다(사용자 최신 요청 우선).

## 한 일
- 홈페이지 관리 화면 13개 파일(목록·설정·편집기·AI 작업 공간·사이트 가져오기·문의·미리보기·템플릿·전체 화면 미리보기)을 이름표로 옮김. 이름표 약 640개(ko+en).
  - 네 묶음을 작업자 넷이 나눠 옮기고 합침(겹친 이름표 0).
- 공용 값(종류·구역·블록·변형·테마)은 관리 화면에서만 값별 이름표로 그린다: `src/lib/site-labels.ts`(`siteLabel`·`templateText`). 공개 홈페이지는 학교 언어를 따르므로 `site-shared`의 한국어 목록을 그대로 쓴다.
- 템플릿 8종의 이름·요약·맞는 학교를 이름표로(`site.tpl.t.<key>.*`).
- 위 막대 언어 고르기가 아이콘과 상자로 쪼개지던 것은 #149(자동 세션 UI 점검)를 병합해 고침.
- 왼쪽 메뉴 묶음 이름(영어 'Academics')이 글자 중간에서 끊기던 것: 옆 여백을 줄이고 낱말 단위로만 줄을 바꿈(`globals.css`).

## 알아 둘 점
- 번역 묶음(`i18n/en.json`)은 배포 때 **빈 칸만** 채운다. 이미 있는 이름표의 영어를 고치면(예: #149의 `people.empty`) 운영 DB에는 바뀐 글이 들어가지 않는다. 고친 영어를 운영에 넣으려면 전체 관리 → 언어·번역에서 고치거나 새 이름표를 쓴다.
