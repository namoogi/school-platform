# 121차: 태국어 번역 묶음 (ADR 0037)

> **요약** 화면 문구 3,036개 전부를 태국어로 옮긴 기본 묶음 `i18n/th.json`을 더했다. 태국어(ไทย)는 이미 언어 목록에 켜져 있어, 배포 때 사전에 들어가면 바로 태국어 화면이 된다. 코드 변경은 위 막대 로그아웃 단추 하나.

> **왜** 사용자 지시(2026-11-28): "태국어도 추가해 줘". 범위는 '전체 한 번에'로 고름(토큰 비용 안내 뒤).

## 한 일
- `i18n/th.json` 3,036개: 작업자 6명이 나눠 옮기고 합침. 기준은 한국어 원문, 영어로 대조.
- 태국어 용어집 `docs/i18n/GLOSSARY-th.md`(학교 용어 50여 개, 문체 규칙).
- 시험: 영어 말고 다른 언어 묶음도 목록에 없는 이름표·채우기 자리가 다른 번역을 막는다(`tests/i18n-format.test.ts`). 다른 언어는 빠진 이름표가 있어도 된다(영어로 대신 보임).
- 위 막대: 로그아웃 이름 길이가 언어마다 달라 휴대폰 폭에서 넘쳤다(태국어 410px > 390px). 아주 좁은 화면(440px 이하)에서는 아이콘만 보이고 이름은 화면 읽기용으로 남긴다.
