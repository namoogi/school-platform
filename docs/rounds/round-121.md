# 121차: 템플릿 새 판 → 학교에 '제안' (ADR 0043 3단계)

- 날짜: 2026-11-28 · 세션: 학사 시스템 개발 전담
- 사용자: "템플릿 새 판 제안 기능 하자"

> **요약** 관제가 학사 관리 템플릿의 새 판을 내면, 그 템플릿을 쓰는 학교마다 '새 판 제안'이 생긴다. 학교는 템플릿 화면에서 '수락하면 더해지는 것 / 학교 값 유지'를 보고 수락(적용)·보류·거절한다. 학교 사본은 수락하기 전에는 바뀌지 않는다.

> **왜** 템플릿을 고친 뒤 학교에 알릴 길이 없었고, 카드의 '새 판' 버튼은 무엇이 바뀌는지 보이지 않은 채 바로 적용했다. 기본판 제안(ADR 0027)과 같은 모양으로 맞춰, 관제는 제안만 보내고 학교가 고른다.

```terms
용어 | 쉬운 설명 | 예시
새 판 | 관제가 고쳐 다시 낸 템플릿 | 한국 일반 2판: P/F 척도 추가
제안 | 학교에 "새 판이 있어요" 하고 남기는 기록 | 1판 → 2판, 제안 중
학교 값 유지 | 학교가 이미 정한 것은 새 판이 덮지 않음 | 학기 구조를 고쳤다면 그대로
```

## 흐름
```
관제: 템플릿 새 판 내기 ─▶ 그 템플릿을 쓰는 학교마다 제안 1건(DB 함수)
학교: 템플릿 화면 '템플릿 새 판 제안' 카드
      · 바뀐 이유 · 수락하면 더해지는 것 · 학교 값 유지
      [수락하고 적용] [보류] [거절]   (거절·보류도 나중에 수락 가능, 수락은 끝)
수락 = 기존 적용 길(applyTemplate)로 새 판 적용 + 같은 트랜잭션에서 기록
```
