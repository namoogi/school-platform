# 65차: 학교 홈페이지 템플릿 — 형식 조사 · 템플릿 7종 · 둘러보기 · 미리보기 · 적용 (ADR 0031)

- 날짜: 2026-11-26 · 세션: 관제
- 사용자 지시(2026-11-25, 2026-11-26 "계속 진행해 줘"): 다양한 학교 홈페이지 형식을 정리 → 학교가 템플릿을 둘러보고 골라 시작한다. 자료 AI 자동 배치와 기존 사이트 크롤링 이전은 뒤 차시에서 한다.

## 한 일
- **형식 조사** `docs/research/homepage-templates-2026-11.md`
  - 대상: 한국 공립·대안학교, 미국 사립, 국제학교, 기독교 학교, 호주 NSW 공립, 태국 공립
  - 형식을 가르는 축 다섯 가지를 뽑았다: 첫 화면의 대상, 입학 흐름, 이야기 비중, 언어, 공개 의무.
  - 한계: 한국 교육청 표준 메뉴 지침은 찾지 못했다. 업체 자료는 '업계 의견'으로 표기했다.
- **ADR 0031** 홈페이지 템플릿
  - 코드 안 템플릿 목록(판 번호 있음)이다. 고르면 그 학교에 **시안 쪽**을 만들고, 공개는 사람이 한다.
  - 같은 주소의 쪽은 건너뛴다. 빈 칸 목록(slots)은 66·67차가 채운다.
- **템플릿 7종** `src/lib/site-templates.ts`
  - 종류: 알림 중심, 이야기, 입학 모집, 프로젝트, 사명·후원, 국제·다국어(en/ko/th), 한 쪽 소개
  - 각 템플릿에 담은 것
    - 추천 테마, 쪽(기존 블록·잡지형 구역)
    - 안내 자리 `[ … ]`
    - 빈 칸 목록: 쪽·블록·칸 경로, 무엇을 넣을지, 자료에서 찾을 단서 낱말
    - '꼭 알릴 정보'(입학 절차·학비·오시는 길 등)
- **화면**
  - `/site/templates`: 7종 카드(맞는 학교·첫 화면·쪽 수·채울 칸). `/site`에 '템플릿 둘러보기' 단추가 있다.
  - `/site/templates/<key>`
    - 방문자 화면과 같은 그리기 코드로 미리 본다(쪽 이동, 다국어 템플릿은 언어 바꾸기).
    - 옆에 이 쪽의 채울 칸, 꼭 알릴 정보, '이미 있음' 표시
    - 관리자는 '○○으로 시작하기'를 누른다.
  - API `GET/POST /api/site/templates`: 적용은 관리자만, 기존 `createEntry`(RLS) 경로를 쓴다. 활동 기록 `site.template_apply`.
