# 102차: 다국어 전환 6c — DB 안내 문구 영어 (ADR 0039)

> **요약** DB 함수가 내는 고정 안내 301개에 영어를 달았다. 영어 화면 사용자는 학적·수업·성적·출결·기록·열람 계정·관제 같은 거의 모든 실패 안내를 영어로 본다.

## 한 일
- `db.m001`~`db.m305`(301개): 마이그레이션의 `raise exception '고정 문구'`와 글자가 같은 기준 문구 + 영어. 응답 때 `errorResponse`가 글자로 찾아 바꾼다(101차 틀).
- 뺀 것
  - 표 보호 문구(`source_files: …` 같은 표 이름 접두)·DB 역할 점검 문구 25개: 사람 화면에 나오지 않는다.
  - `{…}`가 든 4개(선택지 모양 2, 꾸러미 제목 모양 1, 번역 모양 1): 채우기 자리 문법과 겹쳐 한국어로 둔다.
  - 값이 든 문구(`format`·`%`): 글자로 찾을 수 없어 한국어로 남는다.
- `tests/server-errors.test.ts`가 301개 모두 마이그레이션에 같은 글자로 있는지 본다.
