# 동화책 분위기의 성품 목록 (2026-11-24)

## 요청과 화면

사용자는 동화 페이지의 선과 형식이 사무적으로 보인다며 동화 분위기를 요청했다. 기존 캐릭터 왼쪽·이야기 오른쪽 배치는 유지한다.

- 제목 아래 긴 선과 에피소드 사이 가로선을 제거한다.
- 작은 책·잎 아이콘, ‘마음이 자라는 이야기 숲’ 문구, 명조 제목으로 도입부를 바꾼다. 한국어·영어·태국어 모두 문구를 제공한다.
- 종이색 바탕, 잎·살구·하늘·장미의 연한 색 번짐과 비대칭 둥근 모서리로 캐릭터를 감싼다. 색은 .story-library 안의 의미 토큰으로 한정한다.
- 에피소드는 작은 이야기 번호와 제목 링크만 유지한다. hover 배경과 키보드 focus 테두리, 최소 44px 링크 높이를 제공한다.
- PC는 성품 2열, 800px 이하는 1열. 작은 휴대전화에서는 화살표를 숨기고 그림 폭을 줄여 제목 공간을 확보한다.
- 11종 그림·에피소드 순서·언어별 필터·공개 상태는 유지한다. 다른 홈페이지 메뉴의 디자인은 바꾸지 않는다.

## 확인

- typecheck, check:repo, 단위 테스트 8개 파일·55개 통과.
- 로컬 생성 캐시의 중복 타입 파일 충돌은 기존 .next를 작업 폴더에 보존하고 새로 빌드해 해소했다. 소스 타입 오류는 없었다.
- 본문·보조 글·강조 글의 배경 대비를 확인하고 강조색을 더 진하게 조정했다.
- DB 통합/E2E는 로컬 Postgres가 없어 미실행. 빌드·운영 화면 확인 결과는 PR에 기록한다.
- DB·권한·마이그레이션 변경은 없다.
