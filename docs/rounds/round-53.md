# 53차: 관리 화면 안에서 '화면에서 고치기'

- 날짜: 2026-11-25 · 세션: 관제
- 사용자 지시: "관리자 모드 안에 화면에서 고치기 기능이 있으면 좋겠는데."

## 진단
화면 편집(`/site/edit/<id>`)은 관리 화면 안에 있었지만, 들어가는 길이 편집 칸 머리의 작은 '화면에서 편집' 단추 하나였고, 화면 편집 안에서는 다른 쪽으로 옮겨 갈 수 없어 매번 목록으로 돌아가야 했다.

## 한 일 (새 길을 더하지 않고 기존 화면 편집으로 가는 길을 드러냄)
- 홈페이지 관리 목록: 줄마다 **화면** 단추 → 그 쪽 화면 편집.
- 편집 칸 맨 위: **항목별로 고치기 | 화면에서 고치기** 전환(예전 머리 단추를 옮김).
- 화면 편집 막대: **쪽 고르기**(쪽·소식·성품 동화 묶음) — 저장 안 한 변경이 있으면 확인 후 이동. '목록'은 '목록 · 항목별로 고치기'로.
