# 130차: 학사 설정 편집 화면 — 맞춤 척도·성적 정책 전체·계산식·출력 프로필 (2026-11-28)

> **요약** 학교 관리자가 학교 AI의 초안을 받아, 관제를 거치지 않고 네 가지 학사 설정을 화면에서 새 판으로 저장합니다. 계산식은 저장 전에 경계 점수 89.5·59.5·39.5로 미리 계산해 문제가 없을 때만 저장됩니다. AI 지시문과 절차 문서는 이 화면들을 가리킵니다.

> **왜** 127차(PR #220) AI 지시문은 화면이 없는 네 가지를 '관제를 거쳐 저장' 묶음으로 보냈습니다. 학교가 스스로 운영한다는 목적(ADR 0011)과 맞지 않아, 화면을 만들어 그 묶음을 없앴습니다.

```terms
용어 | 쉬운 설명 | 예시
판 | 설정을 고칠 때마다 덮어쓰지 않고 새 번호로 쌓는 것 | 척도 1판(A≥85) → 2판(A≥90), 1판도 남음
base_version | '내가 보고 고친 판 번호'. 그 사이 다른 사람이 새 판을 만들었으면 저장을 막음(409) | 두 선생님이 같은 척도를 동시에 고치면 늦은 쪽이 다시 읽고 고침
미리 계산 | 저장하지 않고 합성 점수로 식을 돌려 보는 것 | 89.5점이 A가 되는지, 59.5점이 이수인지
출력 프로필 | 발행 서식(학생부·성적증명서 등)마다 학교가 정한 설정 | 학생부 세특 500자, 태국 ปพ.1 등급 띠
```

## 한 것
| 항목 | 화면 | 저장 길(하나) |
| --- | --- | --- |
| 맞춤 척도 | `/grades` '척도': 척도마다 '구간 고치기(새 판)', '맞춤 척도 새로 만들기' | `POST /api/grades {action:'scale'}` → `saveScale`(`checkBands`) → `app.save_scale` |
| 성적 정책 전체 | `/grades` '성적 정책': 세 칸 양식 + '정책 전체 고치기(JSON)' | `{action:'policy-full'}` → `checkGradingPolicy` → `app.save_grading_policy` |
| 계산식 판 | `/grades` '계산식 판': 식 고치기, 견본에서 새로 만들기 | `POST /api/calc-rules {action:'preview'}` 통과 → `{action:'save'}` |
| 출력 프로필 | `/records` '출력 프로필': 설정 고치기, 새로 만들기 + 발행 양식에서 프로필 고르기 | `POST /api/records {action:'output-profile'}` → `app.save_output_profile` |

- 공용 `ActionForm`: `type: 'json'` 칸, `preview`(미리 계산 후 저장) 추가. 위아래 배치에서 줄 전체 칸이 옆 열로 밀리던 배치도 고침(`flex-wrap: nowrap`).
- '왜' 칸: 네 저장 길 모두 필수(`requireWhy`, 500자). 세 칸 정책 양식도 같은 규칙.
- 성적 정책 검사: 플랫폼이 실제로 읽는 칸(`POLICY_KEYS`: 자릿수·stats·narrative_limits·attendance·requests)만 받는다. 모르는 칸은 아무 데서도 쓰이지 않아 조용히 무시되므로 막는다.
- 발행: 지금까지 발행 양식이 출력 프로필을 고르지 못해 저장한 프로필이 쓰이지 않았다. 이제 고를 수 있고, 다른 서식의 프로필은 서버가 거부한다.
- 출력 프로필 목록 `listOutputProfiles` 하나를 관리 화면과 AI 지시문 요약이 같이 쓴다.
- 지시문: `template-ai-guide.ts` 4단계(가·나 묶음 → 화면별 저장 경로와 붙여 넣을 JSON 모양), `tplAi.step3`(한·영), `docs/agents/grade-intake.md` 4절.
- 세 칸 정책 양식의 표준편차 선택이 지금 값을 보여 주지 않던 것을 고침.

## 남은 것
- 학교 작업 토큰(`package`)으로 척도·계산식을 직접 쓰는 길(ADR 0040 다음 단계). 지금은 AI가 초안, 사람이 화면에서 저장.
- 출력 프로필 설정 칸은 렌더러가 읽는 것만 뜻이 있다(서식 칸 순서 바꾸기는 렌더러에 없음).
- 경계값 견본은 평가 항목 하나(`total`)라, 특정 항목 이름(`items.mid`)을 읽는 식은 그 칸이 '-'로 나온다. 항목별 견본 입력은 다음 일.
