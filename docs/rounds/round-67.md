## 한 일
### `src/lib/site-crawl.ts` — 기존 사이트 읽기
- **안전**: 서버가 외부 주소를 읽는 기능이라 SSRF를 막는다.
  - 받는 주소: http(s), 기본 포트(80·443)만. 사용자 정보가 든 주소는 거부.
  - 막는 주소: localhost·`.local`·`.internal`·메타데이터 이름, 사설·내부·링크 로컬·CGNAT·멀티캐스트 IP(IPv4·IPv6·IPv4 매핑)
  - 확인 방법: 주소 모양과 DNS 결과를 모두 본다. 리디렉트(최대 3번)는 매번 다시 검사한다.
- **예의**
  - `robots.txt`의 `User-agent: *` 묶음 Disallow를 따른다.
  - 사용자 에이전트에 이전 목적을 밝힌다.
- **한도**
  - 같은 호스트만 읽고, 파일 링크(PDF·그림·문서)는 건너뛴다.
  - 쪽 수 8, 쪽당 6초·2MB, 전체 35초(서버 함수 60초 안)
- **줄글 변환**
  - 스크립트·스타일·폼·iframe은 버린다.
  - 제목은 따로 한 줄, 목록은 '- ', 정의 목록은 '이름:'으로 둔다. 겹친 블록은 한 번만 낸다.
  - 그림은 주소·대체 글 목록으로 만든다.
- 그림 받기 `fetchImage`: 같은 안전 검사, 5MB 한도

### `site-templates.ts`
- `migratePropose`: 주소 → 읽은 쪽들 → 66차 같은 제안(`proposeFills`)
  - 함께 돌려주는 것: 옛 사이트 그림 목록(40장까지), 사진 칸 목록
  - 읽은 글은 저장하지 않는다.
- `migrateImages`: **고른 그림만** 10장까지 받는다. 실제 형식을 검사(`checkUpload`)한 뒤 학교 홈페이지 그림으로 올리고, 활동 기록을 남긴다.
- 넣기는 66차 `autofillApply`와 같은 길이다: 안내 자리·빈 칸만 채우고, 쪽마다 새 시안 판을 만든다.

### 화면·API
- API(관리자): `POST /api/site/templates/migrate`, `POST /api/site/templates/migrate/images`(`maxDuration` 60초)
- `/site/templates/<key>` 아래 '기존 홈페이지에서 옮기기'
  - 흐름: 주소 → 읽기 → 읽은 쪽·건너뛴 쪽 → 제안(고치기·고르기) → (선택) 옛 사이트 그림 고르기·가져오기 → 고른 것 넣기
  - 그림을 고를 때 학생 사진 공개 허가 안내가 함께 보인다.
  - '학교 자료로 채우기'와 나란히 둔다.

## 한계·확인하지 못한 것
- 실제 외부 학교 사이트로는 운영에서 시험하지 않았다(시험은 로컬 서버·가짜 크롤러). 자바스크립트로만 그리는 사이트(SPA)는 글이 비어 보일 수 있다.
- 로그인이 필요한 쪽, 게시판 목록(쪽 번호 매김)은 읽지 않는다. 옛 게시판 글 전체 이전은 범위 밖이다(필요하면 별도 차시).
- 옛 사이트의 저작권·개인정보는 이전하는 학교가 확인한다(학교 자기 사이트를 옮기는 경우를 전제로 한다).
