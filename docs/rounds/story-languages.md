# 언어별 성품 동화 (2026-11-23)

## 요청과 동작

언어를 고르면 해당 언어로 된 동화와 시안이 보이도록 한다.

- 공개 목록은 공개된 판의 제목과 본문(구역·설명·대체 글 포함)에 선택 언어가 모두 채워진 동화만 표시한다. 숨긴 블록과 빈 선택 필드는 판정에서 제외한다.
- 해당 번역이 없는 직접 주소는 다른 언어 본문을 대신 보여 주지 않고, 선택 언어 안내와 준비된 언어의 링크를 보여 준다. 메타 제목도 선택 언어로 표시하고 미번역 화면은 검색 색인에서 제외한다.
- 성품 11개와 캐릭터 이름은 한국어·영어·태국어로 표시한다. 식별·그룹 기준과 사용자 정의 이름은 보존한다.
- 이미지 안 글자가 있는 완성본이라도 다국어 본문을 추가했다면 번역문을 그림 아래에 표시한다. 원본 이미지 안 글자는 보존되며 안내를 함께 표시한다.

## 학교 콘텐츠 작업

Rung Arun Suksa 기존 시안 33편의 제목·요약·공지·이미지 설명·줄거리 세 단계·성품 설명·배경 설명에 영어와 태국어를 추가했다. 『비가 지워도 남는 것』은 기존 태국어 16쪽 본문과 제목을 보존하고 한국어·영어를 추가했다.

- 총 34편을 각각 **2판 시안**으로 저장하고 서버에서 다시 읽어 대조했다.
- 모든 기존 문자열·그림 ID·블록 순서를 보존했다. 낙관적 동시성(base_version)으로 저장했으며 공개 판은 1판 그대로다.
- 토큰에 publish 권한이 없어 공개하지 않았다. 학교 관리자가 시안을 확인해 공개할 수 있다.
- 이미지에 들어 있는 한국어·태국어 글자는 번역 이미지로 교체하지 않았다. 번역 본문은 별도 텍스트로 제공한다.
- 번역은 발전시킬 시안이다. 학교의 태국어 표현 검토와 그림 속 글자의 언어별 편집은 후속 작업이다.

## 확인

- 타입 검사, 단위 테스트 54개, 저장소 검사, 운영 빌드 통과.
- 실제 관리자 미리보기에서 영어·태국어 제목과 전체 줄거리 전환 확인.
- 임시 로컬 화면에서 실제 번역 자료의 세 언어 목록·성품명·캐릭터 이름·언어가 유지되는 링크를 확인. 완성본 16쪽 중 영어 2쪽까지 넘겨 번역문이 숨겨지지 않고 그림 아래 보이는 것을 확인했다. 임시 화면은 제거했다.
- E2E 기대값을 미번역 언어의 한국어 대체 표시에서 번역 준비 안내로 바꿨다. 로컬 Postgres가 없어 DB 통합 테스트·전체 E2E는 미실행.
