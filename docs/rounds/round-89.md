  - 기존: 학사 기본, 새벽빛
  - 새로: 맑은 하늘, 힘찬 시작, 작업실, 등불, 지평, 씨앗
  - 새 6종은 공용 틀(`--t-*` 토큰)에 색·글꼴·모서리·첫 화면 모양만 바꾼다.
    - 첫 화면은 큰 사진 위에 제목과 단추를 올린다.
    - 카드·단계·정보·인용·행동 띠·알림·진한 바닥(학교 이름·메뉴·연락처)을 다시 그렸다.
  - 마이그레이션 `20261128000200_site_theme_designs.sql`: 테마 확인 제약을 8가지 값으로 넓혔다(행 변경 없음).
  - 설정 화면의 '화면 모양'에 8종이 설명과 함께 보인다.
- **템플릿마다 고유 디자인**
  - 알림 중심 → 맑은 하늘, 이야기 → 새벽빛, 입학 모집 → 힘찬 시작, 프로젝트 → 작업실, 사명·후원 → 등불, 국제·다국어 → 지평, 한 쪽 소개 → 씨앗
  - 판 2(이야기형은 1)
  - 알림 중심형 첫 화면에 큰 사진 구역을 더했다.
- **예시 그림 22장 자리**
  - 가상 학교 예시의 첫 화면·카드·사진 구역에 그림을 놓는다.
  - 지금은 자리 그림(SVG, `scripts/template-placeholders.mjs`)이다.
  - 사진풍 그림 프롬프트: `docs/design/template-image-prompts.md`(선생님 확인 뒤 생성)
- **둘러보기 쇼케이스**
  - 카드마다 큰 썸네일을 둔다. 첫 화면, 그 아래 구역, 휴대폰 화면을 겹친 그림이다(`npm run templates:thumbs`).
  - 카드에는 디자인 이름·쪽·언어·칸 수와 '미리보기'·'자세히·시작하기' 단추가 있다.
- **전체 화면 미리보기** `/templates/<key>`
  - 관리 화면 밖에서 방문자가 볼 틀(머리·메뉴·바닥) 그대로 보인다.
  - 메뉴로 쪽을 넘기고, 예시 내용과 안내 자리를 바꿔 보고, 언어를 바꾼다.
  - 위 막대에 '이 디자인으로 시작'이 있다.
  - 로그인한 사람만 보고, DB는 읽지 않는다. 예시 소식 3개를 보인다.
- **적용 때 디자인 함께**: '화면 모양도 이 디자인으로 바꾸기'
  - 홈페이지가 닫혀 있으면 기본으로 켜고, 열려 있으면 기본으로 끄며 방문자 화면이 바로 바뀐다고 알린다.
  - 설정이 없으면 바꾸지 않고 알린다.
  - 87차 이관 단추도 같은 선택을 쓴다.
- `SiteFrame`
  - 학사 기본 밖의 테마는 넓은 바닥을 쓴다(새벽빛 동작은 그대로).
  - 바닥 메뉴에 '홈'이 두 번 나오던 것을 고쳤다.
  - 미리보기용 `preview` 링크를 더했다.
