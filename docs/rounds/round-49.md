# 49차: 공개 화면 관리 막대 · 편집 화면 바로가기 (옛 사이트 관리 모드 이전)

- 날짜: 2026-11-24 · 세션: 관제
- 사용자 지시: 48차 '아직 다른 점' 진행 — 공개 화면 위 관리 막대, 편집 화면 안 소식 추가·개선 요청 바로가기.

## 한 일
- **관리 막대:** 로그인한 이 학교 관리자가 공개 화면을 보면 맨 위에 '관리자로 보는 중 · 이 화면 편집 · 소식 쓰기 · 홈페이지 관리 · 개선 요청'. 다른 학교 관리자·방문자에게는 없다(로그인 쿠키가 있을 때만 RLS로 `is_school_admin` 확인).
- 막대의 길은 모두 `/site/open?to=edit|news|manage|chat`을 거쳐 작업 학교를 그 학교로 맞춘다(전체 관리자 입장 기록 포함).
- **편집 화면:** '소식 쓰기'(새 소식 칸이 열린 홈페이지 관리), '개선 요청'(그 자리에서 대화창 열기). 홈페이지 관리 `?new=1`, 대화창 `?chat=1`·`chatdock:open` 사건.

## 시험
- 전체 `npm test` 36파일 275개, E2E 34/34(49차 단계: 방문자·다른 학교 관리자에게 막대 없음, 소식 쓰기·개선 요청·이 화면 편집, 편집 화면 바로가기, axe 포함).

## 남은 것
- 학교 주소(rungarunsuksa.vercel.app)에서는 로그인 쿠키가 플랫폼 주소에만 있어 막대가 보이지 않는다(바닥 '교직원 로그인'으로 들어감). 주소 사이 로그인 넘겨주기는 보안 설계가 필요해 따로.
