# 성품 동화 새 판 일괄 공개

사용자 요청: 제목별로 새 판을 공개하는 반복 작업을 줄인다. 기존 관리자의 공개 권한과 공개 기록을 그대로 사용하며 새 권한·표는 만들지 않는다.

## 동작

- `/site?box=story` 목록 위에 관리자용 **새 판 일괄 공개**를 표시한다.
- 미공개 시안·공개 중 새 판이 있는 동화의 제목, 현재 공개 판, 공개할 판을 확인하고 전체 또는 일부를 선택한다. 한 번에 100편까지다.
- 선택한 판에 저장된 모든 언어와 이미지 구성이 함께 공개된다. 자동 번역 생성·이미지 속 글자 번역은 이 기능에 포함되지 않는다.
- 공개 내림·보관 항목은 후보에서 제외한다. 서버도 공개 내림·보관 항목을 거부한다.
- 확인 뒤 새 판이나 공개 상태가 바뀌면 해당 항목만 건너뛰고 이유를 표시한다. 이미 같은 판이 공개되었으면 중복 기록하지 않는다.
- 응답을 잃으면 목록을 다시 읽고 재선택한다. 예상하지 못한 DB 오류는 전체 트랜잭션을 롤백한다.

## 경계·동시성

`POST /api/site/entries/bulk-publish`는 로그인·같은 출처·성품 동화 라이선스·학교 관리자를 기존 `handle`로 검증한다. 학교 ID는 서버 소속에서 정하고 `asUser`/RLS를 유지한다. 요청은 `{ items: [{ id, base_version, live_version }] }`다.

같은 학교의 동화 부모 행을 ID 순서로 잠근 뒤 최신 판과 공개 상태를 다시 읽는다. 새 판과 공개 기록 삽입은 외래키의 부모 행 잠금과 직렬화된다. 성공 항목은 확인한 판 ID를 `site_publications`에 추가하며 원문·그림·기존 판을 수정하지 않는다. 다른 학교·다른 종류는 같은 찾을 수 없음 결과로 처리한다.

## 검증

- 로컬 타입 검사, 단위 테스트(Vitest 85 + Python 8), 운영 빌드 통과.
- 실제 RLS 양방향·태국어 공개·재시도·오래된 판 거부 통합 테스트 추가, CI Postgres에서 통과.
- E2E에 목록 선택·충돌 항목 건너뛰기·공개 내림 제외·태국어 조회·비로그인 거부 추가.
- 로컬 Postgres가 없어 DB 통합·전체 브라우저 E2E는 로컬에서 미실행. 기존 CI의 Postgres 환경에서 실행한다.
- 합성 자료 컴포넌트 화면에서 전체/일부 선택, 선택한 판 요청, 성공·충돌 안내와 새로고침을 브라우저로 확인했다.

기존 파일 첨부 E2E가 직전 업로드 뒤 비활성/교체된 버튼에 키를 보내 시간 초과하던 대기를 보강했다. 활성 버튼을 찾아 그 버튼에 직접 Enter를 보내며 첨부 제품 동작은 바꾸지 않는다.
