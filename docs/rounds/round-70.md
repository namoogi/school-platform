## 한 일
- **ADR 0032** AI 작업은 구독 계정으로
  - 무거운 AI 작업은 학교 구독 AI(범위 토큰)나 관제 세션이 한다.
  - 플랫폼 서버의 유료 API 분석은 만들지 않는다. 66차 ③은 '채택 안 함'.
  - 무료 규칙 기반 보조는 둔다. 유료 API는 실시간 대화 보조로만, 비용 확인 뒤에 검토한다.
  - AGENTS.md 외부 에이전트 절에 반영했다.
- **학교 AI 길을 분명히**

  - AI 연결 글(쪽 토큰)에도 같은 안내를 넣었다.
- **서비스 이름 onschools**: 로그인 화면, 기본 창 제목, 홍보 페이지 머리, 앱 로고의 화면낭독기 이름
