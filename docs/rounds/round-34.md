# 34차: 화면 편집 (ADR 0011 1단계 — 실시간 관리자 모드)

## 사용자 방향 (2026-11-23)
"가장 좋은 것은 실시간 실제 화면에서 수정 가능한 관리자 모드이며, 생성형 대화로도 고칠 수 있어야 한다. 각 학교가 생성형 대화를 통한 개발과 실시간 화면 편집 등으로 최대한 자유롭게, 쉽게 운영해 관리 소요를 줄인다." 이번 차시는 그중 실시간 화면 편집만 만든다. 대화형(AI) 편집은 2단계(비용 승인 뒤).

## 한 일
- **편집 화면** `/site/edit/<항목 id>`: `/site` 편집기 머리의 '화면에서 편집'으로 들어간다. 공개 화면과 같은 틀(머리·메뉴·바닥, 학교 테마)에 최신 판을 그린다. 쪽·소식·동화 모두.
  - **편집 막대**(위에 붙음): 목록으로, 방문자 모습 보기 ↔ 편집 모드, 고칠 언어, 레이아웃 가이드, 되돌리기(Ctrl+Z), 판 메모, 시안 저장(Ctrl+S), 공개(관리자 — 교사에게는 "공개는 학교 관리자가 합니다"), 저장 안 한 변경 표시, 나갈 때 경고.
  - **글 바로 고치기**: 제목·머리말·소개·구역 글·카드·항목·단추 이름·알림·동화 쪽 글을 그 자리에서. 언어를 바꾸면 그 언어 글을 고친다. 비어 있으면 다른 언어 글을 흐리게 점선으로, 기본 언어 글이 공개본과 달라졌는데 번역이 그대로면 물결로 표시한다.
  - **사진 바꾸기**: 사진마다 '사진 바꾸기/넣기' → 사진함 창(고르기·올리기·대체 글·사진 빼기).
  - **구역 막대**: 끌기 손잡이(끌거나, 손잡이에서 ↑↓ 키), 위·아래, 숨기기, 설정(구역 모양·항목 더하기/빼기·카드 링크·단추, 사진 묶음 사진, 소식 개수·모양, 영상 주소, 그림 대체 글), 지우기(되돌리기 단추).
  - **레이아웃 가이드**(오른쪽, 휴대폰에서는 아래 시트): 팔레트 '레이아웃'(잡지형 구역 10모양)·'기능'(제목·글·그림·사진 묶음·최근 소식·알림·영상 / 동화는 동화 한 쪽·글·영상), 고른 구역 다음에 넣고 바로 첫 글 칸으로. 그림·사진 묶음은 사진부터 고른다. '페이지 구조' 목록에서 끌어 순서 바꾸기·숨기기. '쪽 정보'에서 표지 사진·쪽 머리 모양.
- **숨김 블록**: 어느 블록이든 `hidden: true`. 판에 남고 방문자 화면에서만 빠진다. DB 변경 없음.
- **렌더러**: `SiteBlocks`·`PageHead`에 선택 인자 `ed`. 없으면 방문자 화면과 같은 출력(숨김 블록만 빠짐). 편집 중에는 링크를 같은 모양의 `span`으로 그려 고치는 칸이 링크 안에 들어가지 않게 했다. `PageHead`는 `load.tsx`에서 `SiteRenderer.tsx`로 옮기고 다시 내보낸다(브라우저에서도 쓰기 위해). `SiteFrame`은 타입만 서버 모듈에서 가져오게 바꿨다.
- **편집 함수** `src/lib/site-edit.ts`(순수 함수): 2단계 AI 제안도 이 함수 + 같은 판 저장 API로 시안을 만든다.

## 경계·보존
- 새 쓰기 경로 없음: 기존 판 저장(`validateContent`·RLS)·공개(관리자 RLS)·사진 올리기 API만 쓴다.
- 편집 화면의 읽기도 `asUser`(RLS). 다른 학교 항목 id는 '없는 항목'(404).
- dawn 테마 CSS는 건드리지 않았다. 편집 도구 CSS는 `.le-*`(globals.css 끝 '34차' 구역).

## 남은 것
- 동시 편집 충돌 막기(지금은 둘 다 새 판으로 쌓임) — ADR 0012의 base_version과 함께.
- 공개 화면(`/s/…`)에서 로그인한 구성원이 바로 편집 모드로 들어가기, 가이드 창 끌어 옮기기·위치 기억, 홈 머리·바닥 정보(로고·주소) 화면 편집.
- 옛 사이트 세션의 `ADMIN-FEATURES.md`와 대조(이 차시 시작 때 아직 작성 중).
- 앱 셸이 390px 폭에서 가로로 넘친다(레일·상단 막대, 이번 변경 전부터).
