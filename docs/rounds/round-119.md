# 119차: 왼쪽 메뉴 펼치기 — 마우스를 올리면 아이콘 옆에 전체 이름이 보이는 메뉴 막대

- 날짜: 2026-11-28 · 세션: 관제
- 사용자: "왼쪽의 도구메뉴에 마우스 가져가면 각 아이콘 별로 어떤 메뉴인지 글자가 나오는 전체 메뉴바가 보이면 좋겠어."

> **요약** 아이콘 레일에 마우스를 올리거나 키보드로 들어오면, 아이콘 옆에 화면 이름이 붙은 넓은 메뉴 막대(232px)로 펼쳐진다. 묶음 이름(학사·학교)도 글자로 보인다. 본문은 밀리지 않고 위에 겹친다.

> **왜** 아이콘과 짧은 이름만으로는 무슨 화면인지 알기 어렵다. 항목마다 풍선을 띄우면(#144) 하나씩만 보인다. 펼치면 전체 메뉴를 한눈에 본다.

## 한 일
- `src/components/Nav.tsx`: 항목마다 펼침용 전체 이름(`.nav-full`, 화면낭독기에는 숨김)을 넣었다. 접근 이름은 그대로다.
- `src/app/globals.css`
  - 넓은 화면 + 마우스가 있는 기기에서 `.sidebar:hover`나 키보드 초점(`:has(:focus-visible)`)이 있으면 펼친다.
  - 펼침을 0.12초 늦춰 스칠 때 깜빡이지 않게 했다. 움직임 줄이기 설정을 존중한다.
  - 분석형은 펼쳤을 때 항목별 풍선을 끄고 묶음 이름을 보인다.
  - 휴대폰 폭(768px 이하)·터치 기기는 그대로다.
