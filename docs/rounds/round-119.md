# 119차: 학교 구조를 성격별 탭으로 나눔

- 날짜: 2026-11-28 · 세션: 학사 시스템 개발 전담
- 사용자: "한 화면에 학교급, 학기 구조, 학년도와 학기 등의 카드가 여러 개 크기별로 있는데 같은 계열과 급을 나눠서 탭으로 분리시키면 접근성이 더 좋을 것 같다."

> **요약** 학교 구조 화면(`/academics`)의 크기가 다른 카드 세 개와 따로 떨어진 템플릿 화면을 탭 네 개(학교급·학년 / 학기 구조 / 학년도·학기 / 템플릿)로 묶었다. 한 번에 한 가지만 보이고, 탭마다 개수·판 번호가 붙는다.

> **왜** 카드 크기가 제각각이라 어디부터 정할지 눈이 흩어졌고, 화면 읽기 프로그램으로는 긴 한 쪽을 끝까지 내려가야 했다. 탭으로 나누면 한 번에 한 가지 일만 보이고, 점검표의 '학기 구조'·'학년도' 단계가 그 탭으로 바로 간다.

```terms
용어 | 쉬운 설명 | 예시
탭 | 같은 화면 안에서 묶음을 골라 보는 머리 줄 | '학기 구조' 탭을 누르면 학기 구조만 보임
주소 탭 | 탭마다 주소가 달라 즐겨찾기·뒤로 가기가 되는 탭 | /academics?tab=years
```

## 한 일
- `src/app/(app)/academics/AcademicsTabs.tsx`: 탭 줄(`nav.tabs`, 지금 탭 `aria-current="page"`, 개수 표시). 자바스크립트 없이 링크로 동작.
- `/academics`: `?tab=levels|terms|years`로 카드 하나씩. 모르는 값은 첫 탭.
- `/academics/templates`: 같은 탭 줄(네 번째 탭).
- 점검표의 '학기 구조'·'학년도' 단계 링크를 해당 탭으로. 학년도 탭에서 학기 구조가 없을 때 '학기 구조' 탭 링크.
- 스타일: `.tabs [aria-current="page"]`도 지금 탭으로 표시(밑줄 + 굵기, 색만이 아님). 480px 이하에서는 학교 구조 탭을 2×2 칸으로(가로로 밀려 숨는 탭 없음).
- 이름표 5개(ko·en). e2e는 탭을 눌러 학기 구조·학년도로 이동하게 고침. UI 점검 상태에 `terms`·`years` 추가.
