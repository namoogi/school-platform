# 26차: 화면 형식 선택 (전체 관리 = 분석형, 학교 = 학사 업무형)

## 목적 (사용자 지시)
- 전체 관리자 모드는 분석 대시보드형이 기본이고, 화이트 반전 버튼 하나를 둔다.
- 학교별 관리자 모드는 학사 업무형이 기본이다.
- 기본은 이렇게 하되 사용자가 UI를 골라 바로 바꿀 수 있게 하고, DB는 어떤 UI에서도 연동되게 한다.

결정 기록은 [ADR 0007](../decisions/0007-ui-switching.md)이다.

## 한 일
- **상단 막대**: '화이트/다크' 반전 버튼과 '화면 형식' 메뉴(학사 업무형 / 분석 대시보드형)를 추가했다.
  - 누르는 즉시 바뀐다.
  - 선택은 사용자별로 DB(`user_preferences`)에 저장된다. 다른 기기에서 로그인해도 같은 화면이 열린다.
- **분석 대시보드형**: 얇은 아이콘 메뉴(마우스·키보드 초점에 이름 풍선), 차가운 회색과 파랑, 본문 14px, 숫자는 JetBrains Mono 고정폭.
- **어두운 화면**: 두 형식 모두 지원한다. 상태색은 어두운 바탕용 값을 따로 썼다. 발행본 종이는 인쇄물 색을 유지한다.
- **전체 관리 첫 화면**: 기간 선택(7·14·30일), 운영 기록 추이 막대 차트(화면낭독기용 표 포함), 학교별 좌석 사용 막대를 추가했다.
- **데이터 연동**: 형식은 셸 배치와 토큰만 바꾼다. 모든 화면이 같은 서버 조회(asUser + RLS)를 쓴다. E2E에서 형식을 바꾼 뒤 같은 카드·표 내용이 나오는 것을 확인한다.
