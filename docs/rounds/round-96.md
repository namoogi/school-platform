# 96차: 학교별 격리 등급 배정 (ADR 0038)

- 날짜: 2026-11-27 · 세션: 관제
- 사용자: "각 4단계 모두 승인하고 학교별로 선택 및 배정이 가능하도록 설계 및 구현 진행하자는거지."

> **요약** 전체 관리 → **등급**에서 학교마다 공용·확장·전용·독립을 고르고 진행 상태(정함·옮기는 중·옮김·운영 중)를 판으로 남긴다. 옮긴 학교는 공용 앱에서 새 주소를 안내한다. 전용·독립은 같은 코드를 따로 배포하는 방식으로 정했다.

> **왜** 학교마다 필요한 격리 수준과 비용이 다르다. 고른 등급과 그 이유·원가가 이력으로 남아야 나중에 요금과 운영을 설명할 수 있다.

```terms
용어 | 쉬운 설명 | 예시
등급 판 | 학교의 격리 등급을 바꿀 때마다 새로 쌓는 기록 | 1판 공용 → 2판 전용(정함) → 3판 전용(옮김)
따로 배포 | 같은 프로그램을 그 학교만을 위해 하나 더 띄우는 것 | 큰 학교는 전용 주소에서 따로 돌림
409(판 충돌) | 내가 본 뒤 다른 사람이 먼저 고쳤을 때 저장을 막는 것 | 두 관리자가 동시에 등급을 바꾸면 한쪽은 다시 읽고 고침
```

## 한 일
- 마이그레이션 `20261128000600_school_placements.sql`
  - `school_placements`: 등급·상태·옮긴 주소·이유·월 원가를 판으로 쌓는다. 고치기·지우기를 막는다. 학교 구성원은 자기 학교만 읽는다.
  - 명령 함수 `app.set_school_placement`: 전체 관리자만 쓴다. `base_version`이 낡으면 409로 거부하고, 운영 기록을 남긴다.
- `src/lib/placement.ts`(등급·상태·원가 범위·읽기·검사), `/api/admin/placements`
- 화면 `/admin/placements`(메뉴 '등급')
  - 등급 설명·원가표, 학교마다 지금 등급과 새 판 쓰기, 이력
  - 문구는 처음부터 이름표로 썼다(한국어·영어).
- 학교 화면: 마지막 판이 '옮김'이면 새 주소 안내 띠를 띄운다.
- 학교 화면 언어: 사용자가 고르지 않았으면 학교 기본 언어(`schools.locale`)를 먼저 쓴다. 예: 영어 학교 B는 영어로 열린다(ADR 0038 5항).
- ADR 0038: 전용·독립은 따로 배포 + 따로 DB로 운영한다(앱 안의 학교별 DB 분기는 하지 않음).
