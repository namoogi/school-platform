# 128차: R2로 옮긴 파일의 DB 사본 비우기 (ADR 0047)

- 날짜: 2026-11-28 · 세션: 관제
- 사용자: "db에 남은 원본 파일도 비워줘"

> **요약** R2에 같은 내용(sha256)이 있는 홈페이지 파일만 DB 사본을 비운다. 파일 기록 행은 그대로 두고 바이트 칸만 비운다.

> **왜** R2로 165개(약 189MB)를 옮긴 뒤에도 DB에 사본이 남아 DB 용량을 차지했다. DB 단가가 R2보다 약 8배 비싸다.

```terms
용어 | 쉬운 설명 | 예시
DB 사본 | DB 안에 들어 있던 파일 내용 | 홈페이지 사진의 원래 바이트
sha256 | 파일 내용으로 만든 지문. 한 글자만 달라도 바뀐다 | R2 파일 지문 = DB 기록 지문일 때만 비움
```
