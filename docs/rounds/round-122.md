# 122차: 공개 창 — 사진 공개 허가 확인 + 기록

> **요약** 사진이 든 판을 공개하려면 공개 창에서 "이 사진들의 공개 허가(학생·보호자·학교)를 확인했습니다"를 골라야 한다. 누가·언제·어떤 사진을 확인했는지 공개 기록에 남는다.

## 사용자 지시 (2026-11-28)
"사진 공개 허가 확인도 게시 창에 넣어 줘" — 범위는 '확인 + 기록'(추천안)을 선생님이 골랐다.
- 이전 결정 D-4(2026-11-23, 안내 한 줄만)를 이 지시가 넓힌다. 올리는 곳의 안내 한 줄(`PHOTO_CONSENT`)은 그대로 둔다.

## 한 일
- **공개 창**(`src/components/site/PhotoConsent.tsx`, `usePhotoConsent`): 공개를 누르면 그 판의 사진을 `/api/site/photos`로 읽어 보여 준다. 사진이 있으면 확인 칸을 골라야 '확인하고 공개'가 켜진다. 사진이 없으면 창 없이 바로 공개한다.
  - 공개하는 곳 다섯 군데 모두: 화면 편집 '공개', 목록 카드 '공개하기', 자세한 편집기 '저장하고 공개'·판 기록 '이 판 공개', 가져오기 '모두 공개'(한 번에 확인), 성품 동화 일괄 공개(한 번에 확인).
- **서버가 다시 막는다**: `publish()`·`bulkPublishStories()`는 사진이 든 판을 `photo_consent: true` 없이 공개하지 않는다(`err.photoConsentRequired`, 일괄은 그 동화만 건너뜀). 공개 내림은 확인이 필요 없다.
- **기록**: 마이그레이션 `20261128001400_publish_photo_consent.sql` — `site_publications.photo_consent_at`(확인 시각), `photo_consent_assets`(확인한 사진 id). 확인한 사람 = 같은 행의 `published_by`. 둘은 짝으로만 있고, 공개 기록은 지금처럼 고치거나 지울 수 없다.
- 사진 = 이 학교 그림 자산(`mime image/*`)으로 판에 쓰인 것: 겉표지·로고·그림·사진 묶음·구역/카드 사진·동화 쪽(`src/lib/site-photos.ts`). PDF 내려받기는 사진이 아니다.

## 승인하면 바뀌는 것 / 안 바뀌는 것 / 되돌리기
- 바뀜: 사진 든 판을 공개할 때 확인 한 번이 더 든다. 공개 기록에 확인 시각·사진 목록이 생긴다.
- 안 바뀜: 시안 저장, 공개 내림, 교사 권한(공개는 여전히 관리자), 외부 작업 토큰 공개(이 칸이 비어 '사람 확인 아님'으로 구분된다).
- 되돌리기: 화면·서버 검사는 PR을 되돌리면 된다. 칸 두 개는 비어도 되는 칸이라 남겨 두어도 동작에 영향이 없다.
