# 126차: 학교 AI로 템플릿 맞추기 — 안내 연결 (ADR 0043 5단계)

- 날짜: 2026-11-28 · 세션: 학사 시스템 개발 전담
- 사용자: "학교 AI 맞춤 안내 연결 하자"

> **요약** 템플릿을 고른 학교의 템플릿 화면에 '학교 AI로 우리 학교에 맞추기' 카드를 더했다. 버튼 하나로 지금 학교 사본(학년 체계·학교급·학기·척도·계산식 견본·발행 서식·숨기는 구획)과 할 일 순서가 담긴 AI 지시문을 복사해, 학교가 쓰는 AI 대화창에 붙여 넣는다.

> **왜** 템플릿은 시작점이고, 학교마다 성적표 양식·산출 방식이 다르다(ADR 0041). 그 분석은 학교 구독 AI가 하고(ADR 0032) 확정은 사람이 한다. 지금까지는 어디서 무엇을 AI에게 줘야 하는지 화면에서 이어지지 않았다.

```terms
용어 | 쉬운 설명 | 예시
AI 지시문 | AI 대화창에 그대로 붙여 넣는 작업 설명서 | "우리 학교 사본은 이렇고, 이 순서로 맞춰라"
매핑표 | 학교 규정의 항목을 플랫폼 칸에 짝지은 표 | "반영비율 프로젝트 50 → 평가 항목"
학교 사본 | 템플릿에서 복사해 학교가 고치는 값 | 척도 pass_fail, 학기 1학기·2학기
```

## 흐름
```
템플릿 화면 '학교 AI로 우리 학교에 맞추기'
  [AI 지시문 복사] → 학교 AI 대화창에 붙여 넣기
  → AI가 빈 성적표 양식·평가 규정을 받아 매핑표 + 화면별 '지금 값 → 바꿀 값 · 왜' 초안
  → 학교 관리자가 학기 구조·척도·계산식·출력 화면에서 새 판으로 저장
  → (따로 쌓을 기록) 학사 꾸러미 토큰으로 AI가 정의 작성, 켜기는 관리자
```

## 확인하지 못한 것·다음
- 지시문은 AI에게 주는 글이라 한국어 하나다(AI 연결 글과 같음). 다른 언어 학교용 지시문은 다음.
- 학교 작업 토큰으로 척도·계산식·학기 구조를 직접 쓰는 길은 없다(ADR 0040 다음 단계). 지금은 AI가 초안을 만들고 사람이 저장한다.
- AI 작업 공간은 홈페이지(`/site`) 안에 있다. 홈페이지 모듈이 없는 학교는 그 링크로 토큰을 발급할 수 없다.
