# 그림 아래 다국어 줄거리와 나중에 등록할 번역 그림

사용자 요청: 현재는 비용이 큰 이미지 생성·글자 교체를 실행하지 않는다. 그림 아래에 언어별 줄거리를 표시하고, 나중에 번역한 그림을 등록해 보여 줄 길을 마련한다.

## 현재 표시

- 원본 그림 바로 뒤의 단순한 `section/steps` 이야기 흐름은 선택 언어의 **이야기 줄거리** 구역으로 보여 준다. 시작·갈등·해결의 기존 번역과 제목을 모두 유지한다. 숨김·사진·링크·추가 설명이 있는 복잡한 구역은 기존 렌더러를 쓴다.
- 완성 그림책의 `story_page.text`도 **이 장면의 이야기** 아래에 항상 표시한다. 그림 속 글자가 있다는 이유로 숨기지 않는다.
- 이미 공개된 글과 그림을 그대로 읽으므로 새 판·재공개 없이 화면에 반영된다. 원문·기존 판·이미지 파일은 변경하지 않는다.

## 나중에 번역 그림 등록

`image`와 `story_page`에 선택 항목 `images`를 추가한다. 기본 `asset`은 보존한다.

```json
{"type":"story_page","asset":"<원본 그림 UUID>","text":{"ko":"이야기","en":"Story","th":"เรื่องราว"},"images":{"en":{"asset":"<영어 그림 UUID>"},"th":{"asset":"<태국어 그림 UUID>"}}}
```

- 선택 언어의 `images[lang].asset`이 있으면 사용하고, 없으면 원본 `asset`을 쓴다. 다른 언어의 번역 그림을 대신 사용하지 않는다.
- 관리 화면 `/site`의 그림/동화 한 쪽 블록 → **언어별 그림 (선택 사항)**에서 학교에 올린 그림을 연결한다. 새 판 저장과 공개는 기존 흐름을 따른다. 화면 편집기는 언어별 그림이 있으면 해당 그림을 편집하고, 없으면 원본 그림이라고 표시한다.
- 사람 저장·에이전트 저장 모두 학교 소속과 PNG/JPG/WEBP 형식을 검증한다. 시안 이미지는 공개 전에는 방문자에게 제공하지 않는다.
- UUID를 번역문으로 오인하지 않도록 언어 값은 문자열이 아닌 `{asset}` 객체다. 텍스트 번역 감시기는 이를 번역 작업으로 만들지 않는다.
- 실제 이미지 생성·변환, 외부 번역/이미지 API, 생성 대기열은 실행하거나 연결하지 않는다. 나중에 사용자가 생성 작업을 요청하면 원본을 유지하며 별도 언어 그림을 올리고 위 항목에 연결한다.

## 검증

타입 검사, 단위 테스트 95개와 Python 9개, 운영 빌드 통과. DB 통합에 양방향 학교 경계·토큰 경로·공개 전 그림 차단을 추가했다. E2E에 3개 언어 줄거리, 그림책 글 표시, 언어별 그림 선택 칸을 추가했다. 실제 학교의 33편 시안과 16쪽 완성본에는 기존 다국어 줄거리·장면 글이 있어 별도 콘텐츠 저장이 필요 없다.
