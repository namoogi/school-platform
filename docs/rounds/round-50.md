# 50차: 다시 가져오기 '알아서 구분' — 고친 쪽은 빈 칸만 채움

- 날짜: 2026-11-24 · 세션: 관제
- 사용자 지시: "이미 추가 개발이 많이 이루어지고 있는데 그냥 가져오기를 하면 덮어쓰지 않나? 너가 비교해보고 가져오지 않은 부분만 업데이트 하는 것이 나을 것 같은데" · "알아서 구분해서 업데이트 하나?" → "그래. 진행 부탁해."

## 한 일
- 기존 홈페이지 묶음(zip)을 이미 있는 학교에 다시 가져오면 **쪽·소식마다 최신 판을 보고 판단**한다(`decideReimport`, `src/lib/site-import.ts`).

| 최신 판 | 판단 | 하는 일 |
| --- | --- | --- |
| 가져오기로 만든 판 그대로(메모가 '기존 홈페이지 가져오기'로 시작, 빈 칸만 채운 판 아님) | 바꿈 | 새로 가져온 판으로 새 판 |
| 사람·AI가 고친 판 | 빈 칸만 | 비어 있는 칸·없는 언어만 채움. 구역은 같은 종류끼리 짝지어 채우고, 옛 사이트에만 있는 구역은 더하지 않고 목록으로 보여 줌 |
| 위와 같은데 채울 칸 없음 | 그대로 | 새 판을 만들지 않음 |
| 성품 동화 | 그대로 | 건드리지 않음(42차와 같음) |

- 시안 화면에 쪽마다 판단·채울 칸·더하지 않은 구역을 미리 보여 준다(`[data-testid=import-decisions]`). 최신 판이 아직 공개 전이면 '함께 공개될 수 있음'을 알린다.
- 쓰기는 모두 `base_version`을 붙인다(ADR 0013): 미리 보기 뒤 다른 곳에서 새 판이 생기면 409로 멈춘다.
- 그림은 실제로 쓰는 쪽에 필요한 것만 올린다.
- 사이트 설정: 처음 가져오기는 묶음 설정 그대로, 다시 가져오기는 빈 칸만(제목은 없는 언어만, 언어는 더하기만, 기본 언어 유지, 테마는 기본 테마일 때만)(`mergeSettings`).
- 편집 API `GET /api/site/entries/<id>`(최신 판 내용·메모·공개 여부) 추가.
