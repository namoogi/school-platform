# 66차: 학교 자료로 템플릿 빈 칸 채우기(자동 배치) (ADR 0031)

- 날짜: 2026-11-26 · 세션: 관제
- 사용자 지시: "템플릿에 자동적으로 관리자가 첨부한 학교 자료가 AI로 분석되어 배치"(2026-11-25), "계속 진행해 줘"(2026-11-26)

## 분석 주체 — 비용 원칙에 따라 세 길로 나눔
| 길 | 무엇 | 비용 | 이번 차시 |
| --- | --- | --- | --- |
| ① 자료에서 찾아 채우기(내장) | 올린 자료를 '제목 + 본문' 묶음으로 나누고, 빈 칸 단서 낱말로 맞는 부분을 찾아 제안한다. **규칙 기반**이며 AI 모델은 쓰지 않는다 | 없음 | **구현** |
| ② 학교 AI에게 맡기기 | 학교 구독 AI(Claude Code·Codex)가 작업 토큰(쪽 읽기·고치기)으로 빈 칸 안내를 읽고 자료를 분석해 새 판을 저장한다 | 학교 구독(플랫폼 비용 없음) | **구현**(API·안내·연결 글) |
| ③ 플랫폼 AI 분석(유료 API) | 서버가 Claude API로 자료를 읽어 제안한다 | 사용량 과금 | **채택 안 함**(ADR 0032, 2026-11-26 사용자 결정: 무거운 AI 작업은 구독 계정으로) |

## 한 일
- `src/lib/site-autofill.ts`(DB·외부 API 없음)
  - 자료 나누기: 짧고 문장으로 끝나지 않는 줄, 번호·기호·':'로 끝나는 줄을 제목으로 본다. '3월: 입학식' 같은 이름–값 줄은 본문으로 둔다.
  - 칸 찾기: 제목에 단서가 있으면 +3, 본문에 있으면 +1(최대 2). 2점 이상 중 가장 높은 묶음을 고른다. 제목으로 찾으면 '높은 확신', 본문으로만 찾으면 '확인 필요'.
  - 칸 종류별 처리
    - 글 칸: 본문(900자)이나 첫 문장(제목 칸 120자)
    - 목록 칸: 글머리·번호·연도 줄 → 항목('이름: 설명', 연도 → 제목)
    - 연락처: 도로명 주소·전화·이메일 패턴
    - 사진 칸: 학교 홈페이지 그림(최근 것부터)
  - 맞는 부분이 없으면 제안하지 않는다(지어내지 않음).
  - 넣기는 **안내 자리 `[ … ]`나 빈 칸일 때만** 한다. 학교가 쓴 칸은 그대로 둔다.
- `readers.readPlainText`: PDF·DOCX·TXT 본문 글 읽기(표 판독 `readFile`과 따로).
- `site-templates.ts`
  - 템플릿으로 만든 쪽에 `meta.template`(예: `story@1`)을 남긴다.
  - `autofillPropose`: 파일은 저장하지 않고, 5개·각 8MB까지 받는다.
  - `autofillApply`
    - 쪽마다 새 시안 판 하나(`base_version`), 판 메모 '자료로 빈 칸 채움'
    - 값 형식을 검사하고, 사진은 이 학교 그림만 받는다.
    - 활동 기록 `site.template_autofill`
- API(관리자): `POST /api/site/templates/autofill`(multipart), `POST /api/site/templates/autofill/apply`
- 학교 AI: `GET /api/agent/templates`(쪽 토큰), `docs/agents/README.md` '템플릿 빈 칸 채우기', AI 연결 글에 쪽 토큰용 안내
- 화면 `/site/templates/<key>` 아래 '학교 자료로 채우기'
  - 흐름: 파일 → 자료 읽기 → 제안 목록 → 고른 것 넣기
  - 제안 목록: 체크(높은 확신은 기본 선택), 글은 고쳐서 넣기, 출처 파일·제목, 못 찾은 칸
  - '학교 AI에게 맡기기' 안내
