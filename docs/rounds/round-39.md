## 지시 (2026-11-23, 선생님 → 룽아룬숙사 세션)

## 기준을 잡은 방법
- 옛 사이트 세션이 출력한 `ADMIN-FEATURES.md`(3절 '페이지별 고정 구역')·`app/site.css`·구역별 컴포넌트 17개를 읽었다(저장소에 넣지 않음).
- 옛 사이트를 Playwright로 열어 **브라우저가 계산한 값**(글자 크기·줄 간격·격자 열·여백·선)을 구역마다 뽑았다. CSS를 손으로 겹쳐 계산하지 않았다.
- 실제 글로 비교: 옛 사이트 세션이 묶음의 `content.json`(교직원 실명은 `<교사 이름>`으로 바꿔서)을 조각 출력 → sha256 확인 → 공개 사진 9장을 옛 사이트 공개 주소에서 받아 로컬 묶음을 만들고, 로컬 플랫폼의 '기존 홈페이지 가져오기'로 넣었다. 7쪽을 1440·390 폭에서 옛 화면과 나란히 찍어 비교했다. 실제 글·사진은 임시 폴더에만 두었다(ADR 0008).
