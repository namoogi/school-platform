# 39차: 관제 센터 — 결정 요청함과 지시 전달 (ADR 0015)

- 날짜: 2026-11-23 · 세션: 관제(학교 플랫폼 전체)
- 사용자 지시: 세션이 승인을 물은 채 멈추지 않게, 승인 건은 관제 센터에 요청으로 올리고 다른 일을 한다. 관제 센터에서 승인·지시 대화를 하면 세션에 전달되거나 작업이 실행된다. 개발·연구소 할 일은 승인 대기 건이 아니므로, 세부 내용과 추가 요청사항을 붙여 지시할 수 있게 한다.

## 한 일
- **규칙**: 서브 세션은 승인을 기다리며 멈추지 않는다. 되돌릴 수 있는 일은 추천안으로 진행, 되돌리기 어려운 일(삭제·공개 범위·비용·외부 발송·운영 넘겨주기·권한 확대)만 보류하고 다른 일(AGENTS.md, `docs/automation/SCHOOL-SESSIONS.md`).
- **관제 센터** `/admin/control`: 답 필요(답 기다림·추천안 진행 중·보류) / 전달·진행 / 끝남. 요청마다 세부 내용, 선택지(추천 표시), 주고받은 내용, 답 칸(선택지 + 추가 요청사항 + 받을 곳: 세션·새 세션 만들어 실행·메모만). '새 지시'로 직접 지시.
- **개발·연구소**: 맨 위 안내(할 일은 선생님 목록, 승인 대기는 관제 센터), 항목마다 '세션에 지시' → 제목·내용이 채워진 새 지시.
- **세션 API** `/api/control/*`(점검 토큰): 요청 올리기, 보고, 전달할 지시 목록(inbox), 전달됨 표시, 세션 등록. 절차 `docs/automation/CONTROL-CENTER.md`.
- **DB**: `control_sessions`·`control_requests`·`control_messages`, 역할 `control_writer`, 스키마 `control`. 기록은 추가만, 전달됨 표시는 한 번. 사람의 답(`user`)은 로그인한 전체 관리자만.
- **시작 내용**: 그동안 대화·문서에 있던 결정 대기 9건을 D-1~D-9로 옮김(`DECISIONS.md`는 안내만 남김).
