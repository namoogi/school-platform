# 새벽빛(dawn) 테마 디자인 체계 — 52차

룽아룬숙사 홈페이지가 "사진과 글이 그냥 나열된 느낌"이라는 사용자 판단(2026-11-24)에서 시작했다. 원인과 고친 방식을 적는다. CSS는 `src/app/globals.css`의 '52차: 새벽빛 디자인 체계 정돈' 절.

## 고른 도구와 쓴 곳
| 도구 | 왜 골랐나 | 쓴 곳 |
| --- | --- | --- |
| 방문자 과업 분석(top tasks) | 학교 홈페이지의 첫 방문자는 대부분 입학을 고민하는 보호자다. "어떤 학교인가 → 무엇을 배우나 → 어떻게 입학하나 → 어디로 연락하나" 순서로 찾는다 | 첫 화면 구역 순서, '한눈에 보기' 추가, 쪽마다 끝은 안내 띠(다음 할 일) |
| 시각 위계(글자 단계) | 구역 모양마다 제목이 25·28·29·38·42px로 달라 무엇이 큰 제목인지 흐렸다 | 글자 5단계: 표제 · 구역 제목(28–36) · 항목 제목(22) · 본문(16) · 머리말(12, 금색 대문자) |
| 근접·묶음(게슈탈트) | 구역 사이 간격이 같고 배경이 같아 쪽의 마디가 보이지 않았다 | 배움(번호 상자)·안내 띠를 화면 끝까지 연회색 띠로, 구역 사이는 한 간격(72–112px) |
| 격자와 비율 | 사진을 '잘림 없이' 넣어 크기가 제각각이었고, 위 맞춤이라 글 옆이 비었다 | 사진–글 5:7(가운데 맞춤, 짝수 줄 좌우 바꿈), 사진은 4:3(대표 사진 4:5) 채우기, 카드 3단·동화 4단 |
| 일관성(닐슨 휴리스틱 4) | 같은 활동 사진이 소개·생활·첫 화면에 반복됐다 | 활동 줄은 '학교생활'에만, '학교 소개'는 학교 공간 그림 |
| 내용 설계(방문자 문장) | "확인 필요·확인 중" 같은 작성 메모가 방문자에게 보였다 | 방문자 문장으로 고치고, 원문은 숨긴 '관리자 메모' 구역에 남긴다(화면 편집에서만 보임) |
| 접근성(WCAG 2.1 AA) | 메뉴 12px, 본문 연한 회색 | 메뉴 14px, 머리말 진한 금색 #835d28(종이·연회색 바탕 모두 대비 4.5:1 이상, axe 확인), 누르는 곳 44px 유지, axe 검사 |

## 지키는 규칙
- 색은 `--dawn-*` 토큰만. 새 크기는 `--dawn-fs-*` 단계에서 고른다.
- 새 구역 모양(variant)을 더할 때도 제목은 `--dawn-fs-h2`, 항목 제목은 `--dawn-fs-h3`, 사진은 4:3 채우기를 기본으로 한다.
- 쪽에 같은 사진을 두 번 쓰지 않는다. 쪽 사이 반복도 피한다(활동 사진 → 학교생활, 공간 그림 → 학교 소개).
- 방문자에게 보이는 글에 작성 과정·출처 확인 메모를 쓰지 않는다. 필요하면 숨긴 알림 구역에 둔다.
