## 3. 공통 원리 → 우리 템플릿에 쓸 규칙
| # | 원리 | 본 곳 | 우리 적용 |
| --- | --- | --- | --- |
| 1 | 구역 배경은 화면 끝까지, 내용은 1140~1200px 격자 | 전부 | 100차 레이아웃 체계(1200px·12칸·구역 띠) |
| 2 | 머리글 위 **작은 줄**: 연락처·포털·언어·후원/입학 단추 | Kingster, Eduma, ISKL | 머리글 2층: 위 작은 줄 + 한 줄 메뉴 |
| 3 | 첫 화면 아래 **겹친 바로가기 3~4칸** | Kingster, ISB(옆 타일), ISKL(소식 띠) | 새 구역 모양 '겹친 바로가기' |
| 4 | **학년 단계 카드**(같은 크기, 사진 위 이름) | ISKL, ISB, Paideia | 카드 구역 모양 '단계 카드' |
| 5 | **숫자 띠** | ISKL, ISB | 정보 구역 모양 '숫자 띠'(학교가 입력할 때만) |
| 6 | **소식 + 행사(날짜 배지) + 행동 카드**를 한 줄에 | Kingster, Eduma | 소식 구역에 날짜 배지 행사 목록 |
| 7 | 반반 구역의 사진·글 교차와 **겹친 카드** | Kingster, ISB, Paideia | 기존 split 모양에 겹친 카드 |
| 8 | 후기·목소리 3칸(색 띠 위) | Eduma | 인용 구역 3칸 모양(공개 동의 전제) |
| 9 | 인증·협력 기관 **로고 줄** | Kingster, Eduma, ISB | 바닥글 위 로고 줄(선택) |
| 10 | **4~5칸 바닥글 + 아래 줄**(사이트맵·접근성·개인정보) | 전부 | 100차 4칸 바닥글 + 아래 줄 링크 |

- 판매용 테마(Kingster·Eduma)는 **한 화면에 정보가 촘촘**합니다(구역 10개 이상, 3~4칸 격자 반복). 수상 학교 사이트는 **여백과 사진·이야기**가 많습니다. 선생님이 원하신 '촘촘하게 정돈된' 쪽은 테마형에 가깝습니다. 그래서 **격자 규칙은 테마형을 따르고, 구역 수는 학교가 고르게** 하는 것을 제안합니다.

## 4. 지켜야 할 선
- 테마는 유료 상품이고 학교 사이트도 저작물입니다. **코드·사진·문구·로고·고유 그래픽(물결 모양, 색 조합)은 가져오지 않습니다.** 구역 순서·격자·칸 수 같은 일반 구조만 참고합니다(ADR 0034, `homepage-commercial-plan.md` 1절).
- 숫자 띠·후기·교사 사진은 학교가 입력하고 공개에 동의한 것만 보입니다. 예시는 합성 자료만 씁니다.
