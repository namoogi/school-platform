# 템플릿 레이아웃 체계 — 진단과 작업 지시 (100차 준비, 2026-11-27)

> **요약** 99차로 사진과 쪽별 배치는 들어갔지만, 화면을 붙잡는 **공통 레이아웃 체계**(격자·간격 단계·구역 머리·머리글·바닥글 규칙)가 없습니다. 그래서 구역마다 폭·정렬·여백이 제각각이고 빈 곳이 생깁니다. 이 작업은 잘 정돈된 학교·기관 템플릿들의 **구조 원리**를 조사해, 정리된 레이아웃 체계를 만들고 대표 3종(story·project·kinder)에 적용합니다.

> **왜** 선생님(2026-11-27): "사진도 예쁘고 좋긴 한데 기본적인 골격, 레이아웃이 정리되지 않은 것 같다. 레이아웃이 촘촘하게 잘 정돈된 템플릿을 찾고 반영하도록 하자."

```terms
격자(grid) | 화면을 같은 폭의 세로 칸(예: 12칸)으로 나눠 모든 요소를 칸 경계에 맞추는 규칙 | 카드 3장 = 4칸씩, 글·사진 반반 = 6칸씩
간격 단계 | 여백을 몇 가지 정해진 크기로만 쓰는 규칙 | 구역 사이 96px, 제목과 본문 사이 16px
구역 머리 | 각 구역 위에 오는 작은 이름표·제목·설명·'모두 보기' 링크의 고정 배치 | "학생 작품 / 이번 학기 만든 것 / 모두 보기 →"
구역 띠 | 구역마다 배경색을 번갈아 깔아 경계를 보이게 하는 것 | 흰 바탕 → 연한 베이지 → 흰 바탕
```

## 1. 지금 화면에서 본 문제 (운영 1440px, 99차)
| # | 문제 | 어디서 |
| --- | --- | --- |
| 1 | 화면 공통 격자가 없다. 구역마다 폭이 다르다(본문 760px 제한, 갤러리는 1120px, 소식 카드는 3/4 폭에서 끝남). 오른쪽에 큰 빈칸이 생긴다 | 세 템플릿 모두 |
| 2 | 소식 카드 3장이 줄 끝까지 차지 않고 왼쪽에 몰린다 | 홈 '이야기·발표회·알림' |
| 3 | 구역 간격이 일정하지 않다. 어떤 곳은 200px 넘게 비고, 어떤 곳은 구분선만 있다. 배경 띠가 없어 구역 경계가 흐리다 | 세 템플릿 모두 |
| 4 | 구역 머리 모양이 제각각이다. 이름표·제목·설명·링크 위치가 구역마다 다르고, 단추가 제목과 격자 사이에 끼어 있다 | 프로젝트형 '마을 멘토' |
| 5 | 첫 화면의 글 칸과 사진 칸이 세로로 맞지 않는다. 글 칸이 좁아 제목이 3줄로 꺾이고, 겹친 행사 카드가 사진 밖으로 어긋난다 | 이야기형 첫 화면 |
| 6 | 머리글이 약하다. 학교 이름·메뉴가 위아래로 쌓이고, 오른쪽에 주요 행동(입학 문의 등)이 없다 | 세 템플릿 모두 |
| 7 | 바닥글 3칸의 정렬이 맞지 않는다. 메뉴는 밑줄 친 세로 목록에 간격이 크고, 주소가 떠 있다 | 세 템플릿 모두 |
| 8 | 카드 높이·사진 비율·글 줄 수가 한 줄 안에서 맞지 않는다 | 반 카드, 멘토 카드 |

**근본 원인**: `SiteRenderer`는 블록을 한 줄로 쌓기만 하고, 테마 CSS가 구역별로 폭·여백을 따로 정한다. 공통 '레이아웃 층'(격자·간격 단계·구역 머리·띠)이 없다.

## 범위 나누기

- **다음 작업**: Claude가 대표 학교 홈페이지들을 조사해 `docs/design/school-site-ia.md`(학교 홈페이지가 갖춰야 할 메뉴 구성·쪽 골격)를 만듭니다. 그 결과로 템플릿 메뉴와 쪽을 재구성하는 일은 별도 작업으로 맡깁니다.
- 그래서 머리글·바닥글은 **메뉴가 5~7개, 두 단계(하위 메뉴)로 늘어나도** 견디게 만들어 주세요.

## 2. 해 주실 일 (Codex)
1. **조사**: 레이아웃이 촘촘하게 잘 정돈된 학교·교육기관·비영리 템플릿 5~8개의 **구조 원리**를 정리합니다.
   - 대상: 상용(Framer·Webflow·Squarespace·WordPress 등)과 공개 디자인 시스템(예: GOV.UK, USWDS, Material 격자 규칙)
   - 정리할 것: 격자 칸 수·여백, 간격 단계, 구역 머리 모양, 머리글·바닥글 구조, 카드 격자 규칙, 휴대폰 재배치
   - `docs/design/template-layout-research.md`에 출처 링크와 함께 표로 적습니다.
   - 인터넷이 안 되는 환경이면 알고 있는 원리로 쓰고, 그 사실을 문서 첫머리에 밝힙니다.
   - **코드·사진·문구·고유 디자인은 가져오지 않고 구조 원리만** 참고합니다(ADR 0034, `homepage-commercial-plan.md` 1절).
2. **레이아웃 체계**: 키트 테마(campus·dawn 제외)에 공통으로 적용합니다.
   - 12칸 격자, 콘텐츠 폭(예: 1200px)과 좁은 글 폭(예: 720px) 두 단계, 칸 사이 여백
   - 간격 단계 토큰(예: `--t-space-1..8`)과 구역 상하 여백 규칙
   - 구역 머리 컴포넌트 하나(이름표 → 제목 → 설명, 오른쪽 끝 '모두 보기' 링크)
   - 구역 띠(배경 교차) 규칙, 카드 격자(2·3·4열 자동, 줄 끝까지 채움, 같은 높이·같은 사진 비율)
   - 머리글(왼쪽 학교 이름, 가운데·오른쪽 메뉴, 맨 오른쪽 주요 행동 단추, 휴대폰 메뉴)과 바닥글(4칸 격자: 학교 소개·메뉴·연락·주소/지도 링크)
3. **적용**: 대표 3종의 홈과 안쪽 9쪽을 이 체계에 맞춰 다시 정렬합니다. 1절 문제 1~8이 모두 사라져야 합니다.
   - 저장 형식(블록·variant)은 바꾸지 않습니다. 렌더러와 CSS 층에서 해결합니다.
   - **campus·dawn 테마(룽아룬숙사 운영 사이트)는 바뀌면 안 됩니다.** 전후 화면을 비교해 확인합니다.
4. **시험·증거**
   - `npm run typecheck`, `test:unit`, `lint:colors`, `lint:i18n`, `check:repo`, `npm test`, `npm run build && npm run test:e2e`
   - `npm run ui:review -- template-story template-project template-kinder`(1440·768·390)
   - 썸네일 다시 찍기 `npm run templates:thumbs -- story project kinder`
   - PR 본문에 1절 문제 1~8의 **전후 화면**(1440px)과 휴대폰 화면을 붙이고, 완료 범위·시험 결과·미확인 항목·Claude가 이어 할 일을 적습니다.

## 3. 끝난 기준
- 세 템플릿 모든 쪽에서 구역의 왼쪽·오른쪽 끝이 같은 격자선에 맞는다(첫 화면 전면 사진 예외).
- 구역 간격이 간격 단계 값만 쓴다(CSS에 임의 px 없음, `lint:colors` 규칙 준수).
- 카드 줄이 줄 끝까지 차고, 한 줄 안의 카드 높이·사진 비율이 같다.
- 휴대폰(390px)에서 가로 넘침 0, 머리글 메뉴가 접힌다.
- campus·dawn 화면 변화 없음.
