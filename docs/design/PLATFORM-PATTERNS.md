# 플랫폼 공통 패턴 (서브 세션 성과 → 전체 설계)

서브 세션(학교·기능 세션, ADR 0013)이 한 곳에서 만든 것 중 **다른 모듈·학교에도 쓸 것**을 관제 세션이 모아 여기에 올린다. 각 패턴에 '어디서 나왔나 / 전체에 어떻게 적용하나 / 상태'를 적는다. 서브 세션은 PR 본문의 `## 전체 적용 후보` 칸에 후보를 적고, 관제가 이 문서와 대기열(`docs/automation/QUEUE.md`)에 옮긴다.

상태: **규칙**(AGENTS.md에 올림) · **적용 중** · **대기열**(QUEUE.md) · **결정 대기**(사용자)

## 1. 쓰기·데이터

| 패턴 | 나온 곳 | 전체 적용 | 상태 |
| --- | --- | --- | --- |
| **판 충돌 방지 `base_version`**: 새 판 저장 때 '보고 고친 판'을 보내고, 그 사이 새 판이 있으면 409 + 최신 판 안내 | ADR 0012·0013, 34차(#40) | 판(버전)으로 쌓는 모든 쓰기(홈페이지 항목, 확정 규칙, 양식, 이후 ADR 0004 판들). 사람·에이전트·서브 세션 공통 | 규칙(AGENTS.md 10) · 홈페이지 사람 편집 화면은 35차(#39 이후) |
| **에이전트는 명령 함수로만**: 외부 토큰 요청은 표 권한 없는 역할로 좁은 함수만 호출, 함수 소유 역할에도 RLS | ADR 0012(#40), ADR 0004 `app_writer` | 모든 외부 에이전트·자동화 접근(다른 모듈을 열 때 같은 꼴) | 규칙(AGENTS.md 외부 에이전트) |
| **편집 연산 계층**: 화면 편집이 쓰는 순수 함수(`src/lib/site-edit.ts`)를 AI 제안·에이전트도 같이 쓰고, 저장은 같은 판 API | 35차 화면 편집(#39) | 양식·규칙 등 다른 편집 화면도 '순수 연산 + 같은 저장 경로'로. ADR 0011 2단계(대화형 편집)의 기반 | 적용 중(홈페이지) |
| **숨김 표시 `hidden`**: 지우지 않고 방문자에게서만 빼기 | 35차(#39) | 공개 산출물이 있는 모든 블록형 내용 | 적용 중(홈페이지) |

## 5. AI·에이전트 작업

| 패턴 | 나온 곳 | 전체 적용 | 상태 |
