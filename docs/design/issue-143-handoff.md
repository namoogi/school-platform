기존 `--t-*`, `--space-*`, 글꼴·의미 색 토큰을 사용한다. 새 CSS는 ivory/studio/play에만 적용한다. 760px 이하에서는 교차 줄을 사진 먼저 한 열로 바꾸고, 이야기 홈은 사진 → 겹친 카드 → 소개 순으로 바꾼다. 입학 절차는 900px 이하 두 열, 420px 이하 한 열이다. 초점 테두리와 44px 클릭 영역을 보완하고 동작 줄이기 설정을 존중한다.

새 배치 값은 `curriculum`, `mentors`, `feature-filter`, `portfolio`, `daybook`이다. 기존 블록 구조·값을 유지하고 선택지만 추가했다. 과정 표에는 caption과 행 제목을 둔다. 저장 템플릿에는 예시 사진 ID를 넣지 않고 `samplePages()`에서만 사진을 채운다.

## 사진·예시 자료

- 위치: `public/site-templates/img/`의 story 8장, project 9장, kinder 5장.
- Codex 내장 구독 이미지 생성 도구 사용. 과금 API 키·외부 사이트 사진을 사용하지 않았다.
- 총 5,964,476바이트, 각 JPG 300,000바이트 이하. 첫 화면 1600×900, 일반 1200×900, 계절·놀이 1200×1200.
- 22장 모두 직접 시각 확인: 알아볼 수 있는 얼굴·문자·로고 없이 뒷모습·손·사물 중심. 실제 학교·학생의 기록이 아닌 AI 예시 사진이다. 대체 텍스트에도 AI 예시임을 표시했다.
- 출처·프롬프트·규격: [template-photo-manifest.json](template-photo-manifest.json).
- 비용·멘토·행사·연락처는 가상 예시다. 운영 학교 자료를 읽거나 바꾸지 않았다.
- 썸네일: `public/site-templates/story.jpg`, `project.jpg`, `kinder.jpg`를 production 서버에서 다시 촬영했다.

## 상호작용·자체 점검

- 메뉴·첫 화면 단추는 미리보기 안의 해당 쪽으로 이동한다. 예시 소식은 목록·상세를 실제로 열며 빈 `#` 링크를 쓰지 않는다.
- 필터는 선택 상태를 `aria-pressed`로 표시한다. 학생 작품에서 예술을 고른 뒤 프로젝트로 이동할 때 이전 필터가 남는 문제를 발견해 수정하고 회귀 시험을 추가했다.
- PR 자동 리뷰의 P1(새 필터 배치에서 관리자 분류 입력칸 누락)을 수용했다. `feature-filter`·`portfolio`에도 분류 입력을 열고, 두 쪽 모두 템플릿 적용 → 분류 수정 → 새 판 저장 → 다시 열기 → 미리보기 필터 작동까지 E2E로 확인한다.
- FAQ 펼침, 키보드 필터 선택, 문의 양식의 미리보기 안내를 직접 확인했다. 작은 홈 링크·FAQ 클릭 영역을 44px 이상으로 보완했다.
- 문의 양식은 미리보기에서 실제 전송하지 않음을 표시한다. 유효한 합성 입력 후에도 문의 API 요청이 0건임을 E2E로 검증했다.
- 데스크톱·휴대폰 실제 렌더를 직접 보고 사진 크롭, 계층, 여백, 표 줄바꿈과 교차 배치를 확인했다. 이는 구현자의 자체 점검이며 독립 UI 검토가 아니다.

## Review guidelines 1~3 자체 점검

1. 데이터 경계: 표·RLS·권한·학교 ID 선택·사용자 트랜잭션 변경 없음. DB 접근을 추가하지 않았다.
2. 보존: 확정 규칙·양식·발행본·원본 자료 수정·삭제 없음. 기존 학교 사본을 갱신하지 않고 템플릿 판만 올렸다.
3. 비밀·개인정보: 키·토큰·DB 주소·실제 학생/교직원 자료를 변경 파일에 넣지 않았다. 사진·양식 시험은 합성 자료만 사용한다.

## 확인하지 못한 항목·Claude 인계

- Safari·Firefox·실제 모바일 기기, 보조공학/스크린리더 수동 시험 및 전체 WCAG AA 적합성 인증은 하지 않았다. axe의 자동 검사 통과 범위와 구분한다.
- campus/dawn CSS는 변경하지 않았고 기존 E2E는 통과했지만, 운영 사이트의 모든 쪽에 대한 전후 픽셀 비교는 하지 않았다.
- 운영 DB·배포·실제 학교 공개 및 실사용 문의 발송은 시험하지 않았다. `codex/**`는 저장소 정책상 Vercel 미리보기 배포 대상이 아니다.
- 사진의 미감, 쪽별 정보 우선순위, 새 배치 값의 편집 경험을 Claude가 독립 검토하고 병합 전 통합 시험을 확인한다. 본 작업은 PR 제출까지이며 병합하지 않는다.
