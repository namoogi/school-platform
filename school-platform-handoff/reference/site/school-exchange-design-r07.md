# 학교 간 교육 교류 · 7차 구현 브리프

## 검토 대상

드리미와 룽아룬숙사가 각 학교 수업의 결과물을 교환하고, 다른 교사가 수업안을 재사용할 수 있는 흐름이다. 첫 검증 질문은 “원안을 읽은 교사가 자기 학급에서 적용하고, 결과와 수정점을 다시 공유하는가?”이다.

## 첫 단계

1. **수업 자료실**에서 주제·학교·학년으로 검색하고 활동 유형으로 좁힌다. 수업안을 복제하면 원안과 원본 버전을 기록한다. 수정본은 작성 학교의 초안으로 저장한다.
2. **적용 후기**는 실제 차시, 수정한 활동, 다음 교사에게 전할 팁을 기록한다. 공개 권한이 있는 학급 작품을 연결한다. 원안 작성자가 후기와 후속 수업안을 찾을 수 있게 한다.
3. **공동수업방**에서 참여 교사가 상대 학교·학급, 탐구 질문, 과제와 일정을 합의한다. 시작은 교사가 학급 질문과 결과물을 대표로 올리는 방식이다.
4. **공동 전시**에 각 학교가 승인한 작품을 출품한다. 참여 학교 전용과 공개 상태를 작품별로 관리한다. 두 학교 홈페이지에서 하나의 공개 전시 주소를 연결한다.

## 데이터와 권한

| 대상 | 저장할 내용과 제약 |
| --- | --- |
| 수업안·버전 | 출처 학교, 작성자, 대상, 차시, 언어, 재사용 조건, 원안 버전 ID |
| 적용 후기 | 원안 버전, 적용 학교, 실제 차시, 수정점, 공유 가능한 작품 참조 |
| 공동수업 | 참여 학교·교사, 승인된 학급 질문, 활동, 일정 |
| 전시·출품 | 출품 학교, 작품·설명 원문, 번역, 공개 범위, 승인·철회 이력 |

공용 교류 공간과 학교별 학사 데이터 사이에는 인증된 교사 권한과 학교 식별자만 연결한다. 학생부·성적·학급 명부를 복사하지 않는다. 학교 관리자는 자기 학교 참가 권한을 관리하고, 출품 학교 교사가 학생 식별 정보와 작품 사용 범위를 확인한다. 공개본은 비공개 원본의 직접 주소를 노출하지 않는다. 출품 철회 시 공개 전시와 링크의 접근도 종료되도록 검증한다.

## 후원·판매 확장 후보

- 무료 공유와 출처 표시로 시작하고, 가져간 교사가 현지화와 적용 후기를 남길 수 있게 한다.
- 후원형에서는 학교 또는 후원자가 번역·현지화·교사 연수·공개 수업안 제작비를 지원할 수 있다.
- 유료형은 활동지 번들, 교사 연수, 적용 지원부터 검증한다. 자료 사용권, 번역 및 수정본의 권리, 정산 조건이 정리된 뒤 판매자 등록과 결제를 설계한다.
- 시범 운영에서는 가져간 교사의 실제 적용 수, 후기가 돌아온 수, 프로그램당 운영자 투입시간을 기록한다.

## Claude CLI와 파일로 주고받기

Mac의 Claude CLI와 Codex가 접근 가능한 공통 Git 작업 저장소에서 이 문서를 함께 읽는다. 운영 중인 드리미포털 저장소를 쓸 경우 학교 교류 기능을 어느 앱·폴더에 둘지 먼저 확인한다. 이번 시안의 저장소와 작업 저장소가 다르면 이 파일과 시안의 검토 메모를 작업 저장소에 복사한다.

- 기준 문서 예시: `docs/school-exchange/spec.md`
- Claude 설계 답신: `docs/school-exchange/claude-review.md`
- Codex 검토 메모: `docs/school-exchange/codex-review.md`
- 각 답신에 기준 커밋 SHA, 재사용 가능 코드의 경로, 제안, 미결 사항, 다음 담당을 적는다. 변경은 작업 브랜치에 커밋해 확인한다.
- 자동화는 수동 왕복이 검증된 뒤 검토한다. CLI 세션이나 인증 정보를 복사할 필요는 없다.

### Claude에 전달할 첫 요청

> 학교 교류 구현 브리프를 읽고 이 저장소의 인증, 학교 범위 권한, 수업 아카이브, 전시·게시 기능을 조사해 줘. 재사용할 파일 경로, 추가할 데이터 모델, 권한과 공개 취소의 검증 시나리오, 첫 구현 범위와 미결 사항을 `docs/school-exchange/claude-review.md`에 써 줘. 기준 커밋을 적고 이번에는 설계 검토만 해 줘.

## 시안 검증

- 검색, 유형 필터, 수업안 복제와 원안 연결, 적용 후기 저장을 확인한다.
- 공동수업 초안과 학급 질문을 저장한다.
- 참여 학교 전용 작품이 홈페이지 방문자 미리보기에 표시되지 않는지 확인한다.
- 공개 출품에 확인 체크를 요구하고, 승인한 작품이 공개 화면에 표시되는지 확인한다.
- 검토 메모 저장과 Markdown 내려받기를 확인한다.

7차 시안은 가상 데이터와 브라우저 로컬 저장으로 위 흐름을 시험한다. 실제 학교 간 동기화와 로그인·권한 적용은 서비스 구현에서 검증한다.
